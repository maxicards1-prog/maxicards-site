Vérifier si un mot existe

Chargement…

    Le lien rouvre la page avec vos lettres.

    Tapez un mot, avec ou sans accents : la réponse s'affiche tout de suite.

    Mis à jour le 26/11/2026 · recherche faite dans votre navigateur, rien n'est envoyé.

    Comment vérifier un mot

    Tapez le mot, avec ou sans accents, et l'outil dit s'il est présent dans notre dictionnaire libre. Par exemple, « kiwi » y est ; « bonjourr » n'y est pas.

    Ce que veut dire « présent »

    Le dictionnaire est le lexique Grammalecte, une liste libre (licence MPL 2.0) qui recense les formes des mots : singuliers, pluriels, féminins, conjugaisons. « Présent » signifie qu'il figure dans cette liste. Cela ne dit rien d'autre : ce n'est ni une définition, ni un avis sur la façon dont le mot est employé.

    Attention : ce n'est pas la liste officielle

    Les compétitions de Scrabble (marque de son propriétaire) utilisent une liste officielle, l'ODS. Notre dictionnaire peut contenir des mots absents de l'ODS, et l'ODS peut contenir des mots absents du nôtre. Pour une partie de club, vérifiez dans le document de votre fédération. Pour une partie entre amis, mettez-vous d'accord avant de jouer sur la liste à suivre.

    Ce qui est exclu

    • Les noms propres (prénoms, villes, marques).
    • Les mots avec trait d'union, apostrophe ou espace.
    • Les symboles, les formules et les mots d'une seule lettre.

    Si le mot n'est pas trouvé

    Contrôlez l'orthographe. Essayez la forme conjuguée ou accordée (« mangeons » et non « manger », par exemple) : l'outil vérifie la forme exacte que vous tapez. Pour chercher des mots à partir de lettres, utilisez l'outil d'anagrammes ; pour les points d'un mot, l'outil de points.

    Plus de détails sur l'origine de la liste : page crédits.

    Questions fréquentes

    Comment savoir si un mot existe ?

    Tapez-le dans l'outil : il dit s'il est présent dans notre dictionnaire libre. Un mot absent peut exister dans d'autres ouvrages.

    Un mot présent ici compte-t-il en partie officielle de Scrabble ?

    Pas forcément. Notre dictionnaire n'est pas la liste officielle des compétitions : vérifiez dans cette liste pour une partie officielle.

    Faut-il taper les accents ?

    Tapez le mot comme il s'écrit, avec ses accents : une forme sans accent peut être un autre mot, ou ne pas exister.
