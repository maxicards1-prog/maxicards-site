Comment trouver la couleur d'un point d'une image ?

  1. Choisissez une image de votre ordinateur ou de votre téléphone.
  2. Cliquez sur le point qui vous intéresse (ou touchez-le sur un écran tactile). Au clavier, placez-vous sur l'image puis utilisez les flèches : un pixel par pression, dix avec la touche Maj.
  3. Le code HEX, le RGB et le HSL s'affichent, avec le nom CSS le plus proche. Les boutons « Copier » les placent dans le presse-papiers.

Votre image reste chez vous

La lecture se fait entièrement dans votre navigateur : l'image est dessinée sur une zone de travail de votre page, jamais envoyée sur internet et jamais enregistrée. En fermant la page, tout disparaît. Par sécurité, les fichiers de plus de 25 Mo et les images de plus de 64 millions de pixels sont refusés ; une grande image est réduite à 1 000 pixels sur son grand côté pour l'affichage.

Les couleurs dominantes

L'outil réduit l'image à une petite taille (64 pixels au plus sur le grand côté), range les pixels par familles de couleurs proches et affiche les familles les plus fréquentes, avec leur part de l'image. Deux couleurs presque identiques ne sont pas répétées. C'est une aide pour trouver la couleur principale d'une photo ou d'un logo, pas une mesure de laboratoire.

Pourquoi la couleur peut sembler différente

  • Une photo JPG contient du bruit : deux pixels voisins n'ont pas exactement la même couleur. Cliquez à plusieurs endroits d'une zone et gardez la valeur qui revient.
  • Les images enregistrées avec un profil de couleur particulier, ou un écran réglé différemment, peuvent s'afficher autrement que le code relevé.
  • Les zones transparentes d'une image PNG peuvent être lues comme du noir : cliquez sur une zone colorée.

Pour la suite, le code couleur donne toutes les écritures et un nuancier, la palette propose des harmonies, et le testeur de contraste vérifie qu'un texte reste lisible. Pour préparer l'image elle-même, voir redimensionner une image ou compresser une image.

Questions fréquentes

L'image est-elle envoyée sur internet ?

Non. Elle est lue et dessinée dans votre navigateur seulement. Rien n'est envoyé ni enregistré.

Quels formats d'image fonctionnent ?

Ceux que votre navigateur sait afficher : en général PNG, JPG, WebP et GIF. Si le format n'est pas pris en charge, un message l'indique.

Comment lire la couleur sur mon téléphone ?

Chargez la photo puis touchez le point voulu. Chaque touche remplace la couleur affichée.

Pourquoi deux clics proches donnent-ils des codes différents ?

Les photos contiennent du bruit et de la compression. Les pixels voisins diffèrent légèrement : cliquez à plusieurs endroits.
