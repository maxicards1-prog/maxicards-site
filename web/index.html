Des outils simples, qui marchent sans compte

Un QR code pour votre menu ou votre Wi-Fi, le code exact d'une couleur, un texte de remplissage pour une maquette : ces petits besoins reviennent souvent. Ici, l'outil s'ouvre tout de suite, le résultat s'affiche pendant que vous tapez, et rien ne vous est demandé en échange.

Ce qui change ici

  • QR codes statiques : le contenu est écrit dans le code lui-même. Pas de redirection par nos serveurs, pas d'abonnement, pas de date de fin.
  • Rien ne quitte votre appareil : le mot de passe Wi-Fi, vos coordonnées ou l'image dont vous prélevez une couleur restent dans votre navigateur.
  • Des règles citées : contraste selon les règles WCAG du W3C, noms de couleurs de la norme CSS, capacité des QR codes selon la norme ISO/IEC 18004.
  • Images et PDF : pour convertir ou compresser le fichier obtenu, la rubrique Convertir s'en charge, elle aussi dans votre navigateur.
