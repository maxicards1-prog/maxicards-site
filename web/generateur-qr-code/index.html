    QR code statique ou dynamique : la vraie différence
    

    Un QR code statique contient l'information elle-même : l'adresse du site, le texte, le réseau Wi-Fi. Le téléphone la lit directement dans le dessin. Rien ne passe par un serveur : le code ne peut pas expirer, et personne ne compte vos scans.
    

    Un QR code dynamique contient l'adresse courte d'un service, qui redirige ensuite vers votre page. C'est pratique pour changer la destination après l'impression. Mais si le service s'arrête ou si l'abonnement prend fin, tous les codes imprimés cessent de marcher. Ici, nous ne faisons que des codes statiques.
    

    Pour pouvoir changer la destination plus tard sans service payant, faites pointer le code vers une page de votre propre site, puis modifiez cette page.
    

    Bien imprimer un QR code
    

      

    • Gardez la marge. La norme ISO/IEC 18004 prévoit une zone vide de 4 modules (les petits carrés) tout autour. Sans elle, les lecteurs peinent à trouver le code.
      • 

    • Code foncé sur fond clair. Un fort contraste se lit partout. Un code clair sur fond foncé (inversé) n'est pas lu par certains lecteurs.
      • 

    • Assez grand. Plus le contenu est long, plus le code a de modules et plus il faut l'imprimer grand. Une adresse courte donne un code simple.
      • 

    • Testez avant d'imprimer en série, avec deux téléphones différents si possible, à la distance réelle de lecture.
      • 

    

    Quel niveau de correction choisir ?
    

    Le QR code répète une partie de l'information pour survivre aux taches et aux rayures. Plus le niveau est haut, plus le code est dense pour un même texte.

    PNG ou SVG ?
    

    Le PNG est une image en pixels : parfaite pour un site, un document ou un message. Le SVG est vectoriel : il reste net à toutes les tailles, c'est le format à donner à un imprimeur. Besoin d'un autre format ? Transformez le PNG avec notre outil PNG en JPG ou PNG en PDF.
    

    Prudence avec les QR codes des autres
    

    Un QR code peut cacher une adresse piégée : c'est l'hameçonnage par QR code (« quishing »). Avant d'ouvrir un lien, lisez l'adresse affichée par le téléphone. Un autocollant collé par-dessus un code officiel doit vous mettre en alerte.

    Questions fréquentes
    Ce QR code est-il vraiment gratuit et sans limite de durée ?
    Oui. C'est un QR code statique : le contenu est dans le code lui-même, sans redirection ni abonnement. Il marchera tant que la destination existe.
    Puis-je modifier le lien après l'impression ?
    Non, un code statique ne change pas. Astuce : faites pointer le code vers une page de votre site, puis changez le contenu de cette page.
    Combien de texte peut contenir un QR code ?
    Au plus 2 953 octets au niveau L, avec la version 40 (177 × 177 modules). Mais un code aussi plein est difficile à lire : restez court.
    Mes données sont-elles envoyées quelque part ?
    Non. Le code est calculé dans votre navigateur. Rien n'est envoyé, rien n'est enregistré, rien n'est écrit dans l'adresse de la page.
    Pourquoi mon téléphone ne lit pas mon QR code ?
    Vérifiez la marge (4 modules), le contraste (code foncé sur fond clair), la taille d'impression et la netteté. Un code inversé ou trop dense se lit mal.
