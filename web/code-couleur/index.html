Comment lire un code couleur ?

Un écran fabrique chaque couleur en mélangeant du rouge, du vert et du bleu (RVB, ou RGB en anglais). Chacun de ces trois canaux a 256 niveaux, de 0 à 255 : cela donne 256 × 256 × 256 = 16 777 216 couleurs possibles. Le code HEX écrit ces trois nombres en base 16, avec deux caractères par canal. Par exemple, #1E90FF veut dire : rouge 1E (soit 30), vert 90 (soit 144) et bleu FF (soit 255).

Le CMJN : une approximation

Le CMJN décrit des encres, pas de la lumière. Passer du RGB au CMJN dépend du papier, de l'encre et du profil de couleur de l'imprimeur. Notre calcul est le plus simple qui existe : le noir est K = 1 − max(R, V, B) ÷ 255, et les trois autres valeurs s'en déduisent. Il donne un repère, pas un résultat d'imprimerie : pour un document à imprimer, demandez le profil à votre imprimeur.

Nom CSS, texte lisible, nuancier

  • Nom CSS : la norme CSS connaît 148 noms de couleurs. Si la vôtre n'en a pas, l'outil donne le plus proche, mesuré dans l'espace Lab, qui suit mieux l'œil que le RGB. Voir tous les noms CSS.
  • Texte lisible : noir ou blanc, selon celui qui contraste le plus avec votre couleur. Pour tester deux couleurs précises, utilisez le testeur de contraste.
  • Nuancier : les teintes plus claires sont mélangées avec du blanc, les plus foncées avec du noir.
  • Harmonies : couleurs qui se marient bien. Pour les copier en variables CSS, voir la palette de couleurs.

Questions fréquentes

Comment trouver le code HEX d'une couleur ?

Choisissez-la avec le sélecteur ou tapez son code RGB, HSL ou son nom : le code HEX s'affiche tout de suite. Pour une couleur dans une image, utilisez la pipette sur image.

Le CMJN affiché est-il exact pour l'imprimerie ?

Non. C'est un calcul simple. Le CMJN réel dépend de l'imprimeur, du papier, de l'encre et du profil de couleur : demandez-lui la valeur à utiliser.

Que veut dire le nom CSS le plus proche ?

La couleur choisie n'a pas de nom dans la norme CSS. L'outil affiche le nom de la couleur nommée qui lui ressemble le plus à l'œil.

Puis-je écrire le code sans le dièse ?

Oui : 1e90ff, #1e90ff et #19f sont compris. Les codes rgb() et hsl() et les noms de couleurs en anglais aussi.
