    Comment marche un QR code Wi-Fi ?
    

    Le code contient une courte ligne de texte qui décrit votre réseau. Le téléphone la reconnaît et propose de se connecter. Pour un réseau « MaBox » protégé par le mot de passe « secret », le code contient :
    

    WIFI:T:WPA;S:MaBox;P:secret;;
    

      

    • T : le type de sécurité (WPA, WEP, ou nopass pour un réseau ouvert) ;
      • 

    • S : le nom du réseau (SSID) ;
      • 

    • P : le mot de passe ;
      • 

    • H:true : ajouté seulement si le réseau est masqué.
      • 

    

    Si le nom ou le mot de passe contient un caractère spécial (\ ; , : "), l'outil le fait précéder d'une barre oblique inverse, comme le prévoit le format. Vous n'avez rien à faire.
    

    Quelle sécurité choisir ?
    

    Pour un réseau protégé par WPA, WPA2 ou WPA3, choisissez « WPA » : c'est la valeur du format. Si votre box est réglée en WPA3 seul, testez le code sur plusieurs téléphones avant de l'imprimer : les appareils anciens ne connaissent pas ce mode. Le WEP est un ancien système. « Aucun » ne sert que pour un réseau ouvert, sans mot de passe. Le nom et le mot de passe doivent être recopiés exactement, majuscules comprises : une seule lettre fausse et la connexion échoue.
    

    Votre mot de passe reste chez vous
    

    Le code est calculé dans votre navigateur. Le mot de passe n'est envoyé à aucun serveur, n'est pas enregistré et n'apparaît pas dans l'adresse de la page. Fermez l'onglet : il ne reste rien.
    

    Attention tout de même : toute personne qui scanne le code obtient le mot de passe. Pour les visiteurs, un réseau « invités » séparé, si votre box le propose, est plus prudent.
    

    Comment vos invités le scannent
    

    Sur iPhone, l'appareil photo lit les QR codes depuis iOS 11 : il suffit de viser le code et de toucher la notification. Sur Android, selon le modèle, c'est l'appareil photo ou Google Lens. Aucune application à installer dans la plupart des cas.
    

    Où le placer ?
    

    Imprimez le code sur une petite carte posée dans l'entrée, le salon ou la chambre d'amis. Pour un gîte, un café ou une salle d'attente, glissez-le dans un cadre. Ajoutez le nom du réseau en clair sous le code : il aide ceux qui préfèrent taper.
    

    Si vous changez le mot de passe du Wi-Fi, l'ancien code ne marche plus : c'est un code statique. Refaites-en un nouveau ici en quelques secondes. Pour l'envoyer par e-mail ou l'insérer dans un document, convertissez le PNG avec PNG en JPG ou PNG en PDF.

    Questions fréquentes
    Le QR code Wi-Fi marche-t-il sur iPhone et Android ?
    Oui. Sur iPhone, l'appareil photo lit les QR codes depuis iOS 11. Sur Android, utilisez l'appareil photo ou Google Lens selon le modèle.
    Mon mot de passe Wi-Fi est-il envoyé sur Internet ?
    Non. Le code est fabriqué dans votre navigateur : le mot de passe n'est envoyé nulle part et n'est pas enregistré.
    Que faire si je change le mot de passe de ma box ?
    Refaites un code : un QR code statique contient l'ancien mot de passe et ne se met pas à jour tout seul.
    Mon réseau a un nom avec des points-virgules ou des virgules : ça marche ?
    Oui. L'outil ajoute la barre oblique inverse devant ces caractères, comme le demande le format Wi-Fi.
