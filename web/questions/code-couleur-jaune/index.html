Quel est le code couleur du jaune ?

Le jaune pur s'écrit #FFFF00 en HEX, soit rgb(255, 255, 0) en RGB : le rouge et le vert sont au maximum, le bleu est éteint.

Mis à jour le 26/11/2026.

Les codes du jaune

Nom CSSHEXRGBHSLCMJN (calcul simple)
yellow#FFFF00rgb(255, 255, 0)hsl(60, 100%, 50%)C 0 % · M 0 % · J 100 % · N 0 %
gold#FFD700rgb(255, 215, 0)hsl(51, 100%, 50%)C 0 % · M 16 % · J 100 % · N 0 %
khaki#F0E68Crgb(240, 230, 140)hsl(54, 77%, 75%)C 0 % · M 4 % · J 42 % · N 6 %
lightyellow#FFFFE0rgb(255, 255, 224)hsl(60, 100%, 94%)C 0 % · M 0 % · J 12 % · N 0 %

Le CMJN est calculé par une formule simple (K = 1 − max(R, V, B) ÷ 255) : le CMJN réel dépend de l'imprimeur, du papier et de l'encre.

Un jaune très lumineux

Sur un écran, le jaune est obtenu en allumant ensemble le rouge et le vert. C'est une couleur très lumineuse : sur fond blanc, un texte jaune est presque illisible, comme le montre le tableau. À l'inverse, un texte noir sur fond jaune est très lisible : on l'emploie d'ailleurs souvent pour des panneaux d'avertissement.

Pour un jaune plus chaud, tirant vers l'orange, essayez gold. khaki est un jaune pâle un peu terne, et lightyellow un jaune très clair, presque blanc, utile en fond de zone mise en évidence.

Nuances voisines

Voici des teintes plus claires (mélangées avec du blanc) et plus foncées (mélangées avec du noir) de yellow.

Est-ce lisible en texte ?

Un texte normal demande un contraste d'au moins 4,5:1 (niveau AA des règles WCAG 2.2). Voici ce que donne chaque code, en texte sur un fond blanc ou noir :

Couleur du texteSur fond blancSur fond noir
yellow1,07:1 (insuffisant)19,55:1 (AA)
gold1,40:1 (insuffisant)14,97:1 (AA)
khaki1,28:1 (insuffisant)16,40:1 (AA)
lightyellow1,01:1 (insuffisant)20,63:1 (AA)

Couleur complémentaire

Sur le cercle des écrans (RVB), la couleur complémentaire de yellow (#FFFF00) est #0000FF, que le CSS nomme blue. Pour d'autres harmonies, voir la palette de couleurs.

Questions fréquentes

Quel est le code RGB du jaune ?

Pour yellow : rgb(255, 255, 0).

Quel est le code CMJN du jaune ?

Pour yellow, le calcul simple donne C 0 % · M 0 % · J 100 % · N 0 %. Le CMJN réel dépend de l'imprimeur : demandez-lui la valeur à utiliser.
