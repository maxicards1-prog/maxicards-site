Comment scanner un QR code Wi-Fi ?

Ouvrez l'appareil photo de votre téléphone, visez le QR code Wi-Fi et validez la proposition de connexion qui apparaît : le téléphone rejoint le réseau sans que vous tapiez le mot de passe.

Mis à jour le 26/11/2026.

Un QR code Wi-Fi contient le nom du réseau, le type de sécurité et le mot de passe. En le scannant, votre téléphone sait tout ce qu'il faut pour se connecter.

Sur iPhone

L'appareil photo lit les QR codes depuis iOS 11. Ouvrez-le, visez le code, attendez la bulle de proposition, puis validez. Les mots exacts varient selon la version.

Sur Android

Selon le modèle, la lecture se fait avec l'appareil photo ou avec Google Lens. Si l'appareil photo ne réagit pas, cherchez une option de lecture de QR codes dans l'appli photo, ou ouvrez Google Lens.

Si rien ne se passe

  • Éloignez ou rapprochez le téléphone : le code doit être net et entier à l'écran.
  • Améliorez la lumière et évitez les reflets sur un code imprimé.
  • Vérifiez qu'il y a une marge blanche autour du code : sans elle, la lecture est plus difficile.
  • Essayez l'autre mode de lecture (appareil photo ou Lens).
  • Si le réseau a changé de mot de passe, l'ancien code ne marchera plus.

Vérifiez avant de vous connecter

Regardez le nom du réseau que le téléphone propose. Un code collé par quelqu'un d'autre sur un panneau pourrait mener à un faux réseau. Ne vous connectez qu'à un réseau dont vous connaissez la source.

Questions fréquentes

Faut-il une appli pour scanner un QR code Wi-Fi ?

Pas en général : l'appareil photo (iPhone depuis iOS 11) ou Google Lens selon le modèle Android suffit.

Pourquoi mon téléphone ne propose-t-il pas de se connecter ?

Le code est peut-être mal lu (flou, reflet, trop petit) ou ne contient pas de réseau Wi-Fi. Essayez de le rendre plus net.

Un QR code Wi-Fi montre-t-il le mot de passe ?

Le code le contient, donc quiconque le scanne peut se connecter. Certains téléphones n'affichent pas le mot de passe, mais ne comptez pas dessus.
