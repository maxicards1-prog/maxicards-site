Comment insérer du lorem ipsum dans Word ?

Dans Microsoft Word, tapez =lorem() sur une ligne vide puis appuyez sur Entrée : Word insère du faux texte, que l'on peut régler avec =lorem(p,l).

Mis à jour le 26/11/2026.

Word sait fabriquer du faux texte tout seul, sans rien installer. Il suffit d'une petite formule à taper dans le document.

La commande de base

  1. Placez le curseur sur une ligne vide.
  2. Tapez =lorem().
  3. Appuyez sur Entrée.

Word remplace la formule par du faux texte.

Choisir la quantité

Dans =lorem(p,l), p est le nombre de paragraphes et l le nombre de lignes par paragraphe.

Ce que vous tapezCe que Word insère
=lorem()Du faux texte, avec les réglages par défaut
=lorem(3,4)3 paragraphes de 4 lignes
=lorem(2)2 paragraphes
=rand()Du texte dans la langue de Word

Et =rand() ?

La commande =rand() insère du texte dans la langue de Word. Elle fonctionne de la même façon, avec les mêmes réglages entre parenthèses. Elle convient si vous voulez du texte plus lisible que le latin.

Si ça ne marche pas

  • Vérifiez que la ligne ne contient rien d'autre que la formule.
  • Appuyez sur Entrée juste après la parenthèse fermante.
  • Le remplacement automatique peut être désactivé dans les options de correction de Word. L'emplacement du réglage dépend de la version : consultez l'aide de votre Word.

Avant de rendre le document

Le faux texte inséré par Word est un vrai texte du document : il s'imprime et s'enregistre comme le reste. Relisez le document en entier avant de l'envoyer, et supprimez ce qui n'est plus utile. Si vous ne voyez pas le texte apparaître, essayez sur un document vide pour savoir si le problème vient de votre fichier ou du réglage de Word.

Questions fréquentes

Que veut dire =lorem(p,l) ?

p est le nombre de paragraphes et l le nombre de lignes dans chaque paragraphe.

Quelle différence entre =lorem() et =rand() ?

=lorem() insère du lorem ipsum ; =rand() insère du texte dans la langue de Word.

Cela marche-t-il sur d'autres logiciels ?

Pas partout : c'est une fonction de Word. Dans les autres logiciels, générez le texte avec notre outil puis collez-le.
