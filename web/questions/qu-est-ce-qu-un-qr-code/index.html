Qu'est-ce qu'un QR code ?

Un QR code est un code-barres en deux dimensions, fait de petits carrés noirs et blancs, qui stocke du texte (souvent un lien) et se lit avec l'appareil photo d'un téléphone.

Mis à jour le 26/11/2026.

QR vient de l'anglais « Quick Response », réponse rapide. C'est un dessin carré fait de petits carrés, les modules. Il représente du texte : une adresse web, un numéro de téléphone, un réseau Wi-Fi, une fiche de contact.

D'où ça vient

Le QR code a été inventé en 1994 par Denso Wave, une entreprise japonaise, pour suivre des pièces dans l'industrie. « QR Code » est une marque déposée de DENSO WAVE INCORPORATED, et le format est décrit par la norme ISO/IEC 18004.

Comment ça marche

Trois grands carrés dans les coins aident le téléphone à repérer le code et son sens. Le reste du dessin encode les données, avec des informations de secours. Le téléphone traduit le dessin en texte, puis vous propose une action : ouvrir un lien, rejoindre un Wi-Fi, ajouter un contact.

À quoi ça sert

  • Ouvrir une page web sans la taper.
  • Partager un Wi-Fi sans dicter le mot de passe.
  • Donner ses coordonnées sur une carte de visite.
  • Consulter un menu, une notice ou un programme.

Ses limites

  • Il contient du texte, pas un fichier : pour un PDF ou une vidéo, on code un lien.
  • Il peut mener à une fausse page : lisez l'adresse avant d'ouvrir.
  • Un code dynamique dépend d'un service qui peut s'arrêter.

Statique ou dynamique

Un code statique contient l'information elle-même et n'expire jamais. Un code dynamique contient une adresse courte d'un service qui redirige : il cesse de marcher si le service s'arrête.

En créer un

Il suffit de choisir le type de contenu, de le taper ou de le coller, puis de télécharger l'image. Notre outil le fait dans votre navigateur, gratuitement.
