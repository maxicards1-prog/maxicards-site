À quoi sert le niveau de correction d'un QR code ?

Le niveau de correction d'erreur ajoute des données de secours dans le QR code : il reste lisible même s'il est un peu abîmé, à raison d'environ 7 % (L), 15 % (M), 25 % (Q) ou 30 % (H) de dégâts.

Mis à jour le 26/11/2026.

Un QR code contient, en plus de votre contenu, des données de réparation. Si une partie du dessin est salie, cachée ou déchirée, ces données permettent de retrouver ce qui manque. Le niveau de correction règle la quantité de ces données de secours.

Les quatre niveaux

NiveauPart restaurablePour qui
Lenviron 7 %Écran propre, contenu long
Menviron 15 %Usage courant
Qenviron 25 %Impression, risque de salissure
Henviron 30 %Environnement difficile, logo au centre

Ces pourcentages sont des ordres de grandeur : ils décrivent la part des données que la méthode de correction sait retrouver.

Le compromis

Plus la correction est forte, plus le code est chargé. Pour un même contenu, un niveau H donne un code plus dense qu'un niveau L. Un code plus dense demande des modules plus petits ou une taille plus grande à l'impression.

Comment choisir

  • Affichage à l'écran, lien court : L ou M suffisent.
  • Papier, affiche, emballage : M ou Q, pour supporter plis et salissures.
  • Logo au centre du code : prenez un niveau élevé et testez beaucoup.

La marge de silence

La correction ne remplace pas la marge blanche autour du code, d'une largeur de 4 modules. Sans elle, le téléphone peut ne pas repérer le code.

Un conseil

Quel que soit le niveau, imprimez et testez avec plusieurs téléphones. La correction aide, mais un bon contraste et une taille suffisante comptent davantage.

Questions fréquentes

Quel niveau choisir par défaut ?

Le niveau M convient à la plupart des usages. Passez à Q ou H pour une impression exposée aux salissures.

Un niveau plus fort rend-il le code plus lisible ?

Il le rend plus résistant aux dégâts, mais aussi plus dense, donc parfois plus difficile à lire si le code est petit.

Peut-on mettre un logo dans un QR code ?

Oui, un logo cache une partie du code. Il vaut mieux un niveau de correction élevé et des tests sur plusieurs téléphones.
