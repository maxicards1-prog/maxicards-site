Combien de caractères peut contenir un QR code ?

Au maximum, un QR code peut contenir 7 089 chiffres, 4 296 caractères alphanumériques ou 2 953 octets, mais c'est la capacité du plus grand modèle avec le niveau de correction le plus faible.

Mis à jour le 26/11/2026.

La capacité d'un QR code dépend de trois choses : le type de contenu, la taille du code (sa « version ») et le niveau de correction d'erreur. Les valeurs maximales sont données pour la version 40 avec le niveau L.

Les maximums

Type de contenuMaximum
Chiffres seuls7 089
Alphanumérique (chiffres, majuscules, quelques signes)4 296
Octets (texte avec minuscules, accents)2 953

Les accents et les caractères spéciaux comptent comme du texte « octets », donc la limite est plus basse qu'avec des chiffres seuls.

Les versions

Il existe 40 versions. La version 1 mesure 21 × 21 modules (les petits carrés du dessin). La version 40 en compte 177 × 177. Chaque version ajoute 4 modules de chaque côté. Plus il y a de contenu, plus le code est grand et dense.

Pourquoi ne pas tout remplir

  • Un code très dense a de très petits modules : il faut une bonne caméra et un grand format pour le lire.
  • Un niveau de correction plus fort (M, Q ou H) réduit la place disponible.
  • Un lien court donne un code plus simple et plus facile à scanner.

Exemple

Une adresse web de quelques dizaines de caractères donne un petit code, très lisible. Un long texte de plusieurs paragraphes donne un code très dense, difficile à lire sur une petite carte. Dans la pratique, mieux vaut coder un lien court vers la page qui contient le texte.

À retenir

Le maximum existe, mais c'est rarement un bon objectif. Plus le contenu est court, plus le code se lit facilement. Notre outil vous montre le code en direct pendant que vous tapez.

Questions fréquentes

Combien de caractères pour un lien ?

Une adresse web tient largement dans un code de taille moyenne. Plus elle est courte, plus le code est simple à lire.

Pourquoi le maximum varie-t-il ?

Il dépend du type de caractères : les chiffres sont les plus compacts, le texte avec accents l'est moins.

Le niveau de correction change-t-il la capacité ?

Oui. Plus la correction est forte, moins il reste de place pour votre contenu.
