Quel est le code couleur de l'argent ?

L'argent le plus proche en CSS est silver : #C0C0C0 en HEX, soit rgb(192, 192, 192) en RGB, un gris clair.

Mis à jour le 26/11/2026.

Les codes de l'argent

Nom CSSHEXRGBHSLCMJN (calcul simple)
silver#C0C0C0rgb(192, 192, 192)hsl(0, 0%, 75%)C 0 % · M 0 % · J 0 % · N 25 %
lightgray#D3D3D3rgb(211, 211, 211)hsl(0, 0%, 83%)C 0 % · M 0 % · J 0 % · N 17 %
darkgray#A9A9A9rgb(169, 169, 169)hsl(0, 0%, 66%)C 0 % · M 0 % · J 0 % · N 34 %

Le CMJN est calculé par une formule simple (K = 1 − max(R, V, B) ÷ 255) : le CMJN réel dépend de l'imprimeur, du papier et de l'encre.

Un gris clair qui évoque le métal

La couleur nommée silver est un gris clair neutre : ses trois canaux ont la même valeur. Comme pour le doré, un code ne rend pas l'éclat du métal, qui vient des reflets. Plus clair, lightgray ; plus foncé, darkgray.

Pour suggérer l'argent sur un site, on construit en général un dégradé de gris clairs et de blancs. Attention : un texte argenté sur fond blanc est presque invisible, le tableau le montre. Mettez-le sur un fond sombre, ou utilisez un gris foncé pour le texte.

Nuances voisines

Voici des teintes plus claires (mélangées avec du blanc) et plus foncées (mélangées avec du noir) de silver.

Est-ce lisible en texte ?

Un texte normal demande un contraste d'au moins 4,5:1 (niveau AA des règles WCAG 2.2). Voici ce que donne chaque code, en texte sur un fond blanc ou noir :

Couleur du texteSur fond blancSur fond noir
silver1,81:1 (insuffisant)11,54:1 (AA)
lightgray1,49:1 (insuffisant)14,02:1 (AA)
darkgray2,35:1 (insuffisant)8,93:1 (AA)

Couleur complémentaire

Sur le cercle des écrans (RVB), la couleur complémentaire de silver (#C0C0C0) est #C0C0C0, que le CSS nomme silver. Pour d'autres harmonies, voir la palette de couleurs.

Questions fréquentes

Quel est le code RGB de l'argent ?

Pour silver : rgb(192, 192, 192).

Quel est le code CMJN de l'argent ?

Pour silver, le calcul simple donne C 0 % · M 0 % · J 0 % · N 25 %. Le CMJN réel dépend de l'imprimeur : demandez-lui la valeur à utiliser.
