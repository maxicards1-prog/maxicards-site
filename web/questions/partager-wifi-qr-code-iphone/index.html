Comment partager son Wi-Fi avec un QR code sur iPhone ?

Le plus simple est de créer un QR code Wi-Fi avec le nom du réseau et le mot de passe, puis de le montrer : l'appareil photo d'un iPhone lit les QR codes depuis iOS 11 et propose de rejoindre le réseau.

Mis à jour le 26/11/2026.

Taper un long mot de passe Wi-Fi est pénible. Un QR code Wi-Fi règle cela : la personne ouvre l'appareil photo, vise le code, et son téléphone propose de rejoindre le réseau.

Créer le code

  1. Ouvrez notre outil de QR code Wi-Fi.
  2. Tapez le nom exact du réseau (attention aux majuscules et aux espaces).
  3. Choisissez le type de sécurité de votre box ou de votre routeur, et tapez le mot de passe.
  4. Téléchargez l'image du code.

Le scanner avec un iPhone

L'appareil photo d'un iPhone lit les QR codes depuis iOS 11. Il suffit de l'ouvrir et de viser le code : une proposition de connexion apparaît, que l'on valide. Les libellés exacts dépendent de la version d'iOS.

Et le partage direct entre iPhone ?

Selon les versions, les appareils Apple proposent aussi un partage de mot de passe entre appareils proches. Cette fonction existe en parallèle et ne produit pas d'image à imprimer. Le QR code, lui, se montre à tout le monde : amis, invités, clients, et il se lit aussi avec un téléphone Android.

Ce que contient le code

Le code contient du texte au format WIFI:T:WPA;S:nom;P:mot de passe;;. Les caractères spéciaux comme le point-virgule ou les deux-points sont protégés par une barre oblique inverse : notre outil s'en occupe.

Attention à la confidentialité

Quiconque scanne le code obtient le mot de passe. Ne l'affichez pas dans un lieu public si le réseau est privé. Si vous changez le mot de passe, il faut refaire le code. Notre outil fonctionne dans votre navigateur : rien n'est envoyé.

Questions fréquentes

Faut-il installer une appli sur l'iPhone ?

Non : l'appareil photo lit les QR codes depuis iOS 11.

Le QR code Wi-Fi marche-t-il sur Android ?

Oui. Selon le modèle, c'est l'appareil photo ou Google Lens qui lit le code.

Mon mot de passe est-il envoyé sur Internet ?

Non. Le code est créé dans votre navigateur, rien n'est transmis.
