Comment savoir si un QR code est dangereux ?

On ne peut pas juger un QR code à son dessin : il faut regarder l'adresse que le téléphone affiche avant d'ouvrir, et se méfier d'un code collé, imprévu ou qui demande des informations personnelles.

Mis à jour le 26/11/2026.

Un QR code est comme une adresse web cachée dans un dessin : on ne voit pas où il mène. Des escrocs en profitent. On parle de « quishing » : un QR code qui mène à une page piège, souvent une fausse page de paiement ou de connexion.

Les réflexes à avoir

  1. Lisez l'adresse affichée par le téléphone avant d'ouvrir. Si elle ne ressemble pas au nom de l'organisme, n'ouvrez pas.
  2. Méfiez-vous d'un code collé par-dessus un autre, sur un panneau, une borne ou un parcmètre.
  3. Méfiez-vous d'un code reçu sans l'avoir demandé : courrier, message, e-mail, colis.
  4. Ne saisissez jamais de mot de passe, de code de carte ou de données personnelles sur une page ouverte depuis un code dont vous n'êtes pas sûr.
  5. Passez par le site officiel en tapant vous-même son adresse si vous avez un doute.

Signes d'alerte

  • Une adresse avec des fautes, des mots mélangés ou un nom proche mais différent du vrai.
  • Une page qui crée l'urgence : « paiement immédiat », « compte bloqué ».
  • Une demande de télécharger une appli inconnue.

Si vous avez un doute après coup

Ne donnez rien de plus. Si vous avez saisi un mot de passe, changez-le sur le vrai site. Si vous avez donné un numéro de carte, contactez votre banque. Le site cybermalveillance.gouv.fr propose des conseils et une assistance en cas de piège en ligne.

Pour vos propres codes

Si vous créez un code pour des clients, mettez-le sur un support que l'on ne peut pas recouvrir facilement, et indiquez à côté l'adresse en toutes lettres : cela rassure.

Questions fréquentes

Un QR code peut-il pirater mon téléphone ?

Le code lui-même est du texte. Le danger vient de la page qu'il ouvre ou de ce que vous y faites. Lisez l'adresse et ne saisissez rien de sensible.

Comment vérifier où mène un QR code ?

Le téléphone affiche l'adresse avant d'ouvrir. Lisez-la, et n'ouvrez pas si elle vous semble étrange.

Que faire si j'ai scanné un faux code ?

Fermez la page, ne saisissez rien, et si vous avez donné un mot de passe ou une carte, changez-le ou prévenez votre banque.
