Quelle taille minimum pour imprimer un QR code ?

Il n'existe pas de taille unique : plus le code contient de données, plus il doit être grand, et seul un essai d'impression scanné avec plusieurs téléphones donne la bonne réponse.

Mis à jour le 26/11/2026.

On aimerait un chiffre unique, mais il n'existe pas. La taille minimum dépend de la densité du code, de la distance de lecture, de la qualité d'impression et du téléphone. Voici des repères, à prendre comme tels.

Ce qui fait varier la taille

  • La quantité de contenu. Un lien court donne un code simple, aux gros modules. Un long texte donne un code dense, aux modules minuscules.
  • La distance de lecture. Un code sur une carte tenue à la main n'a pas besoin de la taille d'un code sur une affiche vue de loin.
  • Le niveau de correction. Plus il est élevé, plus le code est dense.
  • La qualité d'impression et le support. Un papier brillant ou une encre pâle réduisent la lisibilité.

Repères pratiques

SituationRepère
Carte de visite ou ticketChoisir un contenu très court et un code assez grand pour que les petits carrés restent bien visibles
Affiche lue de prèsUn code de taille moyenne suffit si le contenu est court
Affiche lue de loinPlus la distance est grande, plus le code doit être grand

La marge de silence

Gardez une marge blanche de 4 modules autour du code. Elle fait partie de sa taille : un code collé contre une image ou un texte se lit mal.

Le test d'impression

  1. Imprimez le code à la taille et sur le support prévus.
  2. Scannez-le avec au moins deux téléphones différents.
  3. Essayez à la distance réelle et dans la lumière réelle.
  4. Si la lecture est lente ou incertaine, agrandissez le code ou raccourcissez son contenu.

Astuce

La meilleure façon de gagner de la place est de raccourcir le contenu. Un lien court donne un code plus gros et plus facile à lire sur la même surface. Exportez toujours l'image en grande taille, pour ne pas la déformer en l'agrandissant.

Questions fréquentes

Peut-on réduire un QR code autant qu'on veut ?

Non. Quand les petits carrés deviennent trop fins pour l'impression ou pour l'appareil photo, le code ne se lit plus.

Pourquoi faut-il une marge autour du code ?

La marge de 4 modules aide le téléphone à repérer où commence le code.

Comment savoir si ma taille est bonne ?

Imprimez un essai et scannez-le avec plusieurs téléphones, à la distance et dans la lumière réelles.
