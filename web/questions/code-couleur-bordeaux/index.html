Quel est le code couleur du bordeaux ?

Le bordeaux n'a pas de code officiel : les couleurs CSS les plus proches sont maroon (#800000) et darkred (#8B0000).

Mis à jour le 26/11/2026.

Les couleurs CSS les plus proches

Le CSS ne connaît pas de couleur nommée « bordeaux ». Voici les couleurs nommées qui s'en approchent le plus :

Nom CSS le plus procheHEXRGBHSL
maroon#800000rgb(128, 0, 0)hsl(0, 100%, 25%)
darkred#8B0000rgb(139, 0, 0)hsl(0, 100%, 27%)
brown#A52A2Argb(165, 42, 42)hsl(0, 59%, 41%)

Le CMJN n'est pas affiché ici : sans code de départ, il n'aurait pas de sens. Pour une couleur donnée, le CMJN réel dépend de l'imprimeur, du papier et de l'encre.

Pourquoi pas de code officiel ?

Le bordeaux est un rouge sombre, tirant vers le violet, comme le vin dont il porte le nom. Aucune norme ne fixe sa valeur : chaque nuancier de peinture, chaque fabricant et chaque charte graphique a sa propre référence. Un code trouvé sur un site n'est donc qu'une proposition parmi d'autres.

En CSS, maroon est un rouge foncé sans autre teinte, que l'on traduit souvent par bordeaux ; darkred est un peu plus vif ; brown est plus brun. Pour une correspondance avec un objet réel (un tissu, une peinture, un logo), partez de la référence du fabricant ou d'un échantillon, et utilisez notre outil pour convertir son code dans les autres écritures.

Teintes voisines de maroon

Plus clair de 20 % : #993333. Plus foncé de 20 % : #660000. Ces valeurs sont calculées pour maroon (#800000), pas pour un « vrai » bordeaux.

Est-ce lisible en texte ?

Un texte normal demande au moins 4,5:1 de contraste (niveau AA des règles WCAG 2.2).

Couleur du texteSur fond blancSur fond noir
maroon10,94:1 (AA)1,91:1 (insuffisant)
darkred10,01:1 (AA)2,09:1 (insuffisant)
brown7,08:1 (AA)2,96:1 (insuffisant)

Questions fréquentes

Quel est le code HEX du bordeaux ?

Il n'y en a pas d'officiel. La couleur CSS la plus proche est maroon, #800000, ou darkred, #8B0000. Chaque nuancier a sa référence.

Maroon veut-il dire marron ?

Non : en anglais, maroon désigne un rouge foncé, proche du bordeaux. Le marron est brown ou saddlebrown.
