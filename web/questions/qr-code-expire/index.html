Un QR code a-t-il une date d'expiration ?

Un QR code statique n'expire jamais, car il contient l'information elle-même ; seul un QR code dynamique peut cesser de marcher, si le service qui le gère s'arrête ou si l'abonnement prend fin.

Mis à jour le 26/11/2026.

Un QR code n'est qu'un dessin qui représente du texte, par exemple une adresse web. Un dessin ne vieillit pas et n'a pas de date de fin. Quand un QR code « expire », c'est toujours à cause de ce qu'il y a derrière.

Les trois cas

SituationLe code marche-t-il encore ?
Code statique vers une page qui existeOui, sans limite de durée
Code statique vers une page supprimée ou déplacéeIl se scanne, mais la page n'existe plus
Code dynamique dont l'abonnement est finiNon : le service ne redirige plus

Le cas du code dynamique

Un code dynamique contient l'adresse courte d'un service. Le service redirige vers votre lien. Si vous cessez de payer, ou si le service ferme, la redirection s'arrête. Le code est toujours lisible, mais il ne mène plus où vous voulez. C'est pour cela que certains QR codes « gratuits » cessent de marcher après un essai.

Le cas de la page qui disparaît

Même un code statique devient inutile si le lien change. Si votre site déménage ou si vous supprimez la page, le code mène à une erreur. Avant d'imprimer en grande quantité, choisissez une adresse que vous garderez longtemps.

Autres causes de problème

  • Un code abîmé, taché ou trop petit se lit mal : ce n'est pas une expiration, mais le résultat est le même.
  • Un code décoloré ou avec peu de contraste peut devenir difficile à lire.

Que faire ?

Pour ce qui doit durer, créez un code statique vers une adresse stable, gardez l'image d'origine, et testez de temps en temps avec un téléphone. Notre outil ne crée que des codes statiques : ils ne dépendent d'aucun abonnement.

Questions fréquentes

Pourquoi mon QR code ne marche-t-il plus ?

Soit il était dynamique et le service s'est arrêté, soit la page visée n'existe plus, soit l'image est abîmée ou trop petite.

Peut-on prolonger un QR code expiré ?

Chez le service d'origine, en renouvelant l'abonnement. Sinon, il faut créer un nouveau code statique.

Un QR code Wi-Fi expire-t-il ?

Non : il contient le nom et le mot de passe. Il cesse de servir seulement si vous changez le mot de passe du réseau.
