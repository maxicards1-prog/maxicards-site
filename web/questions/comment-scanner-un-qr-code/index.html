Comment scanner un QR code avec son téléphone ?

Ouvrez l'appareil photo, visez le QR code et touchez la proposition qui s'affiche : sur iPhone, c'est possible depuis iOS 11, et sur Android c'est l'appareil photo ou Google Lens selon le modèle.

Mis à jour le 26/11/2026.

Scanner un QR code ne demande ni appli spéciale ni réglage compliqué dans la plupart des cas. Le téléphone lit le dessin et vous propose d'ouvrir ce qu'il contient.

iPhone

L'appareil photo lit les QR codes depuis iOS 11. Ouvrez-le, cadrez le code dans l'image, attendez que le téléphone le reconnaisse, puis touchez la bulle qui apparaît.

Android

Selon le modèle, c'est l'appareil photo ou Google Lens qui lit le code. Essayez d'abord l'appareil photo. Si rien ne se passe, ouvrez Google Lens. L'emplacement exact des options varie d'une marque et d'une version à l'autre.

Depuis une image sur l'écran

Si le QR code est dans une capture d'écran ou une photo, certains téléphones savent le lire depuis la galerie. Sinon, utilisez un second appareil pour le viser. Ce n'est pas disponible partout : cela dépend du modèle.

Pour bien réussir

  • Gardez le code entier à l'écran, sans le couper.
  • Tenez le téléphone stable, dans une bonne lumière.
  • Évitez les reflets sur le papier brillant ou sur un écran.
  • Laissez de la marge blanche autour du code.

Soyez prudent

Avant d'ouvrir, lisez l'adresse affichée par le téléphone. Si elle semble étrange, n'ouvrez pas. Ne saisissez jamais de mot de passe ou de numéro de carte sur une page ouverte depuis un code dont vous ne connaissez pas la source.

Questions fréquentes

Faut-il une appli pour scanner un QR code ?

Souvent non : l'appareil photo des iPhone (depuis iOS 11) lit les codes, et sur Android c'est l'appareil photo ou Google Lens selon le modèle.

Mon téléphone ne lit pas le code, que faire ?

Améliorez la lumière, éloignez ou rapprochez le téléphone, vérifiez que le code est entier et essayez l'autre mode de lecture.

Un QR code peut-il être dangereux ?

Il peut mener à une fausse page. Lisez toujours l'adresse avant d'ouvrir.
