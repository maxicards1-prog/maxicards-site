Comment créer un QR code gratuit et illimité ?

Pour créer un QR code gratuit et illimité, choisissez un QR code statique : le lien ou le texte est écrit dans l'image elle-même, donc il ne dépend d'aucun abonnement et ne s'arrête jamais.

Mis à jour le 26/11/2026.

Un QR code statique contient l'information elle-même. Il n'y a pas de serveur au milieu, donc pas de compteur de scans, pas de date de fin et pas de limite. Une fois l'image enregistrée, elle fonctionne aussi longtemps que votre lien existe.

Les étapes

  1. Choisissez le type de contenu : un lien, un texte, un réseau Wi-Fi ou un contact.
  2. Collez ou tapez le contenu. Pour un lien, copiez l'adresse complète, avec https://.
  3. Regardez le QR code qui s'affiche en direct.
  4. Téléchargez l'image et gardez-en une copie.
  5. Testez avec votre téléphone avant d'imprimer ou de publier.

Pourquoi certains services demandent de payer

Beaucoup de sites proposent des QR codes « gratuits » qui sont en fait dynamiques : le code contient une adresse courte qui passe par leur serveur. Tant que vous payez, le lien fonctionne. Quand l'essai ou l'abonnement s'arrête, le code ne mène plus nulle part. Un code statique évite ce piège.

Un exemple

Vous voulez un QR code vers votre page de menu. Collez l'adresse de la page, téléchargez l'image, imprimez-la. Si un jour la page change d'adresse, il faudra refaire le code : c'est la seule contrainte d'un code statique.

Dans notre outil, tout se passe dans votre navigateur : rien n'est envoyé ni enregistré, et l'image n'a pas de filigrane.

Questions fréquentes

Y a-t-il une limite de scans ?

Pas pour un QR code statique : l'image contient l'information, personne ne compte les scans.

Faut-il créer un compte ?

Non. Vous collez le contenu et vous téléchargez l'image.

Mon QR code peut-il s'arrêter de marcher ?

Un code statique ne s'arrête pas lui-même. Il cesse d'être utile seulement si la page vers laquelle il pointe disparaît.
