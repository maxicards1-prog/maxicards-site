Comment créer un QR code pour les avis Google ?

Pour créer un QR code d'avis Google, copiez le lien d'avis de votre fiche d'établissement, collez-le dans un générateur de QR code, téléchargez l'image et testez-la avec un téléphone.

Mis à jour le 26/11/2026.

Un QR code d'avis n'a rien de magique : c'est un QR code vers un lien. Votre travail consiste à obtenir le bon lien, celui qui ouvre la page où le client écrit son avis.

Étape 1 : trouver le lien d'avis

Depuis votre compte gestionnaire de la fiche d'établissement, cherchez l'option qui permet de partager ou de demander des avis. Elle fournit un lien à copier. Le nom exact du bouton et sa place changent selon les versions et les pays : regardez ce que propose votre compte et copiez le lien de demande d'avis, pas celui de la simple page de présentation.

Étape 2 : créer le QR code

Collez ce lien dans l'outil, vérifiez que le code s'affiche, puis téléchargez l'image. Un code statique convient très bien : le lien d'avis d'une fiche ne change pas.

Étape 3 : tester

Scannez le code avec votre téléphone. Vous devez arriver sur la page d'avis de votre établissement. Testez aussi avec un autre téléphone, et si possible hors de votre compte, car certaines pages se présentent autrement quand on est connecté.

Où mettre le code

  • Sur le comptoir, près de la caisse ou sur la table.
  • Sur le ticket, la facture ou la carte de visite.
  • Sur un petit panneau avec une phrase claire, par exemple « Votre avis nous aide ».

Quelques conseils

  • Imprimez le code assez grand et sur fond clair.
  • Demandez un avis honnête : les règles des plateformes interdisent en général d'acheter des avis ou d'en filtrer.
  • Gardez l'image d'origine pour pouvoir la réimprimer.

Questions fréquentes

Où trouver le lien d'avis de ma fiche ?

Dans votre compte gestionnaire de la fiche, à l'endroit où l'on peut demander des avis. L'emplacement exact dépend de la version et du pays.

Le QR code d'avis coûte-t-il quelque chose ?

Non. Un code statique créé dans notre outil est gratuit et sans limite.

Faut-il un QR code dynamique pour les avis ?

Non, sauf si vous voulez des statistiques. Le lien d'avis d'une fiche reste le même, un code statique suffit.
