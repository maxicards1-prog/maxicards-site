QR code carte de visite

Adresses web seulement (http ou https). Sans « https:// », il est ajouté tout seul.

Le texte apparaît tel quel sur le téléphone qui lit le code.

Exactement comme il s'affiche, majuscules comprises.

Il reste sur votre ordinateur : il n'est envoyé nulle part.

Avec l'indicatif (+33…) si le code sert hors de France. Les espaces sont retirés.

    Ce que contient le code : une vCard
    

    Le code renferme une fiche de contact au format vCard 3.0, décrit par la RFC 2426. C'est le format que les carnets d'adresses savent importer. Quand on scanne le code, le téléphone propose « Ajouter aux contacts » : le nom, le numéro, l'e-mail et l'adresse sont déjà remplis.
    

    Exemple de fiche, ligne par ligne :
    

    BEGIN:VCARD
VERSION:3.0
N:Dupont;Marie;;;
FN:Marie Dupont
TEL;TYPE=CELL:+33 6 00 00 00 00
END:VCARD
    

    Les virgules et les points-virgules de vos textes sont précédés d'une barre oblique inverse, comme le demande la norme : une entreprise « Durand, père et fils » reste écrite d'un seul tenant.
    

    Moins de champs, meilleur code
    

    Chaque champ ajouté rend le code plus dense, donc plus petit à l'impression et plus lent à lire. Sur une carte de visite, l'essentiel suffit : nom, téléphone, e-mail, site. L'adresse postale n'est utile que si l'on doit venir vous voir.
    

      

    • Téléphone : écrivez l'indicatif (+33…) si vos contacts sont à l'étranger.
      • 

    • Site web : une adresse courte donne un code plus simple.
      • 

    • Niveau de correction : M convient presque toujours. Montez à Q pour une carte qui va traîner dans les poches.
      • 

    

    Bien l'imprimer sur une carte de visite
    

    Le code doit garder sa marge blanche de 4 modules et un bon contraste : un code noir sur fond blanc est le plus sûr. Envoyez le SVG à l'imprimeur : il reste net à toutes les tailles. Testez une carte imprimée avec deux téléphones avant de lancer tout le tirage.
    

    Le PNG sert pour une signature d'e-mail, une présentation ou un badge. Pour le convertir, utilisez PNG en JPG ou PNG en PDF.
    

    Si vos coordonnées changent
    

    Le code est statique : il garde les coordonnées du jour où il a été créé, pour toujours. Si vous changez de numéro, il faut refaire le code et réimprimer. Si vos coordonnées changent souvent, une autre solution consiste à mettre dans le code l'adresse d'une page de votre site qui présente vos coordonnées à jour : utilisez alors le type « Lien » de l'outil.
    

    Confidentialité
    

    Vos coordonnées ne sont envoyées nulle part : le code est calculé dans votre navigateur. Rien n'est enregistré, rien n'est écrit dans l'adresse de la page.

    Questions fréquentes
    Le contact s'ajoute-t-il directement au téléphone ?
    Le téléphone affiche la fiche et propose de l'ajouter aux contacts : la personne confirme d'un geste. Rien n'est ajouté sans son accord.
    Quels champs dois-je remplir ?
    Seulement ceux que vous voulez partager. Un nom et un téléphone suffisent. Moins il y a de texte, plus le code est simple à lire.
    Pourquoi le format vCard 3.0 ?
    C'est un format de fiche de contact décrit par la RFC 2426, que les carnets d'adresses savent importer.
    Puis-je mettre ce QR code sur ma carte de visite imprimée ?
    Oui. Téléchargez le SVG pour l'imprimeur, gardez la marge blanche et testez une carte avant le tirage complet.
