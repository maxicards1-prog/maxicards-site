Que sont les noms de couleurs CSS ?

Le CSS, le langage qui met en forme les pages web, comprend 148 noms de couleurs en anglais : tomato, navy, gold, rebeccapurple… On peut les écrire à la place d'un code HEX : color: tomato; revient à color: #FF6347;. La liste est fixée par la norme CSS Color Module Level 4 du W3C. Les noms ne sont pas sensibles à la casse.

Les pièges à connaître

  • Vert : green est #008000, un vert foncé. Le vert vif s'appelle lime (#00FF00).
  • Marron et bordeaux : brown est #A52A2A, et le mot anglais maroon, que l'on traduit parfois par marron, désigne en fait un bordeaux foncé (#800000).
  • Gris : gray et grey sont acceptés et identiques. darkgray est plus clair que gray.
  • Doublons : aqua et cyan ont le même code, comme fuchsia et magenta, et les variantes gray et grey.
  • transparent et currentcolor sont des mots-clés du CSS, mais ne font pas partie des 148 couleurs nommées de ce tableau.

Utiliser le tableau

Le champ de filtre cherche dans le nom, dans le code et dans la famille. La colonne « Famille » est une indication calculée à partir de la teinte : une couleur à la limite de deux familles peut être classée de façon discutable. Sélectionnez un code dans le tableau pour le copier. Pour une couleur qui n'a pas de nom, le code couleur indique le nom le plus proche.

Nom ou code ?

Un nom est facile à retenir, mais il ne couvre que 148 couleurs sur 16 777 216 possibles. Pour une marque, un site ou un document, le code HEX est plus précis et reste le même partout. Si un code vous est donné en RGB, le convertisseur HEX en RGB le traduit. Pour choisir des couleurs qui vont ensemble, voir la palette de couleurs.

Questions fréquentes

Combien y a-t-il de couleurs nommées en CSS ?

148 noms dans la norme CSS Color Module Level 4 du W3C, dont rebeccapurple.

Quel est le code de la couleur green en CSS ?

#008000, un vert foncé. Le vert vif, #00FF00, s'appelle lime.

Gray et grey sont-ils différents ?

Non : les deux écritures donnent le même gris, #808080.

Les noms de couleurs sont-ils sensibles à la casse ?

Non. Tomato, TOMATO et tomato désignent la même couleur.
