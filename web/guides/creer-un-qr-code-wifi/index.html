Créer un QR code Wi-Fi pour vos invités

Un QR code Wi-Fi évite de dicter un long mot de passe. L'invité scanne, puis se connecte. Voici comment le créer et l'afficher sans risque.

Mis à jour le 26/11/2026.

Pour le faire directement : QR code Wi-Fi

La méthode en 5 étapes

  1. Relevez le nom du réseau : C'est le nom exact (SSID) que vos invités voient dans la liste des réseaux, majuscules comprises.
  2. Choisissez le type de sécurité : WPA ou WPA2 pour la plupart des box. Réseau sans mot de passe : « aucune ».
  3. Saisissez le mot de passe : Tapez-le dans l'outil. Il reste dans votre navigateur et n'est pas envoyé.
  4. Téléchargez et imprimez : Mettez le code dans un cadre, avec le nom du réseau écrit à côté.
  5. Testez avec un téléphone : Scannez-le avec un appareil qui n'est pas encore connecté, puis vérifiez l'accès à Internet.

Ce que contient un QR code Wi-Fi

Un QR code Wi-Fi n'est pas une image magique. C'est du texte, écrit dans un format reconnu par les téléphones. Il a cette forme : WIFI:T:WPA;S:nom;P:motdepasse;;. Chaque lettre suivie de deux-points est un champ.

ChampRôleExemple
TType de sécuritéWPA
SNom du réseauMaisonWifi
PMot de passe(le vôtre)
HRéseau masqué : true si ouitrue

Le téléphone lit ce texte et propose de rejoindre le réseau. L'invité n'a rien à taper. Le format est décrit dans la documentation du projet ZXing, utilisée par de nombreux lecteurs.

Les caractères spéciaux

Certains signes ont un rôle dans le format : la barre oblique inverse, le point-virgule, la virgule, les deux-points et les guillemets. Si votre nom de réseau ou votre mot de passe en contient, il faut les faire précéder d'une barre oblique inverse. Notre outil le fait pour vous. C'est l'une des raisons de ne pas écrire le texte à la main : une seule erreur et le téléphone n'arrive pas à se connecter.

Quel type de sécurité choisir

  • WPA : le bon choix pour la plupart des box récentes, y compris en WPA2.
  • Aucune : un réseau ouvert, sans mot de passe. À réserver à un lieu où l'on accepte que tout le monde se connecte.
  • WEP : un ancien mode, jugé fragile. Si votre box l'utilise, il vaut mieux la reconfigurer.

En cas de doute, regardez l'étiquette de la box ou son interface d'administration.

Votre mot de passe reste chez vous

Quand vous saisissez le mot de passe dans notre outil, le code est fabriqué dans votre navigateur. Rien n'est envoyé, rien n'est enregistré, et l'adresse de la page ne contient jamais le mot de passe. Fermez la page et il disparaît.

Gardez en tête que le code contient le mot de passe en clair. Toute personne qui scanne le code peut le lire, même si elle n'a pas besoin de le taper. Le code ne rend donc pas le mot de passe secret ; il le rend simplement plus pratique à partager.

Imprimer pour des invités

  • Mettez le code dans un cadre, près de l'endroit où l'on s'installe : salon, chambre d'amis, comptoir.
  • Écrivez le nom du réseau à côté, en toutes lettres, au cas où le scan échoue.
  • Préférez un motif foncé sur fond clair, avec une marge blanche tout autour. Voir imprimer un QR code lisible.
  • Pour un lieu ouvert au public, un réseau « invité » séparé du réseau principal est une bonne habitude, si votre box le permet.

Si le code ne marche pas

Vérifiez d'abord le mot de passe, majuscules et minuscules comprises. Contrôlez ensuite le type de sécurité. Si vous avez changé le mot de passe de la box, l'ancien code ne fonctionne plus : il faut en créer un nouveau et réimprimer.

Un mot sur la sécurité du réseau

Un code collé sur un mur peut être photographié par n'importe qui qui passe devant. Si le réseau donne accès à vos appareils personnels, mieux vaut ne pas le partager de cette façon. Un réseau pour les invités, séparé du réseau principal, limite ce que les visiteurs peuvent atteindre. Pensez aussi à changer le mot de passe de temps en temps, surtout après un événement avec beaucoup de monde.

Enfin, choisissez un mot de passe assez long. Puisque personne n'a plus à le taper, vous pouvez en prendre un solide sans gêner vos invités : c'est un des vrais avantages du QR code.

Un petit plus pour les visiteurs

Ajoutez sous le code une phrase simple : « Scannez avec l'appareil photo de votre téléphone ». Les personnes moins à l'aise avec la technique n'osent pas toujours essayer sans indication.

Questions fréquentes

Le QR code Wi-Fi marche-t-il sur tous les téléphones ?

La plupart des téléphones récents lisent ce format avec l'appareil photo. Sur certains modèles Android, c'est Google Lens qui s'en charge.

Mon mot de passe est-il envoyé quelque part ?

Non. Le code est créé dans votre navigateur, sans envoi ni enregistrement.

Quelqu'un peut-il lire le mot de passe dans le code ?

Oui. Le code contient le mot de passe en clair. Ne l'affichez qu'à des personnes à qui vous acceptez de le donner.

Que faire si je change le mot de passe de la box ?

Créez un nouveau code avec le nouveau mot de passe et remplacez l'ancien.
