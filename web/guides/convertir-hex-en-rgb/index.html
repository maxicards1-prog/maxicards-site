Convertir un code HEX en RGB, à la main et avec l'outil

Un code comme #FF5733 se lit en trois paires de chiffres. Voici la méthode pour le convertir en RGB, et l'inverse, avec des exemples calculés.

Mis à jour le 26/11/2026.

Pour le faire directement : HEX en RGB · Code couleur

La méthode en 5 étapes

  1. Retirez le dièse et coupez en trois paires : #FF5733 devient FF, 57 et 33 : rouge, vert, bleu.
  2. Convertissez chaque chiffre en nombre : 0 à 9 restent tels quels ; A = 10, B = 11, C = 12, D = 13, E = 14, F = 15.
  3. Appliquez la formule 16 × a + b : Pour la paire « ab », multipliez le premier chiffre par 16 et ajoutez le second.
  4. Écrivez le résultat : Les trois nombres, entre 0 et 255, donnent rgb(255, 87, 51).
  5. Contrôlez avec l'outil : Saisissez le code dans l'outil : il affiche les trois nombres et un aperçu de la couleur.

Ce que veut dire un code HEX

Un code comme #FF5733 est une façon d'écrire une couleur d'écran. Le dièse annonce un nombre en hexadécimal, un système qui compte en base 16. Après le dièse, six chiffres : deux pour le rouge, deux pour le vert, deux pour le bleu. Chaque paire représente un niveau de 0 à 255. Comme il y a 256 niveaux par canal, cela donne 256 × 256 × 256 = 16 777 216 couleurs possibles.

Les chiffres hexadécimaux

En base 16, il faut seize signes. Les dix chiffres ne suffisent pas, on ajoute donc les lettres A à F.

LettreABCDEF
Valeur101112131415

Les minuscules valent les majuscules : #ff5733 et #FF5733 sont la même couleur.

La formule : 16 × a + b

Pour une paire « ab », le premier chiffre compte seize fois, le second une fois. Prenons « 57 » : 16 × 5 + 7 = 80 + 7 = 87. Prenons « FF » : F vaut 15, donc 16 × 15 + 15 = 240 + 15 = 255. C'est le maximum d'un canal. « 00 » donne 0, le minimum.

Trois exemples calculés

Code HEXRougeVertBleuRésultat
#FF5733FF → 25557 → 8733 → 51rgb(255, 87, 51)
#1E90FF1E → 3090 → 144FF → 255rgb(30, 144, 255)
#2F4F4F2F → 474F → 794F → 79rgb(47, 79, 79)

Vérifions le deuxième : #1E90FF. Pour « 1E », 16 × 1 + 14 = 30. Pour « 90 », 16 × 9 + 0 = 144. Pour « FF », 255. On obtient rgb(30, 144, 255).

L'inverse : de RGB vers HEX

On divise chaque nombre par 16. Le quotient donne le premier chiffre, le reste donne le second. Exemple avec 87 : 87 ÷ 16 = 5, reste 7, donc « 57 ». Avec 255 : 255 ÷ 16 = 15, reste 15, donc « FF ». Il faut toujours écrire deux chiffres : 9 devient « 09 », pas « 9 ». En assemblant les trois paires, on retrouve #FF5733.

La forme courte : #abc

Quand chaque paire est faite de deux chiffres identiques, on peut abréger. #FFAA00 s'écrit #FA0 : chaque chiffre est doublé pour retrouver la forme longue. Ainsi #09C vaut #0099CC, soit rgb(0, 153, 204). Cette forme ne marche pas pour #FF5733, car « 57 » n'a pas deux chiffres identiques.

Les erreurs fréquentes

  • Oublier que la lettre O n'est pas le chiffre zéro.
  • Lire les paires dans le désordre : l'ordre est toujours rouge, vert, bleu.
  • Dépasser 255 : aucune paire hexadécimale ne peut donner plus.

Pourquoi 255 et pas 100

Un ordinateur stocke chaque canal sur huit bits, c'est-à-dire sur huit petites cases qui valent chacune 0 ou 1. Huit cases donnent 256 combinaisons, de 0 à 255. Deux chiffres hexadécimaux, chacun valant de 0 à 15, couvrent exactement ces 256 valeurs : c'est pour cela que l'hexadécimal est si commode pour les couleurs. Chaque paire correspond pile à un canal.

Pour estimer une couleur de tête, regardez les paires : plus elles sont proches de FF, plus le canal est fort. Un code où les trois paires sont égales, comme #808080, donne toujours un gris.

Un exercice pour s'entraîner

Essayez avec #20B2AA. Pour « 20 » : 16 × 2 + 0 = 32. Pour « B2 » : B vaut 11, donc 16 × 11 + 2 = 178. Pour « AA » : A vaut 10, donc 16 × 10 + 10 = 170. Vous obtenez rgb(32, 178, 170), un vert d'eau. Refaites ensuite le calcul avec l'outil pour contrôler votre résultat.

Questions fréquentes

Que veut dire F dans un code couleur ?

C'est le chiffre 15 en base 16. Deux F, « FF », valent 255 : le maximum pour un canal.

#FFFFFF et #000000, ce sont quelles couleurs ?

#FFFFFF est le blanc (255, 255, 255) et #000000 est le noir (0, 0, 0).

Majuscules ou minuscules ?

C'est la même couleur. Choisissez une écriture et gardez-la dans tout votre projet.

Le HEX et le RGB donnent-ils la même couleur ?

Oui, ce sont deux écritures du même mélange rouge, vert et bleu.
