Vérifier le contraste des couleurs d'un texte (WCAG 2.2)

Un texte gris clair sur fond blanc plaît parfois aux yeux de l'auteur et fatigue tous les autres. Voici comment mesurer le contraste et ce que demandent les règles.

Mis à jour le 26/11/2026.

Pour le faire directement : Contraste de couleurs

La méthode en 5 étapes

  1. Relevez les deux couleurs : Le code HEX du texte et celui du fond.
  2. Saisissez-les dans l'outil : Il calcule le rapport de contraste, de 1:1 à 21:1.
  3. Repérez le type de texte : Texte normal, grand texte (18 pt ou plus, ou 14 pt gras), ou élément d'interface.
  4. Comparez au seuil : 4,5:1 pour le texte normal, 3:1 pour le grand texte et les composants.
  5. Corrigez et recommencez : Foncez le texte ou éclaircissez le fond, puis testez à nouveau.

Pourquoi mesurer le contraste

Le contraste est la différence de luminosité entre le texte et son fond. S'il est trop faible, le texte se lit mal : pour les personnes malvoyantes, mais aussi en plein soleil sur un téléphone, ou sur un écran ancien. Mesurer évite de juger « à l'œil », ce qui est trompeur.

Le rapport de contraste

Les règles d'accessibilité du W3C (WCAG 2.2) donnent un rapport entre deux couleurs. Il va de 1:1 (aucune différence) à 21:1 (noir sur blanc). Le calcul compare la luminance relative des deux couleurs : (L1 + 0,05) ÷ (L2 + 0,05), où L1 est la plus claire. Notre outil le fait pour vous.

Les seuils à connaître

SituationNiveauRapport minimal
Texte normalAA (critère 1.4.3)4,5:1
Grand texteAA (critère 1.4.3)3:1
Composants d'interface et graphiquesAA (critère 1.4.11)3:1
Texte normalAAA (critère 1.4.6)7:1
Grand texteAAA (critère 1.4.6)4,5:1

Le niveau AA est le niveau visé par la plupart des sites. Le niveau AAA est plus exigeant, et le W3C précise qu'il n'est pas réaliste de l'exiger partout.

Qu'est-ce qu'un grand texte

Le grand texte désigne les caractères d'au moins 18 points, ou d'au moins 14 points en gras. Plus le texte est gros, moins il demande de contraste. Pour du texte de taille normale, visez 4,5:1.

Les composants d'interface

Le critère 1.4.11 demande 3:1 pour ce qui sert à utiliser la page : le contour d'un champ, un bouton, une icône, le bord d'une case à cocher. Un champ gris très pâle sur blanc, sans contour visible, passe ce test de justesse ou le rate.

Exemples calculés

CombinaisonRapportTexte normal AA
Noir sur blanc21:1oui
Gris #767676 sur blanc4,54:1oui
Gris #777777 sur blanc4,48:1non
Gris #999999 sur blanc2,85:1non

Le gris #767676 est connu comme l'un des gris les plus clairs qui passent encore le seuil sur fond blanc. Un seul niveau de gris plus clair fait tomber le rapport sous 4,5:1. Cela montre que la limite est étroite : en cas de doute, foncez.

Ce que le rapport ne dit pas

  • Un bon rapport ne remplace pas une taille de texte lisible.
  • Une image de fond derrière du texte change le contraste d'un endroit à l'autre : testez au point le plus défavorable.
  • Le texte purement décoratif, comme un logo, n'est pas soumis à ce critère.
  • Ne donnez jamais une information par la couleur seule : doublez-la d'un mot ou d'un symbole.

Que faire si le contraste est insuffisant

Gardez la teinte, mais assombrissez le texte ou éclaircissez le fond. Un bleu pâle devient un bleu soutenu, sans changer d'identité. Testez ensuite le mode sombre à part : une palette réussie en clair peut échouer en sombre.

Une méthode rapide

Commencez par les textes les plus petits et les plus pâles : légendes, mentions, texte d'aide dans les champs, liens. Ce sont eux qui échouent en premier. Testez ensuite chaque bouton, dans son état normal puis lorsqu'il est survolé ou désactivé. Notez les couples de couleurs validés, et réutilisez-les : un tableau de cinq ou six combinaisons sûres vous évite de retester à chaque page. Ce travail se fait une fois, puis il sert pour tout le projet.

Pensez au mode sombre et aux reflets

Beaucoup de gens lisent leur téléphone dehors, avec des reflets, ou le soir avec un écran très sombre. Un contraste juste au seuil se dégrade dans ces conditions. Si vous le pouvez, visez un peu au-dessus du minimum pour garder de la marge.

Questions fréquentes

Quel contraste faut-il pour un texte normal ?

Au moins 4,5:1 pour le niveau AA de WCAG 2.2.

Le noir sur blanc est-il le meilleur choix ?

C'est le plus fort contraste, 21:1. Beaucoup préfèrent un gris très foncé pour limiter l'éblouissement.

Les boutons et les icônes sont-ils concernés ?

Oui. Le critère 1.4.11 demande 3:1 pour les composants d'interface et les éléments graphiques utiles.

Le contraste suffit-il pour être accessible ?

Non. C'est un point parmi d'autres : taille du texte, navigation au clavier, textes alternatifs.
