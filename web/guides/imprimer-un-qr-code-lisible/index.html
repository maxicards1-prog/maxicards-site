Imprimer un QR code lisible : marge, contraste et taille

Un QR code mal imprimé ne se lit pas. Marge, contraste, taille et format de fichier : voici les points à contrôler avant d'envoyer à l'imprimeur.

Mis à jour le 26/11/2026.

Pour le faire directement : Générateur de QR code

La méthode en 5 étapes

  1. Gardez la marge blanche : Laissez autour du code un blanc d'au moins 4 modules, la zone de silence. Ne la rognez pas.
  2. Soignez le contraste : Motif foncé sur fond clair. Évitez deux couleurs proches ou un fond chargé.
  3. Choisissez le niveau de correction : Le niveau M est un bon départ. Augmentez-le si le support risque d'être abîmé.
  4. Donnez le bon fichier : SVG ou PNG de grande taille à l'imprimeur, jamais une capture d'écran réduite.
  5. Testez avant la série : Imprimez un exemplaire, scannez-le avec plusieurs téléphones, puis lancez le reste.

Le module : l'unité de mesure d'un QR code

Un QR code est une grille de petits carrés appelés modules. La plus petite version compte 21 modules de côté ; la plus grande en compte 177. Entre les deux, chaque nouvelle version ajoute 4 modules par côté. Plus vous mettez de données, plus la version monte et plus les modules deviennent petits à taille égale.

La marge de 4 modules

La norme demande autour du code un espace vide de 4 modules, appelé zone de silence. Il sert à isoler le code du reste de la page. Sans lui, le lecteur peut confondre le bord du code avec un texte ou une image voisine. Quand vous placez le code sur une affiche, ne le collez donc pas à un bord ni à un dessin.

Le contraste

Les lecteurs cherchent des carrés foncés sur un fond clair. Le noir sur blanc est le choix le plus sûr. Une couleur sombre sur un fond très clair fonctionne aussi. Évitez le motif clair sur fond foncé, qui n'est pas lu par tous les lecteurs, et les couleurs proches comme un gris sur un beige. Pour mesurer un contraste, voir le guide vérifier le contraste des couleurs.

Le niveau de correction d'erreurs

Un QR code contient de la redondance : il peut rester lisible même si une partie est abîmée ou cachée. Quatre niveaux existent.

NiveauPart du code récupérable (environ)Quand l'utiliser
L7 %Support propre, code simple
M15 %Usage courant
Q25 %Support exposé
H30 %Support abîmé, ou petit logo au centre

Un niveau élevé rend le code plus résistant, mais aussi plus dense : à contenu égal, les modules sont plus petits. Il faut donc choisir selon l'usage, pas toujours le maximum.

La taille : prudence

La bonne taille dépend du contenu, de la distance de lecture et du téléphone. Vous entendrez des règles du genre « la largeur du code doit valoir tant de fois la distance de lecture ». Prenez-les comme des repères courants, pas comme des garanties. La seule vraie méthode est l'essai : imprimez, posez à l'endroit prévu, scannez de la distance réelle. Si la lecture est lente ou échoue, agrandissez le code ou raccourcissez l'adresse.

PNG ou SVG : quel fichier donner

  • SVG : une image vectorielle, qui s'agrandit sans flou. C'est le meilleur choix pour un imprimeur ou une grande affiche.
  • PNG : une image faite de pixels. Elle convient à l'écran et aux petits documents. Prenez-la grande, car l'agrandir plus tard rend les bords flous.

Si votre imprimeur demande un PDF, vous pouvez passer d'une image à un PDF avec l'outil PNG en PDF.

Les supports difficiles

Un verre, une bouteille, un tissu ou un métal brillant déforment ou reflètent le code. Dans ces cas, choisissez un niveau de correction plus élevé, un grand format et testez sur le vrai support avant de commander en série.

La liste de contrôle avant la série

  • La marge blanche est entière.
  • Le contraste est fort.
  • L'adresse affichée par le téléphone est la bonne.
  • Le code se lit sur au moins deux téléphones différents.
  • Le premier exemplaire a été imprimé et testé tel qu'il sera diffusé.

Un exemple concret

Vous préparez des cartes de visite avec un QR code vers votre site. Vous créez le code avec une adresse courte, vous le téléchargez en SVG, vous le placez avec une marge blanche confortable et vous envoyez le fichier à l'imprimeur. Avant de commander mille cartes, vous demandez une seule épreuve. Vous la scannez avec votre téléphone, celui d'un proche et un modèle plus ancien. Si l'un des trois hésite, vous agrandissez le code ou vous raccourcissez l'adresse, puis vous recommencez l'essai.

Cette petite vérification coûte quelques minutes et évite de jeter toute une série.

Un dernier point : le sens du support

Un code collé sur une surface courbe, plissée ou posée en biais est plus difficile à lire. Choisissez une surface plane, bien éclairée, et placez le code à hauteur de main plutôt qu'au ras du sol.

Questions fréquentes

Quelle taille minimale pour un QR code imprimé ?

Il n'y a pas de chiffre universel. Cela dépend du contenu et de la distance de lecture. Faites un essai à la distance réelle.

Puis-je mettre un logo au centre ?

C'est possible avec un niveau de correction élevé, mais cela cache une partie du code. Testez toujours le résultat.

Pourquoi mon code ne se lit pas sur l'affiche ?

Les causes fréquentes : marge trop étroite, contraste faible, code trop petit ou adresse trop longue.

SVG ou PNG pour l'imprimeur ?

Le SVG, s'il l'accepte : il reste net à toutes les tailles. Sinon, un PNG de grande taille.
