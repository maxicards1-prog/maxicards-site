Créer un QR code gratuit, sans inscription

Un QR code se crée en quelques clics. Voici comment bien choisir son contenu, éviter les pièges et vérifier le résultat avant de l'afficher.

Mis à jour le 26/11/2026.

Pour le faire directement : Générateur de QR code

La méthode en 5 étapes

  1. Choisissez ce que le code doit contenir : Une adresse de site, un texte, un réseau Wi-Fi ou une fiche de contact. Plus le contenu est court, plus le code reste simple à lire.
  2. Saisissez le contenu dans l'outil : Collez l'adresse complète, avec le début « https:// ». Le code se met à jour en direct.
  3. Choisissez les couleurs et le niveau de correction : Gardez un motif foncé sur un fond clair. Le niveau M convient à la plupart des usages.
  4. Téléchargez l'image : PNG pour un écran ou un document, SVG si l'on veut l'agrandir sans perte.
  5. Testez avec deux téléphones : Scannez le code avec l'appareil photo, vérifiez l'adresse affichée, puis seulement ensuite diffusez-le.

Ce qu'est un QR code

Un QR code est un carré de petits points noirs et blancs. Il a été inventé en 1994 par l'entreprise japonaise Denso Wave. « QR Code » est une marque déposée de DENSO WAVE INCORPORATED ; le format est décrit par la norme ISO/IEC 18004. Le téléphone le lit avec son appareil photo et affiche ce qu'il contient : une adresse, un texte, un réseau Wi-Fi, un contact.

Notre outil est gratuit, sans inscription et sans limite. Tout se passe dans votre navigateur : ce que vous saisissez n'est pas envoyé.

Statique ou dynamique : la différence qui compte

C'est la question la plus importante avant de créer un code. Un QR code statique contient l'information elle-même. Il n'expire jamais et ne dépend de personne. Un QR code dynamique contient l'adresse courte d'un service, qui redirige ensuite vers votre contenu. Il permet de changer la destination plus tard, mais il cesse de marcher si le service s'arrête ou si l'abonnement prend fin.

Notre générateur crée des codes statiques. Si vous imprimez un code sur un support durable, c'est le choix le plus sûr.

Que mettre dans le code

  • Une adresse de site : écrivez-la en entier, avec « https:// ».
  • Un texte libre : un message court, un numéro de référence.
  • Un réseau Wi-Fi : voir le guide créer un QR code Wi-Fi.
  • Une fiche de contact : nom, téléphone, courriel, au format vCard.

Plus il y a de données, plus le carré compte de petits points. À taille égale, chaque point devient plus petit et le code plus difficile à lire. Une adresse courte donne donc un code plus lisible qu'une adresse très longue.

Les erreurs à éviter

  • Une adresse qui change : si le site déménage, le code imprimé ne mène plus nulle part.
  • Un contraste faible : un motif clair sur fond foncé ou deux couleurs proches se lisent mal.
  • Un code trop petit : voir imprimer un QR code lisible.
  • Un code jamais testé : un essai prend dix secondes.

Vérifier l'adresse avant d'ouvrir un code

Un code collé sur une affiche ou reçu dans un message peut mener vers un faux site. Cette fraude s'appelle l'hameçonnage par QR code, ou « quishing ». Le réflexe est simple : regardez l'adresse que le téléphone affiche avant d'ouvrir. Si elle ne correspond pas à ce que vous attendez, n'ouvrez pas.

Quel téléphone peut le lire

L'appareil photo de l'iPhone lit les QR codes depuis iOS 11. Sur Android, l'appareil photo ou Google Lens s'en charge selon le modèle. Il n'y a rien à installer dans la plupart des cas.

Une méthode en cinq minutes

Commencez par écrire en une phrase ce que la personne doit trouver en scannant : une page de menu, un formulaire, un horaire. Si vous n'arrivez pas à le dire simplement, le code sera sans doute inutile. Ensuite, ouvrez l'adresse vous-même dans un navigateur pour vérifier qu'elle fonctionne, sans faute de frappe. Créez le code, téléchargez-le, puis scannez-le sur votre écran avec un téléphone. Enfin, imaginez l'endroit où il sera affiché : une personne pressée, debout, avec un téléphone d'ancienne génération ? Si oui, faites-le plus grand et plus simple.

Pensez aussi à ce qui se passe après le scan. Une page qui s'ouvre lentement ou qui n'est pas adaptée au téléphone fait perdre le lecteur, même si le code est parfait.

Garder une trace

Conservez le fichier du code et notez ce qu'il contient, avec la date. Dans un an, vous ne vous souviendrez plus de l'adresse encodée, et vous serez content de la retrouver sans avoir à scanner.

Questions fréquentes

Un QR code gratuit expire-t-il ?

Un code statique n'expire jamais, car il contient l'information elle-même. Un code dynamique dépend du service qui redirige : il s'arrête avec lui.

Faut-il créer un compte ?

Non. L'outil fonctionne sans inscription, et ce que vous saisissez reste dans votre navigateur.

Puis-je utiliser le code sur un document imprimé ?

Oui. Choisissez un fort contraste, une taille suffisante et testez une première impression avant d'en faire beaucoup.

Comment savoir si un QR code est sûr ?

Regardez l'adresse que le téléphone propose d'ouvrir. Ne continuez pas si elle semble étrange ou ne correspond pas à l'émetteur.
