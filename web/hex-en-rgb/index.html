Convertir un HEX en RGB à la main

Un code HEX a six caractères après le dièse : deux pour le rouge, deux pour le vert, deux pour le bleu. Chaque paire est un nombre en base 16, avec les chiffres de 0 à 9 puis les lettres A à F (A = 10, B = 11, jusqu'à F = 15). Pour la convertir : premier caractère × 16, plus le second.

Exemple avec #1E90FF : « 1E » = 1 × 16 + 14 = 30 ; « 90 » = 9 × 16 + 0 = 144 ; « FF » = 15 × 16 + 15 = 255. On obtient rgb(30, 144, 255).

Et dans l'autre sens : RGB en HEX

Divisez chaque nombre par 16. Le quotient est le premier caractère, le reste le second. Pour 144 : 144 ÷ 16 = 9, reste 0, donc « 90 ». Pour 255 : 255 ÷ 16 = 15 (F), reste 15 (F), donc « FF ». Ajoutez un zéro devant si le résultat n'a qu'un caractère : 5 devient « 05 ».

Le code court et les autres écritures

Quand les deux caractères de chaque paire sont identiques, on peut écrire trois caractères : #09c veut dire #0099cc. Le CSS moderne accepte aussi des codes de 4 ou 8 caractères qui ajoutent la transparence ; cet outil lit seulement les codes de 3 ou 6 caractères, ainsi que les écritures rgb() et hsl() et les noms de couleurs. Questions fréquentes

Comment convertir #FF5733 en RGB ?

Convertissez chaque paire : FF = 255, 57 = 87, 33 = 51. Le résultat est rgb(255, 87, 51). L'outil le fait pour vous, en direct.

Les majuscules et les minuscules changent-elles la couleur ?

Non. #FF5733 et #ff5733 sont la même couleur. L'outil affiche les majuscules.

Pourquoi les nombres RGB vont-ils jusqu'à 255 ?

Chaque canal utilise 8 bits, soit 256 valeurs de 0 à 255. En hexadécimal, 255 s'écrit FF, ce qui tient sur deux caractères.

Que se passe-t-il si je tape un nombre trop grand ?

Le nombre est ramené entre 0 et 255. Une saisie qui n'est pas un nombre est signalée.
