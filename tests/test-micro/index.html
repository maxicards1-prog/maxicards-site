Comment faire le test du micro

  1. Cliquez sur « Démarrer le test » et acceptez la demande d'accès au micro.
  2. Si vous avez plusieurs micros, choisissez le bon dans la liste (micro du casque, micro de la webcam, micro de l'ordinateur).
  3. Dites une phrase à voix normale pendant trois secondes. La barre et l'onde bougent, puis le résultat s'affiche : ça marche, ou ça ne marche pas, avec la solution.
  4. Cliquez sur « Enregistrer 5 secondes » pour vous réécouter, comme vos correspondants vous entendent.

Comment lire le résultat

  • Aucun son : le micro est ouvert mais rien n'arrive. Voir micro qui ne marche pas sous Windows 11.
  • Trop faible : la crête reste sous environ -20 dB. Voir micro trop faible.
  • Sature : la crête touche le maximum (0 dB). Voir micro qui sature ou grésille.
  • Bon niveau : entre les deux. Le niveau idéal dépend de l'application ; ce test vérifie surtout que le micro répond et que le son n'est ni trop bas ni écrasé.

Les seuils (silence sous -50 dB, faible sous -20 dB, saturation à -1 dB) sont ceux de ce site : ils servent de repère, ce n'est pas une norme. Les dB sont des dBFS : 0 dB est le maximum que l'on peut enregistrer.

Pourquoi les corrections automatiques sont coupées

Le navigateur peut corriger le son tout seul : réduction du bruit, suppression de l'écho, réglage automatique du volume. Pendant ce test, on les coupe pour voir ce que le micro envoie vraiment. Dans une visio, l'application les active souvent : le son peut donc être un peu meilleur qu'ici.

Si l'accès est refusé

Le message « Accès refusé » veut dire que le navigateur ou le système bloque le micro pour ce site. Suivez Autoriser le micro dans Chrome, Edge ou Firefox. Le message « Appareil déjà utilisé » indique qu'une autre application tient le micro : fermez-la, puis réessayez.

Vie privée

Le micro n'est ouvert qu'après votre clic sur « Démarrer le test ». Le son est mesuré dans votre navigateur et l'enregistrement de 5 secondes reste en mémoire dans l'onglet : il n'est envoyé nulle part et disparaît quand vous fermez la page. Le bouton « Arrêter » coupe l'accès au micro.

Questions fréquentes

Mon micro n'apparaît pas dans la liste, que faire ?

La liste se remplit seulement après l'autorisation. Cliquez sur « Démarrer le test », autorisez le micro, puis ouvrez la liste. Si le micro manque toujours, vérifiez le branchement et les réglages de confidentialité du système.

Le test fonctionne-t-il avec un micro de casque Bluetooth ?

Oui, s'il apparaît dans la liste. Le système peut basculer le casque en mode « mains libres » quand le micro s'ouvre, ce qui baisse parfois la qualité du son : c'est normal.

Mon enregistrement est-il conservé ?

Non. Il reste en mémoire dans l'onglet et disparaît quand vous fermez ou rechargez la page. Rien n'est envoyé.

Pourquoi le test dit « aucun son » alors que mon micro marche ailleurs ?

Le plus souvent, le mauvais micro est choisi, le navigateur n'a pas l'accès, ou une autre application tient le micro. Essayez un autre micro dans la liste.
