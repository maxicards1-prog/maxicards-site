How to test a keyboard

  1. Click “Start test”. From then on the page captures your key presses and blocks their usual action (F5 no longer reloads, Space no longer scrolls) so nothing disturbs the test.
  2. Press every key. Each one lights up blue while it is down, then stays marked in purple to say “this one works”.
  3. Check the “Keys never pressed” list: these are the keys that haven't reacted yet. If a key stays in the list while you press it, it isn't working.
  4. To stop, press Esc twice or click “Stop”.

What the key code means

The code shown (for example KeyQ) names the position of the key on the keyboard, not the letter printed on it. On a French AZERTY keyboard, the key marked A reports the code KeyQ, because it sits where the Q is on a US keyboard. This is how the page can draw the right visual keyboard whatever your layout. QWERTY is the default here; switch to AZERTY if that is what you use.

Rollover and ghosting test

Hold several keys at once, for example W, A, S, D, Shift and Space as in a game, and watch “most at the same time”. If that number is lower than the number of keys you are really holding, the keyboard is not sending all of them. Some budget keyboards only handle a few simultaneous keys. The number depends on the keyboard and its connection.

What this test cannot see

  • Some keys are handled by the operating system before the browser: the Windows key, Print Screen and media keys (volume, brightness) may show nothing.
  • The Fn key on a laptop is usually invisible: it changes what other keys do without sending a signal.
  • On a Mac, the Command key matches the “Win” key drawn here.

Typing the wrong characters? See keyboard typing wrong characters. A key that stopped working? See keyboard key not working and the guide how to clean a keyboard.

Privacy

The test only notes which keys are pressed, in your browser, for as long as the page is open. What you type is not recorded or sent, and the test stops when you leave the page.

Frequently asked questions

How do I know if a key on my keyboard is broken?

Start the test and press the key. If it doesn't light up and stays in the “Keys never pressed” list, it isn't responding. Try it in another program too, because a setting can cause the same symptom.

What is keyboard ghosting?

It's when the keyboard fails to report all the keys held at the same time. The test shows the largest number of keys received together: compare it with the number you are holding.

Why does the A key show the code KeyQ?

The code identifies the physical position of the key. On an AZERTY keyboard, the A key is where the Q sits on a QWERTY keyboard.

Does the test work on a laptop keyboard?

Yes. Choose “Compact laptop” to show only the keys of that type of keyboard. The Fn key and media keys are not always visible to the browser.
