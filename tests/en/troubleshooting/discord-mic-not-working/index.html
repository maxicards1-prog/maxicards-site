Discord not picking up your mic

If your mic works in an online test but not in Discord, pick the right Input Device in Discord's voice settings; if the test fails too, the problem is in your system.

Page updated November 26, 2026.

Separate the app from the system

Start with the mic test in your browser. - The test works: your mic is fine and allowed. The problem is inside Discord's settings. - The test fails: the problem is in the system or the connection. Follow mic not working on Windows 11 or mic not working on Mac.

Settings inside Discord

Discord's help points to User Settings, then Voice & Video. Labels may vary by version, but check these: 1. Input Device. Choose your mic instead of Default if the default is a different device. 2. Input volume. It should not be set to zero. 3. Input mode. Discord offers Voice Activity and Push to Talk. Push to Talk looks like a dead mic if you forget the key. With Voice Activity, a sensitivity setting set too high can cut your voice. 4. Automatic processing. Noise suppression, echo cancellation and automatic gain can interfere. Turn them off for a test. 5. Mic Test. Discord has its own mic test in the voice settings. Discord notes that testing while you are in a voice channel mutes and deafens you until the test ends.

If everything looks right and it still fails, Discord's help suggests the Reset Voice Settings option, which sits under the Voice & Video page in some versions.

Error codes

Discord's guide mentions error 3001 for no microphone detected and 3002 for a mic that is not picking up sound. For 3002, check your system input volume and any mute switch.

System settings

The desktop app needs permission to use the microphone in your system privacy settings. On Windows 11 that is Settings, Privacy & security, Microphone, including Let desktop apps access your microphone. On a Mac it is System Settings, Privacy & Security, Microphone. If you use Discord in a browser, the mic is allowed site by site: see how to allow microphone access.

Another app holds the mic

Depending on the driver, another app can occupy the mic. Close recorders, streaming tools or other call apps, then restart Discord.

Others hear you badly

A mic that is too quiet, clipping or echoing is fixed as anywhere else: mic too quiet, mic distorted or crackling, mic echo.

If it still fails

Restart Discord, then the computer. Unplug and reconnect the device, and check for a hardware mute button. Test the mic in another call app to confirm it works.

This site is not affiliated with Discord, and its menus can change.

Frequently asked questions

Why do people only hear me now and then on Discord?

Voice Activity can cut your voice if its sensitivity is set too high. Lower it, or switch to Push to Talk.

Does the online test replace Discord's own mic test?

It checks the mic and the browser permission. For Discord-specific options, use the voice settings and Mic Test inside Discord.

What do Discord errors 3001 and 3002 mean?

According to Discord's help, 3001 means no microphone was detected and 3002 means the mic is not picking up sound. Check the device selection, input volume and mute switches.
