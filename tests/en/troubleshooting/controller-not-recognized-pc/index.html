Controller not recognized on PC

Press a button on the controller in the gamepad test, because browsers only show it after input; if that fails, change the cable or port, re-pair it or close apps using it.

Page updated November 26, 2026.

Start with a quick test

Open the gamepad test and press several buttons. The Gamepad API that websites use only reports a controller after a first user action. If the page lists your controller, the PC sees it, and any problem lies in a game or launcher.

1. The cable

Many USB cables only charge. Use a data cable, and try a second one if you can. A front-panel port or an unpowered hub can lack power, so try a port on the back of the computer.

2. Bluetooth

  • Is the controller paired and connected, not just paired?
  • Remove it from your PC's Bluetooth devices, then pair it again.
  • A controller can connect to another device first, such as a console or phone. Switch that device off.

For an Xbox controller, hold the Pair button for three seconds, then use Settings > Bluetooth & devices > Add device on Windows 11. See Xbox controller on PC. For a PlayStation controller, see PS5 controller on PC.

3. Software that grabs it

A game launcher, a remapping tool or a remote-play app can take exclusive control of a controller. Close them and restart your browser.

4. The browser

Try another recent browser. A browser extension can interfere. Reload the page after plugging the controller in.

5. The controller itself

Charge it for a while. Some models have a small reset button on the back; look it up in the maker's instructions. Then try it on a console or another computer. If it works there, the problem is on your PC.

6. Windows' own list

On Windows, press Windows + R, type joy.cpl and press Enter to see the game controllers Windows knows about. Not every controller appears there, and the dialog's labels can vary, but a listed device with working input confirms the system sees it.

Tell the problem apart

It helps to ask where the failure sits. If the controller shows up in the gamepad test but not in a game, the PC is fine and the game or its launcher needs a setting. If it never shows up anywhere, look at the cable, the pairing and the controller. If it works on a console, the controller itself is healthy.

A strange name in the test

The browser gives the page a technical identifier, which the test shows and uses to guess the family (Xbox, PlayStation, Switch). An unknown controller is treated as generic, and its buttons show as numbers. That is normal for less common models.

If nothing works

Check for a firmware or driver update from the manufacturer, and read the guide to choosing a PC controller if you need a model that works with a PC without extra software.

Frequently asked questions

Do I need to update my browser for controllers?

Current browsers support controllers. If yours does not work, try another recent browser.

Can I test more than one controller?

Yes, browsers list several at once. The test shows the one you select.

Why is my controller found by Windows but not the test?

Press a button on the test page first, and close any app that holds the controller exclusively.
