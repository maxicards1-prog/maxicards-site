Périphérique qui ne marche pas : diagnostiquer en 6 étapes

Pour savoir qui est en panne, isolez les éléments un par un : autre port, autre appareil, autre navigateur, puis le test en ligne qui lit la touche ou le signal.

Page mise à jour le 26/11/2026.

Tester directement : Test micro · Test webcam · Test clavier · Test souris · Test manette

La méthode en 6 étapes

  1. Notez le symptôme : Que se passe-t-il exactement : rien, par intermittence, mal ? Une phrase précise vous évite de tourner en rond.
  2. Testez dans le navigateur : Ouvrez le test correspondant : micro, webcam, clavier, souris ou manette. Si le test fonctionne, le périphérique est bon : cherchez du côté de l'application.
  3. Changez le port ou la prise : Un autre port USB, directement sur l'ordinateur et non sur un concentrateur. Refaites le test.
  4. Changez d'ordinateur : Branchez l'appareil sur une autre machine, ou un téléphone s'il le permet. Si le défaut suit le périphérique, c'est lui. Sinon, c'est l'ordinateur ou ses réglages.
  5. Vérifiez les autorisations et les logiciels : Autorisations du navigateur, confidentialité du système, applications qui occupent l'appareil, logiciels de remappage : fermez-les ou désactivez-les un à un.
  6. Mettez à jour, redémarrez, puis contactez la garantie : Un redémarrage règle plus de problèmes qu'on ne le croit. Si le défaut est bien celui de l'appareil, contactez le vendeur ou le fabricant en gardant vos notes.

Le principe : une seule chose à la fois

Quand rien ne marche, on est tenté de tout changer d'un coup. On ne sait alors plus ce qui a réglé le problème, ni ce qui l'a causé. Changez une seule chose à chaque étape, puis refaites le test.

Les quatre suspects

  • L'appareil lui-même : usure, panne, pile faible.
  • Le câble ou la connexion : câble de charge sans données, port USB défaillant, Bluetooth instable.
  • Le système : pilote, confidentialité, périphérique désactivé ou mal choisi.
  • Le logiciel : navigateur, application, macro qui interfère.

Les tests de ce site lisent le signal tel que le navigateur le reçoit. Si l'appareil y apparaît correctement, vous pouvez écarter les trois premiers suspects, au moins pour le navigateur.

Par type d'appareil

  • Micro et caméra : micro sous Windows 11, webcam non détectée.
  • Clavier : touche qui ne marche plus.
  • Souris : double-clic tout seul.
  • Manette : manette non reconnue, drift.
  • Écran : pixel mort ou coincé, 144 Hz.

Garder des preuves

Notez la date d'achat, le modèle, la description du défaut, et prenez une photo ou une capture du test. Cela accélère un échange sous garantie.

Ce que le test ne fait pas

Il ne remplace pas un diagnostic matériel de pro. Il ne voit pas l'état d'un pilote ni les réglages internes d'un jeu. Il vous dit seulement si le navigateur reçoit le signal attendu.

Vie privée

Chaque test s'exécute dans votre navigateur et ne transmet aucun son, aucune image ni aucune frappe.

Questions fréquentes

Par quel appareil commencer ?

Par celui dont le défaut est le plus clair. Utilisez le test qui correspond : il dit tout de suite si le signal arrive.

Quand contacter la garantie ?

Quand le défaut suit l'appareil d'un ordinateur à l'autre, après avoir écarté câble, port et logiciels.
