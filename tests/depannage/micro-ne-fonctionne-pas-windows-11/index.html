Le micro ne fonctionne pas sous Windows 11

Dans la plupart des cas, le micro est bloqué par l'accès à la confidentialité de Windows, coupé par un interrupteur, ou ce n'est pas le bon micro qui est choisi.

Page mise à jour le 26/11/2026.

Commencez par un test

Ouvrez le test du micro, cliquez sur « Démarrer le test » et parlez. Le résultat vous dit tout de suite si le navigateur reçoit du son, si l'accès est refusé ou si aucun micro n'est trouvé. Les étapes ci-dessous suivent ces trois cas.

Cas 1 : le navigateur dit que l'accès est refusé

Deux autorisations se cumulent : celle de Windows et celle du site. Dans les paramètres de Windows, cherchez la section « Confidentialité et sécurité », puis « Microphone ». L'accès au microphone doit être activé, et l'accès pour les applications de bureau aussi, car un navigateur en fait partie. Les intitulés peuvent varier un peu selon la version de Windows. Ensuite, autorisez le micro pour le site dans le navigateur : voir Autoriser le micro dans Chrome, Edge ou Firefox.

Cas 2 : aucun micro trouvé

  • Vérifiez le branchement : prise jack bien enfoncée, prise USB changée, casque Bluetooth connecté.
  • Sur un casque ou un micro avec un interrupteur ou un bouton de coupure du micro, vérifiez qu'il n'est pas coupé. Certains claviers portables ont aussi une touche qui coupe le micro.
  • Débranchez puis rebranchez l'appareil, puis relancez le test.
  • Dans les paramètres de son de Windows, regardez la liste des périphériques d'entrée : si votre micro y figure désactivé, activez-le.

Cas 3 : le micro est détecté mais le niveau reste plat

  • Dans la liste du test, choisissez un autre micro : Windows peut utiliser un micro intégré à la place de votre casque.
  • Dans les paramètres de son de Windows, sélectionnez le bon appareil d'entrée et réglez son volume. Parlez en regardant la barre de niveau pour voir si elle bouge.
  • Fermez les autres applications qui utilisent le micro (visio, enregistreur, jeu). Selon le pilote, un seul programme peut le prendre à la fois : le navigateur affiche alors une erreur « micro déjà utilisé ».

Si rien ne change

Redémarrez l'ordinateur, puis essayez un autre navigateur. Si le micro fonctionne ailleurs mais pas sur un seul site, le problème est l'autorisation du site. S'il ne fonctionne nulle part, essayez-le sur un autre ordinateur ou un téléphone : s'il ne marche pas non plus, le micro est probablement en panne. Le guide Bien régler son micro pour les visios détaille ensuite le bon niveau.

Le test se fait dans votre navigateur : le son n'est ni envoyé ni enregistré sur un serveur.

Questions fréquentes

Pourquoi mon micro marche sur Discord mais pas dans le navigateur ?

Chaque application a son autorisation. Autorisez aussi le micro pour le site dans le navigateur et vérifiez l'accès des applications de bureau dans la confidentialité de Windows.

Mon casque est reconnu mais pas son micro : que faire ?

Choisissez le micro du casque dans la liste du test. Pour un casque Bluetooth, le micro peut n'apparaître qu'en mode « mains libres ».
