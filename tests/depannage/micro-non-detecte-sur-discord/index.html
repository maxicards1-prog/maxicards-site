Micro non détecté sur Discord

Si le micro marche dans le test mais pas dans Discord, choisissez le bon périphérique d'entrée dans les paramètres vocaux de Discord ; sinon, le problème vient du système.

Page mise à jour le 26/11/2026.

Séparer l'application du système

Commencez par le test du micro dans votre navigateur. - Le test fonctionne : le micro est bon et autorisé. Le problème vient des réglages de Discord. - Le test échoue : le problème est dans le système ou le branchement. Suivez Micro qui ne fonctionne pas sous Windows 11.

Réglages dans Discord

Dans les paramètres de l'application, section voix et vidéo (l'intitulé exact peut changer), vérifiez : 1. le périphérique d'entrée : choisissez votre micro au lieu de « Par défaut » si le défaut est un autre appareil ; 2. le volume d'entrée, qui ne doit pas être à zéro ; 3. le mode d'entrée : « détection de l'activité vocale » ou « appuyer pour parler ». Si la détection est réglée trop haut, votre voix peut être coupée ; 4. les traitements automatiques (suppression de bruit, réduction d'écho, réglage automatique du gain) : désactivez-les pour tester.

Réglages du système

Pour la version de bureau, l'application a besoin de l'accès au micro dans les paramètres de confidentialité du système. Pour la version dans le navigateur, le micro est autorisé site par site : voir Autoriser le micro dans Chrome, Edge ou Firefox.

Une autre application tient le micro

Selon le pilote, une autre application peut occuper le micro et empêcher son usage. Fermez les logiciels d'enregistrement, de streaming ou de visio, puis relancez Discord.

Les autres vous entendent mal

Un micro trop faible, trop fort ou qui renvoie de l'écho se règle comme ailleurs : micro trop faible, micro qui sature, écho.

Casque Bluetooth

Un casque Bluetooth change de mode quand le micro s'active, ce qui peut troubler la sélection du périphérique. Vérifiez le nom du micro dans la liste de Discord.

Si le problème persiste

Redémarrez l'application, puis l'ordinateur. Testez aussi sur une autre application de visio pour confirmer que le micro fonctionne.

Note : ces pages ne sont pas affiliées à Discord ; les intitulés de ses menus peuvent changer.

Questions fréquentes

Pourquoi les autres m'entendent par intermittence ?

Le mode « détection de l'activité vocale » coupe la voix si son seuil est trop haut. Baissez-le ou passez en « appuyer pour parler ».

Le test en ligne remplace-t-il le test de Discord ?

Il vérifie le micro et l'autorisation du navigateur. Pour les réglages internes, utilisez les paramètres vocaux de Discord.
