Autoriser la caméra dans le navigateur

Cliquez sur « Autoriser » dans la fenêtre qui s'affiche près de la barre d'adresse quand le site demande la caméra ; si vous avez bloqué, rouvrez les permissions du site.

Page mise à jour le 26/11/2026.

Comment ça se passe

Un site ne peut pas allumer votre caméra seul. Quand vous cliquez sur « Démarrer » dans le test de la webcam, le navigateur affiche une demande d'autorisation. Répondre « Autoriser » lance l'image. Répondre « Bloquer » est mémorisé : la demande ne revient plus, et il faut changer le réglage.

Rouvrir l'autorisation d'un site

Sur Chrome et Edge, cliquez sur l'icône à gauche de l'adresse (cadenas ou curseurs) pour voir les permissions du site, passez la caméra sur « Autoriser », puis rechargez la page. Sur Firefox, l'icône d'autorisations à gauche de l'adresse permet de retirer le blocage de la caméra. Sur Safari, les réglages se trouvent dans les paramètres des sites web du navigateur. Les intitulés varient selon les versions : en cas de doute, ouvrez l'aide de votre navigateur.

L'autorisation du système

Si la caméra est refusée même après avoir tout autorisé dans le navigateur, regardez les paramètres de confidentialité de Windows ou de macOS : la section « Caméra » peut interdire l'accès aux applications, navigateurs compris. Réactivez-le pour votre navigateur.

Plusieurs caméras

Après l'autorisation, le test affiche toutes les caméras. Choisissez-en une dans la liste et lancez-la. Pour une explication des erreurs, voir Webcam non détectée.

Sécurité : ce que vous contrôlez

  • Chaque autorisation est propre à un site.
  • Le navigateur affiche un indicateur quand la caméra est active.
  • Vous pouvez retirer l'autorisation à tout moment dans le même menu.
  • Notre page n'envoie aucune image : l'aperçu reste dans votre navigateur. La photo que vous pouvez enregistrer est créée sur votre appareil.

Après le test

Cliquez sur « Arrêter » : la caméra est coupée. La page l'arrête aussi quand vous changez d'onglet ou la fermez. Si le voyant reste allumé, une autre application l'utilise.

Pour vérifier en même temps le son, utilisez le test micro et webcam.

Questions fréquentes

Pourquoi le site ne me redemande pas l'autorisation ?

Vous avez probablement bloqué la caméra. Rouvrez les permissions du site près de la barre d'adresse.

Mes images sont-elles envoyées quelque part ?

Non. L'aperçu et la photo restent dans votre navigateur. Seul l'affichage est local.
