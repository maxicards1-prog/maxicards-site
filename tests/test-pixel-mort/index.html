Comment chercher un pixel mort

  1. Nettoyez l'écran avec un chiffon doux : une poussière ressemble à un pixel défectueux.
  2. Réglez la luminosité sur un niveau confortable et éteignez les économiseurs d'écran.
  3. Cliquez sur « Lancer le test en plein écran ». Parcourez les couleurs avec les flèches ou en cliquant. Sur chaque couleur, regardez toute la surface de près, en balayant de gauche à droite.
  4. Sur noir, cherchez un point lumineux. Sur blanc, cherchez un point sombre. Sur rouge, vert et bleu, cherchez un point d'une autre couleur ou noir.
  5. Appuyez sur Échap pour quitter.

Pixel mort, pixel coincé : la différence

  • Un pixel mort reste éteint : il apparaît noir, surtout visible sur fond blanc.
  • Un pixel coincé reste allumé sur une couleur : un point rouge, vert, bleu ou blanc, surtout visible sur fond noir.
  • Une tache ou un halo qui s'étend sur plusieurs centimètres n'est pas un pixel : c'est un défaut d'uniformité du rétroéclairage. Utilisez le test d'écran.

Pourquoi pas de pixels qui clignotent

Certains sites proposent de « réparer » un pixel coincé avec une animation qui clignote vite. Nous n'en proposons pas : ces motifs peuvent provoquer des crises chez les personnes photosensibles, et leur efficacité n'est pas garantie. Ce test n'affiche que des couleurs fixes.

Que faire si vous en trouvez un

Notez la couleur du point, sa place et le fond sur lequel il est visible. Regardez ensuite la garantie de votre écran : les fabricants ont chacun leur règle sur le nombre de pixels défectueux acceptés, écrite dans leurs conditions. Si vous achetez un écran, faites ce test dès la réception : le guide Vérifier un écran à l'achat détaille la marche à suivre. Voir aussi Pixel mort ou pixel coincé.

Questions fréquentes

Comment savoir si c'est un pixel mort ou de la poussière ?

Nettoyez l'écran avec un chiffon doux. Si le point reste au même endroit sur plusieurs couleurs, c'est un pixel défectueux. Une poussière se déplace ou disparaît.

Le plein écran ne marche pas sur mon téléphone, pourquoi ?

Certains navigateurs mobiles n'autorisent pas le mode plein écran sur une page. Le test occupe alors toute la fenêtre : masquez les barres du navigateur en faisant défiler, ou utilisez un ordinateur.

Un pixel défectueux est-il couvert par la garantie ?

Cela dépend du fabricant et du modèle. Lisez les conditions de garantie de votre écran : elles indiquent le nombre de pixels défectueux acceptés.
