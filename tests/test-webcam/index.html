Comment faire le test de la webcam

  1. Cliquez sur « Démarrer le test » et acceptez la demande d'accès à la caméra.
  2. Votre image apparaît. Le voyant de la caméra s'allume en général quand elle est utilisée.
  3. Regardez la résolution reçue et le nombre d'images par seconde mesuré. Si l'image est noire, le test vous le dit.
  4. Cliquez sur « Prendre une photo » pour juger la netteté, puis enregistrez-la sur votre appareil si vous le souhaitez.

Ce que le test mesure

  • La résolution réelle : celle que le navigateur reçoit, pas celle écrite sur la boîte. Elle peut être plus basse que ce que vous avez demandé.
  • Les images par seconde : mesurées pendant que vous regardez l'aperçu. Dans une pièce sombre, beaucoup de caméras baissent le nombre d'images pour mieux voir : c'est normal.
  • L'image noire : si l'image est presque noire, la caméra répond mais ne voit rien (cache fermé, pièce sans lumière, objectif couvert).

Si ça ne marche pas

  • Accès refusé : voir Autoriser la caméra dans le navigateur.
  • Aucune caméra trouvée ou appareil occupé : voir Webcam non détectée.
  • Image sombre ou floue : lisez le guide Régler sa webcam : lumière et cadrage.

Vie privée

La caméra ne s'ouvre qu'après votre clic sur « Démarrer le test ». L'image reste dans votre navigateur : elle n'est ni enregistrée ni envoyée. La photo est créée en mémoire dans l'onglet ; elle n'est enregistrée sur votre appareil que si vous cliquez sur le lien d'enregistrement. Le bouton « Arrêter » coupe la caméra.

Questions fréquentes

Pourquoi la résolution obtenue est plus basse que celle demandée ?

Le navigateur demande la résolution à la caméra, qui répond avec ce qu'elle sait faire. Un câble USB ancien, un port USB lent ou une application qui utilise déjà la caméra peuvent aussi limiter la résolution.

Le test marche-t-il avec une caméra externe ?

Oui. Choisissez-la dans la liste « Caméra à tester » après l'autorisation.

Mon image est inversée, est-ce normal ?

L'aperçu en miroir est coché par défaut, comme dans la plupart des applications de visio. Décochez-le pour voir l'image comme vos correspondants la voient. La photo n'est pas inversée.

La photo est-elle envoyée quelque part ?

Non. Elle reste en mémoire dans l'onglet jusqu'à la fermeture de la page, sauf si vous l'enregistrez vous-même.
