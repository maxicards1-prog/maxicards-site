Acerca de

Una web gratuita de fans con cifras con fuente.

Herramientas Cartas Pokémon es una web gratuita de pequeñas calculadoras y guías para coleccionistas y jugadores de cartas Pokémon, tanto de cartas físicas como de TCG Pocket. Es la edición en español de nuestro sitio francés.

Quién está detrás de la web

La web la publica MAXICARDS, una empresa francesa que gestiona el canal de YouTube MaxiCards, un canal en francés sobre cartas Pokémon. Todos los datos están en el aviso legal.

Nuestros principios

  • Gratis y sin cuenta: ninguna herramienta te pide registrarte.
  • Tus datos se quedan contigo: los cálculos se hacen en tu navegador; el contador shiny se guarda solo en tu dispositivo.
  • Fuentes citadas: cada probabilidad o comisión mostrada enlaza con su fuente y la fecha de comprobación. Las estimaciones se presentan como estimaciones.
  • Una web de fans: sin imágenes ni logotipos oficiales. La web no tiene relación con Nintendo, Creatures, GAME FREAK ni The Pokémon Company.

Cómo se financia la web

La web muestra publicidad (Google AdSense) para cubrir sus gastos de funcionamiento. La publicidad nunca cambia los resultados de las calculadoras. Consulta la política de privacidad.

¿Has encontrado un error o tienes una idea para una herramienta?

Escríbenos desde la página de Contacto. Corregimos las cifras en cuanto cambia una fuente.
