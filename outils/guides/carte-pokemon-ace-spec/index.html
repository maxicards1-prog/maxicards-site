Carte Pokémon ACE SPEC : c'est quoi ?

En bref Une carte ACE SPEC est une carte de soutien particulièrement puissante, qui obéit à une règle simple : une seule par deck.

Mis à jour le 23/11/2026 · Jouer au JCC · par l'équipe MaxiCards

En bref : un deck ne peut contenir qu'une seule carte ACE SPEC, toutes cartes différentes confondues. Ce sont des cartes Objet, Outil Pokémon, Stade ou Énergie spéciale dont l'effet est plus fort que la moyenne.

La règle

D'après un guide français sur le sujet, une carte ACE SPEC ne peut figurer qu'une fois dans un deck, et le règlement officiel cité répond « non » à la question de savoir si l'on peut mettre deux ACE SPEC différentes. Un Objet ACE SPEC ne peut donc pas être accompagné d'un Outil, d'un Stade ou d'une Énergie spéciale ACE SPEC. Les autres cartes gardent la limite habituelle de quatre exemplaires du même nom, les Énergies de base étant exemptées.

Quels types de cartes ?

  • des cartes Objet ;
  • des cartes Outil Pokémon ;
  • des cartes Stade ;
  • des cartes Énergie spéciale.

Les différences entre ces types sont expliquées dans cartes Dresseur : objet, supporter, stade, outil et dans cartes Énergie.

Comment la reconnaître ?

Le repère principal est le texte « ACE SPEC » imprimé en grandes lettres sur la carte, avec une bande de règle. Selon le guide cité, il n'existe pas de symbole de rareté propre aux ACE SPEC. Lisez le texte de règle sur la carte plutôt que de vous fier au seul visuel.

Un exemple concret

Si vous mettez une carte ACE SPEC dans votre deck, vous ne pouvez plus en ajouter une autre, même d'un autre type. Choisissez celle dont l'effet correspond le mieux à votre stratégie. La méthode complète est dans construire un deck Pokémon.

Peut-on les jouer partout ?

Cela dépend du format et des extensions autorisées. Pour savoir ce qui est légal aujourd'hui, regardez le format Standard et la rotation.

Questions fréquentes

Carte pokemon ace spec, c'est quoi ?

Une carte de soutien (Objet, Outil, Stade ou Énergie spéciale) à l'effet puissant, limitée à une seule dans un deck.

Pokemon card ace spec : combien par deck ?

Une seule carte ACE SPEC par deck, même si elles sont de types ou de noms différents.
