Où entrer le code d'une carte Pokémon (TCG Live)

En bref Une carte avec un code dans un booster ne se joue pas : elle débloque du contenu dans Pokémon TCG Live. Voici où la saisir, ce que vous obtenez et les erreurs à éviter.

Mis à jour le 23/11/2026 · Jouer au JCC · par l'équipe MaxiCards

Utiliser une carte à code dans Pokémon TCG Live

  1. Repérer la carte à code. C'est une carte qui ne se joue pas, avec un code et en général un QR code. Gardez-la intacte et ne la montrez à personne.
  2. Se connecter au bon compte. Ouvrez Pokémon TCG Live (ou le site officiel) et connectez-vous avec le compte Pokémon que vous utilisez pour jouer : le contenu ira sur ce compte.
  3. Ouvrir la saisie de code. Dans le menu ou la boutique de l'application, ou sur la page de saisie du site officiel, choisissez l'option pour utiliser un code (« Redeem Code » en anglais).
  4. Saisir ou scanner le code. Tapez le code sans erreur, ou scannez le QR code si votre appareil le permet, puis validez.
  5. Récupérer son contenu. Les boosters virtuels, decks ou cartes promo arrivent dans votre compte : réclamez-les depuis l'application, puis ouvrez-les.

Dans certains boosters, decks et coffrets, une carte ne ressemble pas aux autres : un code y est imprimé, souvent avec un QR code. C'est une carte à code. Elle n'a aucune valeur de jeu sur la table : elle sert à débloquer du contenu dans l'application Pokémon TCG Live (JCC Pokémon Live en français), la version numérique du jeu. Les étapes pour la saisir sont listées plus haut ; ce guide explique le reste.

À quoi sert une carte à code ?

Selon Poképédia, ces cartes existent depuis l'extension Noir et Blanc. Ce qu'elles donnent dépend du produit :

  • Booster : le code ouvre un booster virtuel de la même extension que la carte. Les anciennes cartes à code donnaient un booster de l'extension la plus récente du jeu en ligne.
  • Deck à thème : le code débloque le deck correspondant dans l'application.
  • Autres produits : certains coffrets donnent des cartes spéciales propres au produit.

Pokémon a aussi indiqué en 2025 que le dessin des cartes à code avait changé à partir de l'extension Méga-Évolution et que certaines cartes à code d'autres produits débloquent des cartes promo numériques. Dans certaines extensions récentes, plusieurs modèles de cartes à code existent dans les boosters, et vous en obtenez un seul au hasard. Pour les boosters physiques et leur contenu, voyez display, ETB et coffrets : que choisir.

Pokémon TCG Live, c'est quoi ?

D'après Poképédia, JCC Pokémon Live est sorti en juin 2023 en Amérique du Nord, en Australie et en Europe. Il remplace le JCC Pokémon Online et fonctionne sur Windows, macOS, iOS, iPadOS et Android ; il faut un compte Cercle des Dresseurs Pokémon pour y jouer. Il propose un tutoriel, un mode classé en Format Standard avec des rangs mensuels et un mode décontracté. Les échanges de cartes entre amis n'y sont plus possibles. Pour jouer vos premières parties, lisez comment jouer aux cartes Pokémon.

Où entrer le code, concrètement

Selon la FAQ officielle de Pokémon, on entre le code depuis le menu de navigation, rubrique d'utilisation de code (« Redeem Code » en anglais), qui demande de se connecter avec le compte lié à Pokémon TCG Live. Le nom exact du bouton peut varier selon la langue de l'application : si vous ne le voyez pas tout de suite, cherchez dans le menu ou dans la boutique. Le même service existe sur le site officiel, qui peut dépanner si votre appareil ne propose pas la saisie directe. Vous pouvez saisir le code à la main ou, selon l'appareil, scanner le QR code.

Les pièges à éviter

  • Le mauvais compte. Pokémon prévient qu'il ne peut pas transférer des cartes ou des decks d'un compte à un autre. Vérifiez le compte connecté avant de valider.
  • Le mauvais jeu. Les codes de Pokémon TCG Pocket (le jeu mobile) ne fonctionnent pas dans Pokémon TCG Live, et inversement. Voyez le guide Pocket pour ce jeu.
  • Un code déjà utilisé. D'après la FAQ de Pokémon, un code ne peut être utilisé qu'une seule fois. Un code sur une carte d'occasion peut donc être déjà épuisé : demandez-le avant d'acheter, ou considérez la carte comme sans valeur.
  • Les ventes douteuses. Méfiez-vous des annonces vendant des « lots de codes » à prix cassé : voyez nos conseils pour éviter les arnaques.
  • Un code qui manque ou qui échoue. Si le produit annonçait un code et qu'il n'y en a pas, ou si la saisie échoue, Pokémon invite à contacter son support.

Que faire si un booster ne contient pas de code ?

Tous les produits n'en contiennent pas, et tous les boosters d'une extension ne donnent pas forcément une carte à code. Regardez l'emballage et la description du produit avant l'achat. Si vous voulez simuler l'ouverture sans rien acheter, essayez notre simulateur d'ouverture de booster.

Peut-on revendre une carte à code ?

Une carte à code n'a pas de valeur de collection en soi, et son code ne sert qu'une fois. Un acheteur ne devrait donc pas la payer cher, et un vendeur doit préciser si le code a déjà été utilisé. N'envoyez jamais de photo d'un code non utilisé à une personne inconnue : elle pourrait l'utiliser avant vous.

Questions fréquentes

Une carte à code Pocket marche-t-elle dans TCG Live ?

Non. Les codes de Pokémon TCG Pocket ne fonctionnent pas dans Pokémon TCG Live, car ce sont deux jeux distincts.

Peut-on utiliser deux fois le même code Pokémon ?

Non. D'après la FAQ de Pokémon, un code ne peut être utilisé qu'une seule fois.

La carte à code compte-t-elle dans le deck ?

Non. Elle ne se joue pas à la table ; elle sert uniquement à débloquer du contenu numérique.

Que faire si le code ne fonctionne pas ?

Vérifiez d'abord la saisie et le compte connecté. Si le problème continue, contactez le support de Pokémon en indiquant le produit acheté.
