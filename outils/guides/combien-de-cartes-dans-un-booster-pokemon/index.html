Combien de cartes dans un booster Pokémon ?

En bref Un booster français récent contient 10 cartes d'extension, plus une carte à code. Voici le détail, et pourquoi certaines sources comptent 11 ou 12 cartes.

Mis à jour le 23/11/2026 · Extensions · par l'équipe MaxiCards

En bref : un booster récent contient 10 cartes de l'extension et 1 carte à code pour le jeu en ligne. Selon la façon de compter, on lit aussi « 11 » ou « 12 » : c'est la carte Énergie et la carte à code qui changent le total.

Ce que disent les sources

Poképédia décrit la composition d'un booster depuis la série Soleil et Lune comme « 10 + 1 carte Énergie + 1 carte à code », soit 12 cartes au total. La fiche de l'extension Méga-Évolution Règne Delta, elle, indique des boosters de 10 cartes, avec une seule carte à code par booster, et précise que les Énergies de base sont « disponibles dans ses boosters » sans dire combien.

Les deux informations se rejoignent : le cœur du booster, ce sont 10 cartes. La carte à code se glisse en plus, et une Énergie de base peut s'ajouter selon l'extension. Pour être certain, comptez sur votre premier paquet ou lisez l'emballage.

Ce qu'on trouve dans les 10 cartes

  • au moins une carte rare (ou d'une rareté supérieure) ;
  • une carte reverse (version brillante du fond), qui peut être n'importe quelle carte de l'extension ;
  • le reste en cartes communes et peu communes.

Cette répartition vient de la même page Poképédia. Pour comprendre les symboles imprimés, voyez les symboles de rareté.

La carte à code, c'est quoi ?

C'est une carte qui ne se joue pas : elle porte un code à entrer dans le jeu en ligne. Le mode d'emploi est dans le guide où entrer le code d'une carte Pokémon.

Et pour un tripack, un display ?

Un tripack contient 3 boosters, un display 36. Il suffit de multiplier. Le guide display, ETB, coffret compare ces produits, et le calculateur de prix par booster donne le coût de chaque carte.

Pour les boosters japonais, coréens ou d'une édition spéciale, le nombre peut être différent : lisez la mention sur le paquet plutôt que de vous fier à un chiffre d'une autre langue.

Questions fréquentes

Combien de cartes dans un booster pokemon japonais ?

Nous n'avons pas trouvé de source fiable à citer, donc pas de chiffre ici. Lisez la mention sur le paquet : la composition peut différer d'un booster français.

Combien de cartes dans un pack pokemon ?

Un pack français récent contient 10 cartes d'extension et une carte à code, d'après les fiches de Poképédia. Un tripack réunit 3 boosters.

Combien de cartes dans un booster pokemon 30 ans ?

Cela dépend du produit : vérifiez la mention sur le paquet. Les produits de l'extension anniversaire sont décrits dans le guide sur les cartes des 30 ans.

Combien de carte dans un booster pokemon français ?

10 cartes d'extension, plus une carte à code ; une Énergie de base peut s'y ajouter selon la fiche de l'extension.
