Where to Enter a Pokémon Card Code (TCG Live)

In short A card with a code in a booster pack is not played at the table: it unlocks content in Pokémon TCG Live. Here is where to enter it, what you get and the mistakes to avoid.

Updated November 24, 2026 · Playing the TCG · by the MaxiCards team

Redeem a code card in Pokémon TCG Live

  1. Spot the code card. It is a card that cannot be played, with a code and usually a QR code. Keep it intact and do not show it to anyone.
  2. Sign in to the right account. Open Pokémon TCG Live (or the official website) and sign in with the Pokémon account you play with: the content goes to that account.
  3. Open code entry. In the app's menu or store, or on the official website's redeem page, choose the option to redeem a code ("Redeem Code").
  4. Enter or scan the code. Type the code carefully, or scan the QR code if your device allows it, then confirm.
  5. Claim your content. Virtual boosters, decks or promo cards arrive in your account: claim them in the app, then open them.

In some booster packs, decks and boxes, one card looks different from the others: it has a code printed on it, often with a QR code. This is a code card. It has no gameplay value at the table: it unlocks content in the Pokémon TCG Live app, the digital version of the game. The steps to redeem it are listed above; this guide covers the rest.

What is a code card for?

According to Pokepedia, these cards have existed since the Black & White expansion. What they give depends on the product:

  • Booster pack: the code opens a virtual booster from the same expansion as the card. Older code cards gave a booster from the most recent expansion in the online game.
  • Theme deck: the code unlocks the matching deck in the app.
  • Other products: some boxes give special cards specific to the product.

Pokémon also said in 2025 that the code card design changed starting with the Mega Evolution expansion, and that some code cards from other products unlock digital promo cards. In some recent expansions, several code card designs exist in the packs, and you get just one at random. For physical boosters and what is in them, see booster boxes, Elite Trainer Boxes and collection boxes: which to choose.

What is Pokémon TCG Live?

According to Pokepedia, Pokémon TCG Live launched in June 2023 in North America, Australia and Europe. It replaces Pokémon TCG Online and runs on Windows, macOS, iOS, iPadOS and Android; you need a Pokémon account to play. It has a tutorial, a ranked mode in the Standard format with monthly ranks, and a casual mode. Trading cards with friends is no longer possible there. To play your first games, read how to play Pokémon cards.

Where to enter the code, exactly

According to Pokémon's official FAQ, you enter the code from the navigation menu, in the "Redeem Code" section, which asks you to sign in with the account linked to Pokémon TCG Live. The exact name of the button can vary by app version: if you do not see it right away, look in the menu or in the store. The same service exists on the official website, which can help if your device does not offer direct entry. You can type in the code by hand or, depending on your device, scan the QR code.

Pitfalls to avoid

  • The wrong account. Pokémon warns that it cannot transfer cards or decks from one account to another. Check which account is signed in before you confirm.
  • The wrong game. Codes for Pokémon TCG Pocket (the mobile game) do not work in Pokémon TCG Live, and the other way around. See the Pocket guide for that game.
  • An already-used code. According to Pokémon's FAQ, a code can only be used once. A code on a used card may already be spent: ask before you buy, or treat the card as worthless.
  • Dodgy sales. Be careful with listings that sell "bundles of codes" at bargain prices: see our tips for avoiding Pokémon card scams.
  • A missing or failing code. If the product advertised a code and there is none, or if redeeming fails, Pokémon invites you to contact its support.

What if a booster has no code?

Not every product contains one, and not every booster in an expansion necessarily gives a code card. Check the packaging and the product description before you buy. If you want to simulate opening packs without buying anything, try our booster pack opening simulator.

Can you resell a code card?

A code card has no collector value in itself, and its code only works once. A buyer should not pay much for one, and a seller must say whether the code has already been used. Never send a photo of an unused code to a stranger: they could use it before you.

Frequently asked questions

Does a Pocket code card work in TCG Live?

No. Pokémon TCG Pocket codes do not work in Pokémon TCG Live, because they are two separate games.

Can you use the same Pokémon code twice?

No. According to Pokémon's FAQ, a code can only be used once.

Does the code card count in your deck?

No. It is not played at the table; it only unlocks digital content.

What if the code does not work?

First check what you typed and which account is signed in. If the problem continues, contact Pokémon support and mention the product you bought.
