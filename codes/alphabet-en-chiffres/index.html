Alphabet en chiffres

Les accents sont retirés (é = e).

Un tiret entre les lettres, une barre / entre les mots.

Un jeu, pas une protection : ce code se casse en quelques minutes, même à la main. Parfait pour une énigme ou un escape game, jamais pour cacher une information importante.

Tout se passe dans votre navigateur : rien de ce que vous tapez n'est envoyé ni gardé.

Chaque lettre devient son rang dans l'alphabet, et inversement.

Mis à jour le 26/11/2026 · tout se passe dans votre navigateur, rien n'est envoyé ni gardé.

Le principe

Chaque lettre est remplacée par son rang dans l'alphabet : A = 1, B = 2, C = 3… jusqu'à Z = 26. « Bonjour » devient 2-15-14-10-15-21-18. Dans l'autre sens, tapez des nombres de 1 à 26 séparés par une espace, un tiret ou une virgule : l'outil retrouve les lettres. Pour séparer les mots, mettez une barre oblique ou deux espaces.

Rang12345678910111213

Rang14151617181920212223242526

Les variantes

Certains jeux commencent à zéro (A = 0, Z = 25), d'autres partent de la fin (Z = 1). Si un message décodé ici ne veut rien dire, essayez de retrancher 1 à chaque nombre, ou de compter à rebours. Un nombre au-dessus de 26 n'est pas une lettre : l'outil l'affiche avec un carré □.

Pour quels jeux ?

C'est le premier code que l'on propose dans une chasse au trésor ou un escape game, parce qu'il se décode sans aide. Pour corser l'énigme, on peut ajouter un décalage, comme dans le code César, ou utiliser un mot-clé avec le chiffre de Vigenère.

Questions fréquentes

Quel chiffre correspond à quelle lettre ?

A = 1, B = 2, C = 3, et ainsi de suite jusqu'à Z = 26. M est la 13e lettre et N la 14e.

Comment séparer les mots ?

Avec une barre oblique, comme dans 2-15-14 / 10-15-21-18, ou avec deux espaces.

Et si mon jeu commence à A = 0 ?

Retranchez 1 à chaque nombre avant de le coller ici, ou ajoutez 1 pour l'autre sens.
