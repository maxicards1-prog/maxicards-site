Code Atbash

Le même bouton chiffre et déchiffre : collez un message codé pour le lire.

Un jeu, pas une protection : ce code se casse en quelques minutes, même à la main. Parfait pour une énigme ou un escape game, jamais pour cacher une information importante.

Tout se passe dans votre navigateur : rien de ce que vous tapez n'est envoyé ni gardé.

Le plus ancien des codes par substitution : la première lettre devient la dernière.

Le principe

L'Atbash retourne l'alphabet : la première lettre est remplacée par la dernière, la deuxième par l'avant-dernière, et ainsi de suite. A devient Z, B devient Y, M devient N. Il n'y a pas de clé, et le même geste chiffre et déchiffre.

ClairAtbash
A B C D E F G H I J K L MZ Y X W V U T S R Q P O N
N O P Q R S T U V W X Y ZM L K J I H G F E D C B A

Un code venu de l'hébreu

L'Atbash a été conçu pour l'alphabet hébreu : il remplace la première lettre (aleph) par la dernière (tav), et ainsi de suite. On en trouve un exemple dans le livre de Jérémie, où le mot « Sheshakh » est l'Atbash de « Bavel », Babylone. Appliqué à notre alphabet latin, il garde le même principe.

Exemple

« Le trésor est dans la cave » devient « Ov givhli vhg wzmh oz xzev ». Recollez le résultat : le message revient.

Pour quel usage ?

Comme le code César ou le ROT13, l'Atbash est un code de jeu. Il n'y a qu'une seule façon de l'appliquer : quiconque connaît son nom lit le message tout de suite. Il fait une bonne énigme d'escape game, surtout si l'on donne un indice comme « le premier devient le dernier ».

Le retenir sans tableau

Écrivez l'alphabet sur une ligne, puis à l'envers sur la ligne du dessous : chaque lettre a sa correspondante juste en dessous. Autre repère : le rang d'une lettre et celui de sa correspondante font toujours 27. A (1) va avec Z (26), E (5) avec V (22), M (13) avec N (14).

À la différence du code César, où toutes les lettres avancent du même nombre de rangs, l'Atbash ne décale pas : il retourne. Le A et le Z échangent leur place, alors qu'un César de 3 envoie le A sur le D. Un message en Atbash ne se retrouve donc pas parmi les 25 décalages du César.

Questions fréquentes

Comment décoder un message en Atbash ?

Collez-le dans l'outil : l'Atbash se décode avec le même geste, puisque retourner deux fois l'alphabet ramène au départ.

D'où vient le nom Atbash ?

Il vient de l'alphabet hébreu, pour lequel le code a été conçu : il échange la première lettre et la dernière, la deuxième et l'avant-dernière, et ainsi de suite.

L'Atbash a-t-il une clé ?

Non. Il n'existe qu'une seule façon de l'appliquer, ce qui le rend très facile à casser.
