Le principe

Chaque lettre est remplacée par la lettre située un certain nombre de rangs plus loin dans l'alphabet. Avec un décalage de 3, A devient D, B devient E, et la fin de l'alphabet repart au début : X devient A, Y devient B, Z devient C. Pour déchiffrer, on recule du même nombre de rangs. Les chiffres, les espaces et la ponctuation ne changent pas.

Pourquoi « César » ?

L'historien romain Suétone raconte que Jules César, dans sa correspondance secrète, remplaçait chaque lettre par la quatrième de l'alphabet, D pour A : c'est un décalage de 3. Le nom est resté pour toute la famille de codes par décalage.

Exemple

« Rendez-vous au vieux chêne à midi », décalé de 3 sans les accents, donne « Uhqghc-yrxv dx ylhxa fkhqh d plgl ». Avec le décalage 13, on obtient le ROT13, qui a une propriété amusante : le même geste chiffre et déchiffre.

Pourquoi il ne protège rien

Il n'existe que 25 décalages utiles. La liste sous l'outil les essaie tous d'un coup : il suffit de repérer la ligne qui forme des mots. L'outil vous aide en colorant la ligne qui contient le plus de mots français courants. C'est parfait pour un jeu de piste, une chasse au trésor ou un escape game, et c'est justement pour cela qu'il ne faut jamais s'en servir pour cacher quelque chose d'important.

Questions fréquentes

Comment déchiffrer un code César sans connaître le décalage ?

Collez le message : la liste sous l'outil montre les 25 décalages possibles. Une seule ligne forme des mots ; l'outil colore celle qui contient le plus de mots français courants.

Quel décalage utilisait Jules César ?

Selon Suétone, il remplaçait A par D, donc un décalage de 3.

Que deviennent les accents ?

Par défaut, ils sont retirés avant de chiffrer (é devient e), car le code ne décale que les 26 lettres. Décochez la case pour les laisser tels quels.

Le code César est-il sûr ?

Non, pas du tout : 25 essais suffisent pour le casser. C'est un jeu, idéal pour une énigme, jamais une protection.
