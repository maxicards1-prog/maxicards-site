Déchiffrer un message codé

Pour déchiffrer un message codé, identifiez d'abord le code à son allure : des points et des traits, c'est du morse ; des 0 et des 1, du binaire ; des lettres mélangées qui gardent la forme des mots, un code par décalage comme César.

Mis à jour le 26/11/2026.

L'outil qui va avec : Code César · Chiffre de Vigenère · Traducteur morse · Binaire en texte · Base64 · Code Atbash

La méthode en 6 étapes

  1. Observez les symboles : Points et traits, chiffres, lettres seules ou mélange de lettres, de chiffres et de signes : chaque code a son allure.
  2. Points et traits : le morse : Collez-les dans le traducteur morse, avec une espace entre les lettres et une barre entre les mots.
  3. Chiffres seuls : binaire, hexadécimal ou alphabet : Des 0 et des 1 par paquets de 8 : du binaire. Des paires de 0 à 9 et de A à F : de l'hexadécimal. Des nombres de 1 à 26 : l'alphabet en chiffres.
  4. Lettres, chiffres et = : le Base64 : Une longue suite de lettres et de chiffres, parfois terminée par = : essayez le décodeur Base64.
  5. Lettres mélangées : les décalages : Si les mots gardent leur longueur mais n'ont pas de sens, essayez le code César, qui teste les 25 décalages, puis ROT13 et Atbash.
  6. Rien ne marche : cherchez une clé : Le message est peut-être chiffré avec le chiffre de Vigenère : il faut alors trouver le mot-clé.

Les quatre dernières lignes se ressemblent : des lettres ordinaires, des mots de la même longueur que l'original, le tiret toujours à sa place. C'est le signe d'un code par substitution de lettres. Les autres codes se reconnaissent au premier regard.

Les lettres mélangées : la piste des décalages

Face à des lettres sans sens, commencez par le plus simple : un décalage fixe de l'alphabet, le code César. Il n'y a que 25 décalages possibles. Notre outil les affiche tous et met en avant celui qui ressemble le plus à du français. Par exemple, « YLUKLG-CVBZ H TPKP » est retrouvé avec un décalage de 7 : « RENDEZ-VOUS A MIDI ». ROT13 est le décalage de 13 ; l'Atbash, lui, retourne l'alphabet (A devient Z, B devient Y) et a sa propre page.

La fréquence des lettres

Si aucun décalage ne donne de sens, comptez les lettres. En français, le E est de loin la plus fréquente ; dans un message assez long, la lettre la plus courante du texte chiffré cache donc souvent un E. Regardez aussi les mots d'une ou deux lettres : en français, ils sont peu nombreux (à, y, de, le, la, un…), ce qui donne des pistes. Cette méthode marche pour toute substitution simple, même quand l'alphabet a été mélangé au hasard, mais elle demande de la patience et un message assez long.

Quand il faut une clé

Avec le chiffre de Vigenère, une même lettre ne se code pas toujours de la même façon : la fréquence des lettres est brouillée. Il faut alors trouver le mot-clé. Dans un jeu, il est souvent caché ailleurs : un mot mis en avant, un nom propre, un titre. Sinon, la méthode historique consiste à repérer les répétitions pour deviner la longueur de la clé (voir comment casser le chiffre de Vigenère).

Les cas que nos outils ne traitent pas

Certains codes de jeu utilisent des dessins (grilles, symboles inventés) ou mélangent l'ordre des lettres au lieu de les remplacer. Pour une anagramme, les lettres du message sont celles d'un mot connu, dans le désordre : la fréquence des lettres reste celle du français. Pour un code à dessins, chaque symbole remplace une lettre : on revient alors à la fréquence des lettres, en notant chaque symbole par une lettre provisoire.

Questions fréquentes

Comment savoir quel code a été utilisé ?

Par son allure : points et traits pour le morse, 0 et 1 pour le binaire, lettres et chiffres terminés par = pour le Base64, lettres mélangées pour un code par décalage.

Comment déchiffrer un code César sans connaître le décalage ?

En essayant les 25 décalages : notre outil les affiche tous et signale le plus probable.

Que faire si aucun décalage ne marche ?

Compter la fréquence des lettres, ou chercher une clé : le message est peut-être chiffré avec Vigenère.
