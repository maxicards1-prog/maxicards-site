Calculateur de classement de foot

Un match par ligne, et le tableau se met à jour tout seul.

#ÉquipePtsJGNPBPBCDiff

Mode d'emploi

Tapez un match par ligne sous la forme « Équipe A 2-1 Équipe B ». Le tiret peut être remplacé par deux-points (2:1). Le classement se met à jour à chaque frappe. Les lignes mal écrites sont signalées sous le tableau, sans bloquer le reste.

Par défaut, une victoire vaut 3 points, un nul 1 point et une défaite 0. Certains tournois de jeunes donnent aussi un point de participation à la défaite, ou 4 points pour une victoire : changez simplement les cases.

Comment les égalités sont départagées

L'outil classe d'abord aux points, puis à la différence de buts (buts marqués moins buts encaissés), puis au nombre de buts marqués, puis par ordre alphabétique. C'est l'ordre le plus courant dans les tournois. Attention : les championnats officiels ont souvent leurs propres règles, par exemple les confrontations directes avant la différence de buts générale, ou le classement du fair-play. Pour un championnat officiel, le règlement de la compétition fait foi.

Lire le tableau

  • Pts : points ; J : matchs joués ; G, N, P : gagnés, nuls, perdus.
  • BP : buts pour (marqués) ; BC : buts contre (encaissés) ; Diff : différence de buts.

Vous pouvez aussi vous en servir pour simuler la fin d'un championnat : tapez les matchs déjà joués, puis les scores que vous imaginez pour les prochaines journées, et voyez le classement final possible. Vos résultats restent enregistrés sur votre appareil. Pour préparer le calendrier, utilisez le générateur de tournoi.

Questions fréquentes

Comment calculer la différence de buts ?

C'est le nombre de buts marqués moins le nombre de buts encaissés. Une équipe qui a marqué 12 buts et en a pris 8 a une différence de +4.

Combien de points pour une victoire au foot ?

3 points pour une victoire, 1 pour un nul et 0 pour une défaite dans presque toutes les compétitions. Certains tournois de jeunes ont un barème différent : l'outil permet de le changer.

Comment sont départagées deux équipes à égalité de points ?

Ici : différence de buts, puis buts marqués, puis ordre alphabétique. Un championnat officiel peut utiliser d'autres critères (confrontations directes, fair-play) : vérifiez son règlement.

Puis-je simuler la fin d'un championnat ?

Oui : ajoutez aux résultats réels les scores que vous imaginez pour les matchs restants, le classement se recalcule aussitôt.
