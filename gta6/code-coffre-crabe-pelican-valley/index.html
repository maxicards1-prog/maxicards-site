Code du coffre du laboratoire de crabes de Pelican Valley

Mis à jour le 24/11/2026

Au laboratoire de recherche de Pelican Valley, le mot de passe de l'ordinateur est CLEAVES, le code du coffre est 0072 (le double de 0036) et celui de la porte du ponton, trouvé dans le coffre, est 0212.

Les trois codes du labo

  • Ordinateur : mot de passe CLEAVES (des lettres, pas des chiffres).
  • Coffre : 0072.
  • Porte du bâtiment du ponton : 0212, que le coffre vous révèle.

Trois guides concordent sur ces valeurs. Ils concordent aussi sur la logique : rien n'est tiré au hasard, tout se déduit des indices sur place. Le labo se trouve dans la zone marécageuse de Pelican Valley, vers Gullet Marsh, dans le comté de Mariana, au nord-ouest de Key Lento. Un guide précise qu'on s'y rend en bateau.

L'énigme, étape par étape

  1. Remettre le courant. L'interrupteur se trouve à l'extérieur, sur le côté de la maison selon un guide, derrière le bâtiment près d'une grande cuve blanche selon un autre.
  2. Trouver le mot de passe. Dans la chambre, regardez le sol (le trou dans le plancher) : plusieurs mots y sont gravés et barrés. Le seul qui ne l'est pas est CLEAVES.
  3. Allumer l'ordinateur de la pièce principale, près du coffre, et saisissez CLEAVES. Il indique que le code du coffre est « double succès ».
  4. Repérer l'expérience réussie. Les notes et les papiers du labo marquent une expérience comme la plus réussie : la numéro 0036. Doublez-la : 0072.
  5. Ouvrir le coffre avec 0072. Il contient de l'argent et une note qui donne 0212.
  6. Aller au ponton. Saisissez 0212 sur le clavier du bâtiment au bout du quai.
Si rien ne marche : vérifiez d'abord que le courant est remis. Un guide note aussi que les valeurs peuvent différer d'une sauvegarde à l'autre ; fiez-vous alors aux numéros que votre jeu affiche.

Pourquoi cette page et pas la liste générale ?

Parce qu'il s'agit d'un coffre à énigme, l'un des seuls dont on peut comprendre le raisonnement : le garder en tête évite de dépendre d'une liste si les chiffres changent chez vous. Pour les autres coffres, voyez la liste des codes de coffres, les braquages pour les coffres aléatoires et les cachettes d'argent. Les secrets du jeu sont regroupés sur la page des easter eggs, et l'avancement sur les missions.

Pas à pas

  1. Remettre le courant : Actionnez l'interrupteur à l'extérieur du labo.
  2. Lire le mot de passe : Dans la chambre, repérez le mot CLEAVES, le seul non barré, gravé dans le sol.
  3. Allumer l'ordinateur : Saisissez CLEAVES : il indique que le code du coffre est « double succès ».
  4. Doubler l'expérience 0036 : Les notes désignent l'expérience 0036 comme la plus réussie : 0036 x 2 = 0072.
  5. Ouvrir le coffre puis la porte : Entrez 0072 dans le coffre, lisez la note : 0212 ouvre le bâtiment du ponton.

Questions fréquentes

Quel est le code du coffre du labo de crabes de GTA 6 ?

0072. L'ordinateur du labo, déverrouillé avec CLEAVES, indique « double succès » ; l'expérience la plus réussie étant la 0036, son double donne 0072.

Quel est le mot de passe de l'ordinateur ?

CLEAVES. Il est gravé dans le sol de la chambre, visible par le trou du plancher : c'est le seul mot qui n'est pas barré.

À quoi sert le code 0212 ?

C'est le code du clavier du bâtiment au bout du ponton. Il est inscrit sur une note dans le coffre.
