Tous les codes de coffres de GTA 6 (combinaisons confirmées)

Mis à jour le 24/11/2026

Les codes fixes confirmés par au moins trois guides sont : Brooks Boatworks 6823, La Cascara Motel 6969, Kingpin Bowling 0300, Nova Auto Junkyard 7777, remorque du lac Cottonmouth 44017, garage de Janjak 4444 et le laboratoire de Pelican Valley 0072.

Les coffres de magasins et de banques, eux, changent à chaque braquage.

Le tableau des codes confirmés

Ce tableau ne reprend que les combinaisons données avec les mêmes chiffres et le même lieu par au moins trois guides publiés depuis la sortie du jeu. Les codes ne sont pas tirés au sort : ce sont des coffres de missions ou de planques de gang. Les codes de tous les autres lieux, sans accord entre les guides, ne sont pas publiés ici.

Les coffres de magasins et de banques : aucun code à retenir

Quand vous braquez un commerce ou une banque, la combinaison est tirée au hasard et change même si vous revenez au même endroit. Deux méthodes, citées par plusieurs guides : menacer un employé avec une arme jusqu'à l'invite « Code du coffre ? », ou chercher une note, un post-it ou un papier près du coffre. Un garde assommé peut aussi porter le code, que le mode Focus fait ressortir. Le code s'affiche en bas à droite de l'écran quand vous vous approchez du coffre.

Sans code : ouvrir quand même

Un guide mentionne l'explosif collant : acheté chez un armurier, il ouvre un coffre sans combinaison, mais il alerte les ennemis proches et peut faire venir la police. Pour utiliser l'argent obtenu, voyez nos conseils pour les cachettes d'argent et gagner de l'argent vite.

Codes volontairement non publiés

D'autres combinaisons circulent (hôtel Marbelle, prêteur sur gages Avery, camp de caravanes Sunrise, laboratoire de Farm Fix, magasins de sneakers de La Perle). Nous ne les donnons pas : elles ne figurent que dans un ou deux guides, ou sont attribuées à des lieux qui ne concordent pas. Un code publié à tort ferait perdre du temps ; nous les ajouterons quand trois guides concordent. Les liens vers les missions concernées se trouvent sur la page missions.

Questions fréquentes

Quel est le code du coffre du bowling de GTA 6 ?

Le coffre du bureau de Kingpin Bowling, à Port Gellhorn, s'ouvre avec 0300. Le code est inscrit sur la carte murale de Brooks Boatworks. Il faut saisir les quatre chiffres, zéro compris.

Les codes des coffres changent-ils d'une partie à l'autre ?

Les coffres de missions et de planques de gang sont fixes d'après la plupart des guides, mais certains signalent des écarts selon les sauvegardes. Les coffres de magasins et de banques sont, eux, aléatoires.

Que faire si un code ne marche pas ?

Vérifiez que vous avez saisi les quatre chiffres, puis cherchez l'indice dans votre partie : note, carte murale ou ordinateur. L'indice affiché chez vous a priorité sur toute liste.

Comment avoir le code d'un coffre de magasin ?

Menacez un employé jusqu'à l'invite « Code du coffre ? », ou cherchez une note ou un post-it près du coffre. La combinaison change à chaque braquage, inutile de la mémoriser.
