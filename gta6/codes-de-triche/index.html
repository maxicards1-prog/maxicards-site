Lire le tableau

  • Combinaison : les flèches de la croix directionnelle, à taper dans l'ordre. Elles sont identiques sur PS5 et Xbox.
  • Comment le débloquer : le défi à réussir pour que le code fonctionne. Un code tapé avant son défi ne fait rien.
  • Confirmé : les six guides que nous suivons donnent exactement la même combinaison.
  • Confirmé, variante signalée : au moins quatre guides donnent la même combinaison, mais une variante circule. Si la nôtre ne marche pas, vérifiez d'abord que le défi est réussi.
  • Pas encore trouvé : le code existe dans le menu du jeu, mais personne n'a encore publié de combinaison fiable. Nous l'ajoutons dès qu'elle est recoupée.

Les codes les plus utiles

Questions fréquentes

Combien y a-t-il de codes de triche dans GTA 6 ?

61 codes : 10 pour le joueur, 11 de combat, 21 de véhicules, 3 de météo et d'heure, 16 filtres d'écran. 17 combinaisons sont connues au 23/11/2026.

Les codes sont-ils les mêmes sur PS5 et Xbox ?

Oui, les combinaisons de flèches sont les mêmes. Seules les touches pour ouvrir la saisie changent : L1 puis R1 sur PS5, LB puis RB sur Xbox.

Pourquoi mon code ne marche pas ?

Trois raisons possibles : l'histoire principale n'est pas terminée, le défi qui débloque ce code n'est pas réussi, ou une flèche a été mal tapée. Vérifiez le menu Progression, onglet Codes de triche.

Peut-on taper les codes au clavier ou avec un numéro de téléphone ?

Non. Contrairement à GTA 5, les codes de GTA 6 se tapent uniquement avec les flèches de la croix directionnelle. Une liste avec des mots ou des numéros est fausse.
