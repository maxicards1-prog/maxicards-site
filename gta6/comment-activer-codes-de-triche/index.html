Comment activer un code de triche dans GTA 6

Mis à jour le 23/11/2026

Les touches exactes sur PS5 et Xbox, les deux conditions pour qu'un code marche, et ce qu'il bloque.

Les touches, pas à pas

ÉtapePS5Xbox Series X|S
1. Sortir le téléphone↑ sur la croix directionnelle↑ sur la croix directionnelle
2. Ouvrir la saisiemaintenir L1 puis appuyer sur R1maintenir LB puis appuyer sur RB

Les guides ne décrivent pas tous l'étape 2 de la même façon : certains disent de maintenir les deux boutons ensemble. Si la saisie ne s'ouvre pas, gardez L1 et R1 (ou LB et RB) enfoncés pendant toute la saisie. Utilisez la croix directionnelle, pas le stick.

Deux conditions avant qu'un code marche

  1. Finir l'histoire principale. Le menu des codes reste fermé pendant toute l'histoire de Jason et Lucia (91 missions).
  2. Réussir le défi du code. Chaque code a son défi : 100 séances d'entraînement pour le gilet pare-balles, 25 médailles d'or aux stands de tir pour « pas de rechargement », etc. La liste est dans le menu Progression, onglet Codes de triche, et dans notre tableau des 61 codes. Les objectifs remplis pendant l'histoire comptent déjà.

Ce que le code bloque

Attention : activer un code désactive la sauvegarde, les trophées (PS5) et les succès (Xbox) jusqu'à ce que vous quittiez la partie. Sauvegardez à la main avant de tricher.
  • Pendant la session où un code est actif, impossible de sauvegarder, et les trophées et succès ne tombent plus.
  • Pour tout retrouver, quittez la partie puis rechargez une sauvegarde propre.
  • Conséquence : ce que vous gagnez pendant une session avec triche, y compris les 250 000 $ du code d'argent, n'est pas conservé.
  • Conseil : faites une sauvegarde manuelle sur un emplacement à part avant de tricher, et ne trichez pas sur la partie qui vise le platine.

Et sur PC ou en ligne ?

Il n'y a pas encore de version PC (voir ici), ni de GTA Online pour GTA 6. Les codes ne concernent que le mode histoire sur PS5 et Xbox Series.

Questions fréquentes

Comment mettre un code de triche dans GTA 6 sur PS5 ?

Appuyez sur la flèche du haut pour sortir le téléphone, maintenez L1 puis appuyez sur R1, et tapez la combinaison avec la croix directionnelle. Le code doit être débloqué et l'histoire terminée.

Comment mettre un code de triche dans GTA 6 sur Xbox ?

Même méthode qu'avec la PS5 : flèche du haut pour le téléphone, maintenir LB puis appuyer sur RB, puis la combinaison à la croix directionnelle.

Les codes désactivent-ils les trophées ?

Oui, pour toute la session de jeu : trophées, succès et sauvegarde sont bloqués. Quittez la partie et rechargez une sauvegarde pour les retrouver.

Peut-on utiliser les codes pendant l'histoire ?

Non. Le menu des codes de triche ne s'ouvre qu'une fois l'histoire principale terminée.
