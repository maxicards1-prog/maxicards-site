Pourquoi GTA 6 n'a pas de disque ?

Mis à jour le 24/11/2026

La version physique de GTA 6 sur PS5 et Xbox Series ne contient pas de disque : la boîte renferme un code de téléchargement.

Rockstar l'a confirmé, et aucun disque n'est prévu pour l'instant.

Ce qu'il y a vraiment dans la boîte

Rockstar a confirmé que les exemplaires physiques de GTA 6 sont du type « code dans une boîte » : l'étui contient un code à entrer sur votre compte, pas un disque jeu. Cela vaut pour la PS5 et pour la Xbox Series X|S, et pour les éditions Standard et Ultimate. Nous n'avons trouvé aucune raison officielle donnée par Rockstar ; les articles de presse n'avancent que des hypothèses, que nous ne reprenons pas. Le format a été annoncé dès l'ouverture des précommandes en juin, puis rappelé par plusieurs médias jusqu'à la sortie, et le jeu a bien été lancé le 19 novembre sur ce modèle, avec des boîtes disponibles en magasin quelques jours avant pour permettre le préchargement.

Un disque est-il prévu plus tard ?

Une rumeur avait annoncé un disque en décembre. D'après le Hollywood Reporter, repris par VGC, aucun disque n'est prévu, ni au lancement ni dans les mois suivants, et un message d'assistance de Rockstar parlant d'une copie physique « dans les mois suivants » désignait la version avec code. Ne comptez donc pas sur un disque pour l'instant.

Ce que cela change en pratique

  • Il faut télécharger le jeu : environ 210 Go, voyez la taille du jeu.
  • Le code ne se revend pas : une fois utilisé, il est lié à un compte. La boîte et l'illustration restent à vous.
  • Prévoyez le bon compte. Utilisez le code sur le compte qui doit posséder le jeu. Sur PS5, un code peut n'être utilisable que dans le pays d'achat.

Comment offrir GTA 6

La boîte peut s'offrir comme n'importe quel jeu : la personne qui la reçoit utilise le code sur son propre compte. Contrôlez l'emballage à l'achat, car aucun disque ne sert de solution de secours. Pour éviter les arnaques, lisez aussi notre page sur les faux codes et arnaques.

Codes manquants ou déjà utilisés

Des acheteurs ont signalé des boîtes sans code ou avec un code déjà utilisé, chez des revendeurs et sur la boutique de Rockstar. Rockstar n'a pas confirmé de problème général. Sony renvoie ces clients vers le revendeur, y compris pour un remboursement. Gardez donc le ticket, et lisez comment se faire rembourser GTA 6.

Pour jouer, vérifiez ensuite votre console.

Questions fréquentes

Pourquoi GTA 6 n'a pas de disque ?

Rockstar a confirmé une version physique avec un code de téléchargement et sans disque. Aucune raison officielle n'a été donnée.

Y aura-t-il un disque de GTA 6 plus tard ?

Rien n'est prévu : la rumeur d'un disque en décembre a été démentie, d'après les articles de VGC et du Hollywood Reporter.

Peut-on offrir GTA 6 en version physique ?

Oui, la boîte s'offre, mais la personne devra utiliser le code sur son compte pour télécharger le jeu.

Que faire si le code de la boîte est déjà utilisé ?

Contactez le revendeur : Sony renvoie vers lui pour un remplacement ou un remboursement.
