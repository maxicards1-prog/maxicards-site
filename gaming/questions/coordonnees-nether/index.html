Comment calculer les coordonnées du Nether ?

Page mise à jour le 26/11/2026.

Divisez X et Z par 8, arrondissez vers le bas et gardez Y : X 1 000, Z −250 dans l'Overworld correspondent à X 125, Z -32 dans le Nether.

Pour vos propres réglages, utilisez l'outil Coordonnées Nether : il affiche le résultat et le calcul écrit.

Pourquoi 8

Dans Minecraft, chaque bloc parcouru dans le Nether compte pour 8 blocs dans l'Overworld, à l'horizontale. C'est ce qui rend le Nether si pratique pour voyager : une base à 4 000 blocs du point de départ n'est qu'à 500 blocs par le Nether. La hauteur, elle, n'est pas multipliée.

Exemples

Overworld (X ; Z)Nether (X ; Z)
800 ; 160100 ; 20
1 000 ; -250125 ; -32
-4 000 ; 2 400-500 ; 300
13 ; -131 ; -2
-7 ; 7-1 ; 0

Attention aux nombres négatifs

Arrondir vers le bas veut dire aller vers le nombre plus petit : −31,25 devient −32, pas −31. De même, −0,875 devient −1. C'est la règle du jeu, et l'erreur la plus fréquente quand on calcule de tête.

Dans l'autre sens

Du Nether vers l'Overworld, multipliez X et Z par 8. Le résultat n'est pas un point unique : un bloc du Nether correspond à un carré de 8 × 8 blocs dans l'Overworld. X 125 dans le Nether couvre ainsi X 1 000 à 1 007 dans l'Overworld.

Les repères à retenir

1 000 blocs dans l'Overworld font 125 blocs dans le Nether, et 8 000 blocs en font 1 000. Le calcul se fait sur X et sur Z séparément : une base à X 2 400, Z 800 se rejoint dans le Nether en X 300, Z 100.

Où lire ses coordonnées

En édition Java, la touche F3 affiche la ligne XYZ. En Bedrock, activez l'affichage des coordonnées dans les paramètres du monde.
