How to learn Roblox scripting (Luau)

The short answer

Roblox games are scripted in Luau, a language derived from Lua. The easiest way in is to follow the free Creator Hub tutorials, inside Roblox Studio, starting with small scripts.

Updated November 24, 2026

How to use it

  1. Install Roblox Studio. Code is written in Studio, which is free. See our guide to making a game if you have not done it yet.
  2. Do the basic tutorials. The Creator Hub offers basic scripting tutorials: deadly lava, a disappearing trap, score points. They are short and very concrete.
  3. Move on to intermediate tutorials. Next come topics like a health pickup or saving player data.
  4. Read the language reference. The Luau page of the documentation describes types (numbers, text, tables), functions and control structures: come back to it when you get stuck.
  5. Tweak a small project of your own. Take your own mini-game and add one feature at a time. You remember by tinkering.

What is Luau?

According to the official documentation, Luau is “a fast, small, safe, gradually typed scripting language” derived from Lua 5.1. It is the language used in Roblox Studio to write how a game behaves: scores, doors, shops, enemies.

A progression that works

Do not try to read everything. Here is a simple order:

  1. Variables and text: store a score, display a message.
  2. Conditions: “if the player touches the lava, then…”.
  3. Functions: group actions so you can reuse them.
  4. Tables: keep lists of items or players.
  5. Events: react when a player arrives, touches or clicks.

Free official resources

As of Nov 23, 2026, the Creator Hub offers in particular: the “Create your first game” tutorial, use-case tutorials (UI gauges, hinged doors, camera, input detection) and a “Gameplay scripting” path for organizing the logic of a bigger project. The Luau page also lists data types, control structures and script editor help (autocomplete, type checking).

Good habits

  • Test after every small change.
  • Read error messages: they give the line number.
  • Do not paste code you do not know into your game: a script you do not understand can contain unwanted things.
  • Set tiny goals: “make a coin counter” rather than “make a game like X”.

And then?

When your small game works, you can publish it. For the big picture, first read how to make a Roblox game. Mostly want inspiration from existing games? See our best Roblox games.

Frequently asked questions

What language does Roblox use?

Roblox uses Luau, a scripting language derived from Lua 5.1, according to the official documentation.

Do I need to speak English to learn Luau?

The official Creator Hub documentation is mostly in English, and the concepts are the same everywhere. Knowing basic English helps a lot.

Where do I start to code on Roblox?

With the basic scripting tutorials in the Creator Hub (deadly lava, score points), then the intermediate tutorials.

Is it free to learn to code on Roblox?

Yes: Roblox Studio and the official documentation are free.
