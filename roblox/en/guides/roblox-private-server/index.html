How to make a private server on Roblox

The short answer

On the game's page, scroll to the Servers section and click Create Private Server, if the creator has turned the option on. The price, which may be zero, is set in Robux by the creator and renews every month.

How to use it

  1. Open the game page. In the app or on the website, open the experience's page.
  2. Scroll to Servers. The Servers section is at the bottom of the page. If the creator enabled private servers, you see Private Servers.
  3. Click Create Private Server. Name your server and read the subscription agreement.
  4. Confirm the purchase. Click Buy Now to finish. You can configure the server right away or later.
  5. Invite your friends. In the three-dot menu, choose Configure: you can allow up to 50 people or your friends list, and create a link.

How much does a private server cost?

According to the official help page (checked 11/24/2026), private server prices are set in Robux by the game's creator. There is an initial charge when you buy, then a monthly charge on the same date each month, taken automatically from your Robux balance. The renewal date appears on the configuration page. Some games offer a free private server, but Roblox limits the number of active free servers: if an error appears, deactivate one before creating another. To convert a price into euros, use the Robux to euro converter.

Why don't I see Create Private Server?

The button only appears if the creator has turned private servers on for that game. Not every game does. Creators can read how to publish a Roblox game for their experience settings.

Who can join my server?

By default, users under 13 can only join their friends' private servers, and only their friends can join theirs. Users 13 and over can also limit who can add them to private servers. Games to play with friends are a natural fit for private servers.

How do I cancel it?

Cancel before the renewal date: in Servers, open the three-dot menu to the right of your server, then Cancel, read the agreement and click "Yes, cancel". You keep the server until the end of the period you already paid for, shown by the expiration date. For a child, consider limiting spending, because the subscription renews by itself.

Frequently asked questions

How do I create a private server in a Roblox game?

Game page, Servers section, Create Private Server, name the server, then Buy Now, if the creator enabled private servers.

Do Roblox private servers cost money?

The price is set in Robux by the creator, with a monthly charge. Some games offer a free one.

How do I invite friends to a private server?

Server menu, Configure: pick up to 50 players, or your whole friends list, or create a link.

How do I stop a private server subscription?

In Servers, open the server menu, choose Cancel, then Yes, cancel, before the renewal date.
