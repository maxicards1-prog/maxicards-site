Nom d'affichage Roblox : différence avec le pseudo

Le nom d'affichage est le nom que les autres voient dans les jeux et sur votre profil. Il se change gratuitement, une fois tous les 7 jours, contrairement au pseudo.

Mis à jour le 23/11/2026

L'outil gratuit qui va avec :
Générateur de pseudosVérifier un pseudo

Comment faire

  1. Ouvrir les paramètres. Connecté, cliquez sur l'engrenage en haut à droite du site, ou sur les trois points (More) dans l'application.
  2. Account Info. Ouvrez l'onglet Account Info (Informations du compte).
  3. Change Display Name. Cliquez sur le bouton Change Display Name, une icône de crayon et de papier.
  4. Saisir le nom. Tapez le nouveau nom d'affichage.
  5. Enregistrer. Cliquez sur Save. Actualisez la page : le nouveau nom apparaît à côté de votre pseudo.

Pseudo et nom d'affichage : la différence

Votre pseudo (nom d'utilisateur) est l'identifiant unique de votre compte : personne d'autre ne peut avoir le même, et le changer coûte des Robux. Votre nom d'affichage est un nom plus personnel, que Roblox montre dans les jeux et sur votre profil, et qui se change gratuitement. Dans certaines versions de l'application, le nom d'affichage est simplement appelé « Name » (Nom).

Les règles du nom d'affichage

  • Il peut être changé une seule fois tous les sept jours.
  • Il doit respecter les règles de la communauté et les conditions d'utilisation, sinon Roblox peut le remplacer par votre pseudo.
  • Il est filtré comme tout texte sur la plateforme : un nom inapproprié est refusé.
  • Votre nom d'affichage et votre pseudo restent visibles sur Roblox et dans les jeux associés.
  • Roblox teste en bêta, pour une partie des utilisateurs, la prise en charge des caractères japonais.

Trouver un bon nom

Un nom d'affichage doit rester respectueux et ne pas contenir d'informations personnelles : pas de vrai nom, d'école ou d'adresse. Pour trouver de l'inspiration, utilisez notre générateur de pseudos. Le vérificateur de pseudo contrôle le format d'un pseudo, pas d'un nom d'affichage, et ne dit pas si le nom est libre.

Quand changer le pseudo plutôt que le nom d'affichage ?

Si le but est seulement d'afficher un autre nom aux autres joueurs, le nom d'affichage suffit. Si vous voulez modifier l'identifiant de connexion, suivez le guide changer de pseudo Roblox.

Sécurité

Un nom d'affichage ne protège pas le compte. Pensez à activer la vérification en deux étapes : lisez sécuriser son compte Roblox.

Questions fréquentes

Peut-on changer son nom d'affichage Roblox gratuitement ?

Oui, c'est gratuit, mais une seule fois tous les 7 jours.

Quelle est la différence entre pseudo et nom d'affichage ?

Le pseudo est l'identifiant unique du compte et se change contre des Robux. Le nom d'affichage est un nom visible, gratuit, que d'autres joueurs peuvent aussi porter.

Pourquoi mon nom d'affichage est revenu à mon pseudo ?

Roblox peut réinitialiser un nom d'affichage qui ne respecte pas les règles de la communauté ou les conditions d'utilisation.

Où change-t-on son nom d'affichage sur mobile ?

Dans l'application : More (trois points), engrenage, Account Info, puis Change Display Name.
