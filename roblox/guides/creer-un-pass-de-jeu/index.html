Créer un pass de jeu Roblox

La réponse en bref

Un pass de jeu se crée dans le Creator Hub, sous Monetization puis Passes, une fois le jeu publié. Il s'achète une seule fois avec des Robux, et le créateur reçoit 70 % des Robux dépensés d'après la documentation officielle.

Mis à jour le 23/11/2026

L'outil gratuit qui va avec :
Gains de vente

Comment faire

  1. Publier votre jeu. Le pass se crée pour un jeu déjà publié. Voyez notre guide si besoin.
  2. Ouvrir la page des passes. Dans Creations, sélectionnez votre jeu, puis allez dans Monetization > Passes.
  3. Créer le pass. Cliquez sur Create pass. Importez une icône (512 x 512 pixels au maximum, formats .jpg, .png ou .bmp, détails importants dans le cercle).
  4. Nommer et décrire. Saisissez un nom et une description clairs, puis choisissez une catégorie : elle sert à organiser votre boutique en jeu.
  5. Valider et mettre en vente. Cliquez sur Create pass. Dans le jeu, la vente passe par MarketplaceService (par exemple PromptGamePassPurchase()). Hors du jeu, le pass doit être marqué « Listed » dans Monetization > Shop.

Ce qu'est un pass de jeu

Un pass offre un avantage permanent : un accès à une zone, un objet exclusif, une couleur de pseudo. La documentation précise qu'il ne s'achète qu'avec des Robux et qu'une seule fois par joueur. Pour un achat répétable (monnaie du jeu, par exemple), Roblox propose les « produits de développeur », qui rapportent généralement davantage.

Combien touche le créateur ?

Au 23/11/2026, la page « How do I make money? » indique, pour les achats dans un jeu : « vous recevez 70 % des Robux dépensés », les 30 % restants étant les frais de Marketplace de Roblox. Pour estimer ce que représente un prix, utilisez notre calculateur de gains de vente. Cette règle s'applique aux achats dans un jeu ; la vente d'objets d'avatar sur la Marketplace suit d'autres règles, expliquées dans notre guide sur les vêtements et objets UGC.

Comment choisir le prix ?

Le guide officiel ne fixe pas de prix minimum ou maximum général. Un repère : pour qu'un pass soit mis en avant sur la page d'achat de Robux, il doit valoir plus de 49 Robux et moins de 801 Robux. Pour le reste, quelques conseils de bon sens :

  • proposez un avantage clair, sans gêner les joueurs qui ne paient pas ;
  • commencez par un prix modeste, vous pourrez le modifier ;
  • décrivez précisément ce que le pass contient.

Les points d'attention

  • À partir du 30 mai 2026, les ventes de passes entre jeux (inter-jeux) sont désactivées, selon la documentation.
  • Ne promettez jamais de gains : beaucoup de jeux ne vendent presque rien au début.
  • Les joueurs sont souvent mineurs : évitez la pression à l'achat. Les parents trouveront nos conseils pour limiter les dépenses.

Pour vendre, il faut d'abord un jeu public : voyez comment publier un jeu puis comment le faire connaître. Et pour convertir vos Robux gagnés en euros, lisez notre page sur le DevEx.

Questions fréquentes

Combien de Robux touche-t-on sur un pass de jeu ?

D'après la documentation officielle consultée le 23/11/2026, le créateur reçoit 70 % des Robux dépensés dans son jeu, Roblox gardant 30 %.

Quel prix pour un pass Roblox ?

Il n'y a pas de prix imposé dans le guide officiel. Pour apparaître sur la page d'achat de Robux, un pass en vente doit valoir plus de 49 et moins de 801 Robux.

Un joueur peut-il acheter plusieurs fois le même pass ?

Non, un pass ne s'achète qu'une fois. Pour les achats répétables, Roblox propose les produits de développeur.

Faut-il un jeu publié pour créer un pass ?

Oui, le jeu doit déjà être publié pour créer un pass dans le Creator Hub.
