Comment signaler un joueur sur Roblox ?

La réponse en bref

Dans le jeu, ouvrez le menu en haut à gauche, cliquez sur l'icône drapeau à côté du nom du joueur, choisissez le motif et envoyez. Signalez le message ou le contenu précis, pas seulement le profil : sinon les modérateurs ne voient pas ce qui a été fait.

Mis à jour le 23/11/2026

Comment faire

  1. Ouvrir le menu du jeu. Cliquez sur l'icône Roblox en haut à gauche de l'écran.
  2. Choisir le joueur. Cliquez sur l'icône drapeau à côté de son nom, ou sur l'onglet Report.
  3. Sélectionner « Person ». Puis choisissez le joueur dans « Which Person? ».
  4. Indiquer le motif. Choisissez la raison dans « Reason for Abuse? » et ajoutez une courte description.
  5. Envoyer. Cliquez sur Submit. Pour couper tout contact, bloquez aussi le joueur.

Pourquoi signaler dans le jeu

La page d'aide officielle (consultée le 24/11/2026) explique que la fonction Report Abuse envoie le signalement directement aux modérateurs. Elle insiste sur un point : il faut signaler le chat, le message privé ou le contenu précis qui enfreint les règles. Si vous signalez seulement un joueur depuis son profil, les modérateurs ne peuvent pas voir ce qu'il a fait de mal.

Signaler en dehors d'un jeu

  • Une expérience entière : bouton rouge Report Abuse dans la description, sur la page About du jeu.
  • Un objet (vêtement, pass, modèle) : les trois points en haut à droite de sa fiche, puis Report item.
  • Un message de chat : dans l'application mobile, l'icône (i) en haut à droite, puis le participant, puis Report Abuse.

Bloquer un joueur

Pour bloquer, ouvrez le profil, cliquez sur les trois points en haut à droite, puis sur Block User. Dans une partie, vous pouvez aussi bloquer depuis la liste des joueurs ou le menu Echap, onglet People. Quand vous bloquez quelqu'un, il n'est pas prévenu, vous n'êtes plus amis, et vous ne pouvez plus vous écrire ni vous inviter. Les parents peuvent bloquer les amis de leur enfant depuis les contrôles parentaux : voir contrôle parental Roblox.

Cas graves

En cas de menace, de harcèlement ou de contenu choquant visant un mineur, gardez des captures d'écran et signalez aussi à un adulte de confiance. En France, l'association e-Enfance propose une aide. Pour voir comment Roblox protège les plus jeunes, lisez Roblox est-il dangereux ?.

Sources

Pages d'aide Roblox : How to Report Rule Violations et How to block another user (consultées le 24/11/2026).

Questions fréquentes

Comment bloquer quelqu'un sur Roblox ?

Profil du joueur, trois points, Block User. Dans une partie, via la liste des joueurs ou le menu Echap, onglet People.

Le joueur bloqué est-il prévenu ?

Non, Roblox précise qu'il n'est pas notifié.

Comment signaler quelqu'un dans le chat vocal ?

Utilisez Report Abuse et précisez « Voice Chat » : le signalement part aux modérateurs de Roblox.

Un parent peut-il bloquer un ami de son enfant ?

Oui, depuis Paramètres, Parental Controls, section Friends, bouton Manage, puis Block.
