Comment apprendre à coder sur Roblox (Luau)

Sur Roblox, on programme en Luau, un langage dérivé de Lua. Le plus simple est de suivre les tutoriels gratuits du Centre des créateurs, dans Roblox Studio, en commençant par de petits scripts.

Mis à jour le 23/11/2026

Comment faire

  1. Installer Roblox Studio. Le code s'écrit dans Studio, qui est gratuit. Reportez-vous à notre guide pour créer un jeu si ce n'est pas encore fait.
  2. Faire les tutoriels de base. Le Centre des créateurs propose des tutoriels de scripting de base : lave mortelle, piège qui disparaît, points de score. Ils sont courts et très concrets.
  3. Passer aux tutoriels intermédiaires. Ensuite viennent des sujets comme un objet de soin à ramasser ou la sauvegarde des données du joueur.
  4. Lire la référence du langage. La page Luau de la documentation décrit les types (nombres, texte, tables), les fonctions et les structures de contrôle : on y revient quand on bloque.
  5. Modifier un petit projet à vous. Prenez votre propre mini-jeu et ajoutez une fonction à la fois. C'est en bricolant qu'on retient.

Qu'est-ce que Luau ?

D'après la documentation officielle, Luau est « un langage de script rapide, petit, sûr et typé progressivement », dérivé de Lua 5.1. C'est le langage utilisé dans Roblox Studio pour écrire le comportement d'un jeu : scores, portes, boutiques, ennemis.

Une progression qui marche

Ne cherchez pas à tout lire. Voici un ordre simple :

  1. Variables et textes : stocker un score, afficher un message.
  2. Conditions : « si le joueur touche la lave, alors… ».
  3. Fonctions : regrouper des actions pour les réutiliser.
  4. Tables : garder des listes d'objets ou de joueurs.
  5. Événements : réagir quand un joueur arrive, touche ou clique.

Les ressources officielles gratuites

Au 23/11/2026, le Centre des créateurs propose notamment : le tutoriel « Create your first game », des tutoriels de cas d'usage (jauges d'interface, portes à charnière, caméra, détection des entrées) et un parcours « Gameplay scripting » pour organiser la logique d'un projet plus gros. La page Luau liste aussi les types de données, les structures de contrôle et l'aide de l'éditeur de scripts (complétion automatique, vérification de types).

Les bons réflexes

  • Testez après chaque petite modification.
  • Lisez les messages d'erreur : ils indiquent le numéro de ligne.
  • Ne collez pas du code inconnu dans votre jeu : un script que vous ne comprenez pas peut contenir des choses indésirables.
  • Fixez-vous des objectifs minuscules : « faire un compteur de pièces » plutôt que « faire un jeu comme X ».

Et ensuite ?

Quand votre petit jeu fonctionne, vous pouvez le publier. Pour la vue d'ensemble, lisez d'abord comment créer un jeu Roblox. Vous voulez surtout vous inspirer de jeux existants ? Voyez nos meilleurs jeux Roblox.

Questions fréquentes

Quel langage utilise Roblox ?

Roblox utilise Luau, un langage de script dérivé de Lua 5.1, d'après la documentation officielle.

Faut-il parler anglais pour apprendre le Luau ?

La documentation officielle du Centre des créateurs est surtout en anglais, mais des outils de traduction du navigateur aident. Les concepts restent les mêmes.

Par quoi commencer pour coder sur Roblox ?

Par les tutoriels de scripting de base du Centre des créateurs (lave mortelle, points de score), puis les tutoriels intermédiaires.

Est-ce gratuit d'apprendre à coder sur Roblox ?

Oui : Roblox Studio et la documentation officielle sont gratuits.
