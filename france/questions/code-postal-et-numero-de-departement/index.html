Le code postal donne-t-il le numéro du département ?

Oui, sauf en Corse (codes en 20), outre-mer (971 à 976) et pour quelques communes frontalières.

Mis à jour le 26/11/2026 · chiffres officiels en vigueur au 1er janvier 2026.

Oui, dans presque tous les cas : les deux premiers chiffres du code postal sont le numéro du département. Il y a trois exceptions : la Corse (codes en 20), l'outre-mer (trois chiffres : 971 à 976) et 21 communes dont le courrier part d'un bureau du département voisin.

La Corse

Les communes de Corse-du-Sud (2A) et de Haute-Corse (2B) ont toutes des codes postaux en 20xxx, l'ancien numéro du département unique. Voir pourquoi le 20 n'existe plus.

L'outre-mer

Le code postal commence par les trois chiffres du département : 97100 pour Basse-Terre (Guadeloupe), 97200 pour Fort-de-France, 97300 pour Cayenne, 97400 pour Saint-Denis de La Réunion, 97600 pour Mamoudzou.

Code postal ou code commune ?

Le code commune de l'INSEE (5 caractères aussi) commence toujours par le numéro exact du département, 2A et 2B compris : 2A004 pour Ajaccio, 01053 pour Bourg-en-Bresse. Il sert aux statistiques et aux formulaires administratifs, pas au courrier.

Questions fréquentes

Pourquoi certaines communes ont-elles le code d'un autre département ?

Parce que leur courrier est distribué par un bureau de poste situé dans le département voisin.

Le code commune INSEE est-il le code postal ?

Non. Le code commune de l'INSEE sert aux statistiques ; seul le code postal sert au courrier.
