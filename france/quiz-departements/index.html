    Quatre jeux de 10 questions pour apprendre les numéros, les préfectures et la place des départements sur la carte.

    Mis à jour le 26/11/2026 · tout se calcule dans votre navigateur, rien n'est envoyé.

    Les quatre jeux

    • Numéro → nom : un numéro s'affiche, choisissez le bon département parmi quatre.
    • Nom → numéro : l'inverse, pour retenir les numéros.
    • Préfectures : trouvez la préfecture du département.
    • Sur la carte : cliquez sur le département demandé. Les numéros sont cachés.

    Comment progresser

    Chaque série tire 10 départements au hasard parmi les 101. Après chaque réponse, la bonne réponse s'affiche : c'est le moment de la retenir. Votre meilleur score à chaque jeu est gardé dans ce navigateur seulement ; rien n'est envoyé. Pour une méthode complète, lisez comment apprendre les départements.

    Questions fréquentes

    Mon score est-il enregistré ?

    Seul votre meilleur score de chaque jeu est gardé, dans votre navigateur (stockage local). Il n'est envoyé nulle part.

    Les questions sont-elles toujours les mêmes ?

    Non : chaque série tire 10 départements au hasard, et les mauvaises réponses proposées changent aussi.
