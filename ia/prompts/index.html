Comment ces prompts sont construits

Les 210 prompts de cette bibliothèque suivent tous la même structure : un rôle pour l'IA, une tâche précise, le contexte à compléter entre [crochets], des contraintes et le format de réponse attendu. Beaucoup se terminent par « pose-moi d'abord les questions qui te manquent » : l'IA vous demande les informations utiles au lieu de les inventer.

Ils fonctionnent avec ChatGPT, Claude, Gemini, Microsoft Copilot et Le Chat de Mistral, en version gratuite comme payante.

Trois règles avant de coller un prompt

  1. Ne collez pas de données personnelles (noms d'élèves, de clients, de candidats, données de santé) ni de secrets d'entreprise : anonymisez d'abord.
  2. Relisez et vérifiez : une IA peut se tromper avec assurance, surtout sur les chiffres, les dates et le droit.
  3. Gardez la décision : l'IA propose, vous choisissez.

Pour écrire vos propres prompts, utilisez le générateur ou faites vérifier un prompt existant par l'analyseur.
