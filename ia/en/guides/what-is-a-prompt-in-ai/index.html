What Is a Prompt in AI?

A prompt is the message you type to ask an AI for something.

In short

Its quality directly shapes the answer.

Short answer. A prompt is the instruction, question or text you send to an artificial intelligence to get a response. It can be one sentence ("Explain VAT") or a long message with context, examples and the format you want. "Prompt engineering" is the practice of writing these instructions so the results are better.

Where the word comes from

"Prompt" means a cue or an invitation to act. In computing, the command prompt is the line that waits for your input. With generative AI the word was kept for what you type, because it is what sets off the answer. You will also hear "request", "instruction" or "query", and the verb "to prompt" is now common.

What a prompt can contain

  • The instruction: what the AI must do (write, summarize, compare, fix, explain).
  • The context: who you are, who the text is for, the situation, the useful data.
  • The constraints: length, tone, reading level, what to avoid.
  • The format: a table, a numbered list, three paragraphs, a two-level outline.
  • An example: a model of the style you want, when style matters.

The official documentation from both OpenAI and Anthropic recommends being precise and explicit, giving context and stating the output format. Anthropic compares its AI to a brilliant colleague who does not know your habits: the more you explain, the better the work.

A weak prompt and a strong prompt

Here is a request written the way most people write it:

Tell me about photosynthesis.

The AI does not know who the answer is for or how long it should be. Here is the same request with the missing pieces:

Explain photosynthesis to a 13-year-old preparing for a science test.

Constraints: 150 words maximum, simple vocabulary, one everyday analogy.
Format: one explanatory paragraph, then three practice questions with answers.

The second version is not "smarter". It simply contains the information that was missing. To learn the method step by step, read how to write a good prompt. To save effort, try the prompt generator, or the prompt improver if you already have a draft.

What does prompt engineering mean?

It is the set of techniques for writing and adjusting prompts: structuring the request, using delimiters to separate the instruction from the text to process, giving examples, asking for a precise format, splitting a task into several steps. OpenAI's documentation has a full section on these practices, and Anthropic's details advice specific to Claude. It does not require technical skills: it is mostly clear writing. There is no magic formula, because the same prompt can give different results from one model to another.

Different kinds of prompts

  • The chat prompt: your message in ChatGPT, Claude or Gemini.
  • Standing instructions: rules that apply to all your conversations. The site has a tool to prepare them: custom instructions.
  • The image prompt: a description used to generate a picture, which follows different rules. See the image prompt generator and the guide to writing Midjourney prompts.

Common mistakes

  • Asking for too many things at once: go step by step in the same conversation.
  • Forgetting the audience: you do not write the same way for a child and for a finance director.
  • Settling for the first answer: a prompt can be corrected ("shorter", "more concrete", "add an example").
  • Not checking: even with an excellent prompt, an AI can be wrong. Reread numbers, dates and names.
  • Pasting personal or confidential data: replace it with brackets such as [name] or [address].

Where to find ready-made examples

If you are starting out, begin with examples: the guide ChatGPT prompt examples offers models to copy, and the prompts by profession page has some for specific jobs. Always adapt the brackets to your situation before sending.

Frequently asked questions

What is a prompt in AI?

It is the instruction, question or text you send to an AI to get an answer. The clearer and more complete it is, the more useful the answer.

What is prompt engineering?

It is the set of techniques for writing good instructions for an AI: context, constraints, format, examples and splitting tasks into steps. OpenAI and Anthropic documentation cover the basics.

Why is it called a prompt?

Because the English word means a cue that sets something off, here the AI's answer. It comes from the command prompt in computing.

How do I prompt an AI effectively?

Say what you want in one sentence, give context, set measurable constraints, ask for a format and add an example if style matters. Then refine in small steps.

Why should a prompt be structured?

Because an AI cannot guess your audience or goal. A clear structure with instruction, context, constraints and format reduces off-target answers.

Which prompt should I use for ChatGPT?

There is no universal prompt. It depends on the task. Start from a model suited to it, such as those in the examples guide, then replace the brackets with your own details.
