What Is Claude AI?

Claude is a conversational assistant built by the company Anthropic.

In short

It writes, summarizes, analyzes and codes from your instructions.

Short answer. Claude is a large language model developed by Anthropic and used as an assistant: you write in plain language and it answers. You can use it in a web browser, in a desktop app for Mac or Windows, or in iOS and Android apps, as long as you are in a supported location and at least 18 years old (official help page, checked on 26/11/2026).

Who is behind Claude

Claude is built by Anthropic, a company that describes itself on its website as a public benefit corporation dedicated to securing the benefits of AI while mitigating its risks. In its help center, Claude is described as a helpful, honest and harmless assistant with a conversational tone.

What Claude can do

Claude's help page explains that you can write to it naturally, as you would to a coworker: simple questions or complex requests, such as multi-step projects, analysis, creative writing, coding or technical tasks. A model selector lets you choose which model you use, and you can adjust how much effort Claude puts into answers. Claude is trained most extensively in English, performs well in many other common languages, and has extensive programming knowledge.

The plans page lists, for the free plan, features such as chat on web, desktop and mobile, web search, file creation, code execution, memory across conversations, connections to your apps, artifacts, plus Claude Design, Slides and Docs (checked 26/11/2026). Plans change, so check the official page before deciding.

How to get started

  1. Open claude.ai in your browser or install the app for your device.
  2. Create an account or sign in. You must be an adult.
  3. Write your request as you would to a colleague, then refine it with follow-up messages.
  4. Use the "+" button or the "/" key to see more options, according to the help page.

For a detailed walkthrough, read how to use Claude. To write better instructions, see how to prompt Claude.

Why Claude is 18+

The help page says you must be at least 18 and in a supported location. We found no detailed explanation of the rule on the pages we read, so treat it as an access condition. Teenagers can look at the guide ChatGPT for teens for a tool with different age rules.

Usage limits

According to the help page (26/11/2026), the free plan has a usage limit per session that resets every five hours, and the number of messages you can send may vary with demand. Paid plans offer more usage. So there is no fixed number of messages per day to remember: it depends on the length of your messages, attached files and traffic. For prices, see the AI subscription comparison.

One more detail: the help page says you cannot import conversation history from other AI providers, but Free, Pro, Max and Ultra users can import memory from them.

Claude and images

We do not claim anything about image generation by Claude: the plans page we read does not mention it, for the free plan or for any other. If you need images, look at the guides on ChatGPT, Gemini's Nano Banana or Midjourney.

A first request to try

To test Claude safely, start from a text you wrote yourself and can judge. For example:

Here is an email I wrote: [paste your text, without names or addresses]. Rewrite it to be clearer and shorter, keep a friendly tone, and tell me in one sentence what you changed.

Then compare it with your original: you will quickly see what Claude does well and what needs fixing. This habit of comparing applies to every assistant.

Good habits

  • Do not paste personal or confidential data without thinking.
  • Always reread: like any AI, Claude can be wrong.
  • Split big requests into steps and correct in small touches.
  • For numbers, dates, law or health, check an official source or a professional.
