What Are Tokens in AI?

A token is the unit an AI uses to read and write text.

In short

It is not exactly a word and not exactly a letter.

Short answer. A token is a piece of text: a character, part of a word, a whole word or a punctuation mark. AI models split everything you type into tokens before processing it, then write their answer one token at a time. The number of tokens measures how long a conversation is and, for developers, how usage is billed.

What a token looks like

According to OpenAI's help center, tokens are the units its models use to process text. A token can be a character, part of a word, a full word or punctuation, and spacing affects how text is split. That is why the token count of a text is never equal to its word count.

For English text, the same page gives three rough rules of thumb: one token is about 4 characters, about three quarters of a word, and 100 tokens are about 75 words. These are estimates, and OpenAI notes that other languages have different ratios. Do not count word for word.

Why tokens matter to you

  • Conversation memory. Anthropic's documentation calls the "context window" everything the model can refer to when answering, including its own reply. Your question, earlier messages, pasted documents and the answer all count. When the window fills up, the start of a long chat can be forgotten or summarized.
  • Usage limits. Consumer plans express their limits in different ways, but a long conversation or a big file uses more of them. The exact rules change, so read the page for your plan.
  • API pricing. Developers who plug an AI into their own app are generally billed by the number of tokens sent and received. Each provider publishes its own rates, and there is no universal value for a token.

How to count tokens

  1. Paste your text into the token counter on this site for an estimate.
  2. For an exact count on a specific model, use the provider's own tool: OpenAI offers an online Tokenizer, and Anthropic documents a token counting API.
  3. To estimate an API cost, take the volume you found and compare it with the provider's pricing page the same day, using the API price calculator.

No third-party number replaces the official count, because each model family splits text its own way.

A concrete example

Take the sentence "Write a summary of this contract in five lines". To the eye it is nine words. To the model it becomes a series of pieces: common words usually stay whole, rarer or longer words may be split, and punctuation counts separately. The total will probably differ from nine, and it will differ from one provider to another. If you then paste a twenty-page contract, thousands of tokens enter the context window before the AI writes a single word.

How to use fewer tokens without losing quality

  • Paste only the passages that matter when your question covers only part of a document.
  • Start a new conversation when the topic changes, so the old history is not re-read.
  • Ask for a short format when you do not need a long answer: "answer in five lines maximum".
  • Cut filler from your prompts. Precision is good; padding is not. Our method for writing a good prompt goes in that direction.

What a token is not

In computing, "token" also means other things: an authentication token, a session identifier or a digital asset. Those have nothing to do with AI tokens, which are simply pieces of text (or, for models that read images, units of computation linked to the image). If a page talks about an "expired token" or an "access token", it is a different subject.

One more point from Anthropic's documentation: as the context grows, accuracy and recall can degrade. Putting ever more text in a conversation is therefore not the best strategy. A well chosen context beats a huge one.

Frequently asked questions

What is a token in AI?

It is the piece of text, a word, part of a word or punctuation, that an AI model reads and writes. The token count measures conversation size and is the basis of API billing.

What is tokenization?

It is the step that splits text into tokens before the model reads it. Each model family has its own splitting, so the same text gives different totals depending on the tool.

How much is a token worth?

There is no single value. It depends on the provider and the model, and prices are published per million tokens on their official pages. Check the pricing page the day you budget.

How many tokens does a prompt use?

It depends on its length, the earlier messages and any attached files, which all count toward the context. A few lines weigh little, while a pasted document can weigh thousands of tokens.

How many tokens do I get on the free Claude plan?

The free plan is not described as a fixed number of tokens. The Claude help page says, as of 26/11/2026, that it has a session-based usage limit that resets every five hours and can vary with demand.
