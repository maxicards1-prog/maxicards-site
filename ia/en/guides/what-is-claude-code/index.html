What Is Claude Code?

Claude Code is a tool that reads your code, edits files and runs commands at your request.

In short

It is aimed mostly at developers.

Short answer. Claude Code is an "agentic" coding assistant from Anthropic: it reads a project, edits files, runs commands and connects to your development tools. It exists in the terminal, in code editors, in a desktop app and in the browser. Most of these require a Claude subscription or an Anthropic Console account (official documentation, checked on 26/11/2026).

Claude Code versus Claude

Claude is the chat assistant described in what is Claude AI: you ask questions and it answers. Claude Code is designed to act on a software project: the official documentation presents it as a tool that understands your whole codebase and can work across multiple files and tools. It is the same provider but a different use, more technical.

What it can do

The official overview page lists uses such as:

  • automating tedious tasks: writing tests for untested code, fixing lint errors across a project, resolving merge conflicts, updating dependencies, writing release notes;
  • building features and fixing bugs: you describe what you want in plain language, it plans the approach, writes code across several files and checks that it works; for a bug, you paste the error message or describe the symptom;
  • working with Git: staging changes, writing commit messages, creating branches and opening pull requests;
  • connecting to other tools through MCP, an open standard for linking AI tools to external data sources;
  • being customized with a project instruction file called CLAUDE.md, reusable skills and hooks that run commands before or after certain actions;
  • running several agents in parallel or scheduling recurring tasks.

How it works

You describe a task, for example "write tests for the auth module, run them and fix any failures". Claude Code explores the project, proposes or applies changes, runs commands and checks the result. You stay in control: you review what changed before accepting it. As with any AI, the result may contain mistakes. In its text on building agents, Anthropic recommends testing in sandboxed environments and keeping human review where it matters.

Where to use it

  1. Terminal: the most complete interface, installed with a command given on the official page.
  2. VS Code and JetBrains: extensions that show changes right inside your editor.
  3. Desktop app: a standalone app to review changes visually and run several sessions; the official page says a paid subscription is required.
  4. Browser: start tasks with no local setup, on claude.ai/code.

Install commands change and depend on your system. Copy them from the official documentation rather than from an old tutorial, and never run a command whose origin you do not know.

Is it for you?

If you do not write code, you do not need Claude Code: the chat assistant is enough to write, summarize or learn. If you are a beginner, you can use it to understand code, but review every change, because an AI can propose code that does not do what you expect. As for cost, it depends on your plan; the free Claude plan does not include Claude Code according to the plans page checked on 26/11/2026. See the AI subscription comparison for the site's reference points.

If you call AI models from your own programs, two tools on this site help you plan volumes and costs: the token counter and the API price calculator. If you wonder what tokens are, read what are tokens in AI.

Speaking to it well

A coding tool is still a language model: it reacts to how clear your instructions are. Name the file or module concerned, the expected behavior, what must not be touched, and how to check the result (a test command, for example). It is the same logic as for any prompt: see how to prompt Claude.

Frequently asked questions
