C'est quoi Le Chat de Mistral AI ?

Le Chat est l'assistant d'intelligence artificielle de Mistral AI.

L'essentiel

Il a changé de nom : Mistral l'appelle désormais Vibe. Voici ce que cela change pour vous.

La réponse en bref : Le Chat est l'assistant IA lancé par Mistral AI. Selon le centre d'aide de Mistral, il est devenu Vibe le 12 août 2026 : même adresse (chat.mistral.ai), même connexion, et votre compte, votre offre et vos conversations suivent. Vibe propose trois modes : Work (productivité), Code (développement) et Chat (la conversation que l'on connaissait).

Le changement de nom, en deux minutes

Si vous cherchiez « Le Chat Mistral » et trouvez « Vibe », vous êtes au bon endroit. Le centre d'aide de Mistral explique que « Le Chat est devenu Vibe », décrit comme l'agent unifié de Mistral pour la productivité et le code. Il précise que rien de ce que vous aviez créé n'est perdu. Les trois modes sont :

  • Vibe Work : le mode productivité, qui reprend ce que faisait Le Chat ; interface web et mobile pour déléguer des tâches complexes en plusieurs étapes à travers vos applications et outils.
  • Vibe Code : un mode pour développeurs, en ligne de commande, en extension VS Code ou en interface web.
  • Vibe Chat : la conversation « tour par tour » pour laquelle Le Chat était connu, toujours disponible.

La documentation détaillée du produit se trouve sur docs.mistral.ai ; le centre d'aide garde les questions de compte, de facturation, de confidentialité et de sécurité.

Ce que l'on peut faire avec

La page de présentation de Mistral mentionne des conversations, des recherches sur le web, la génération et la retouche d'images de base, plus de cent connecteurs vers d'autres outils, et des tâches de longue haleine en mode Work. Pour un particulier, le plus utile reste la conversation : poser des questions, rédiger, traduire, résumer. Le principe est le même qu'avec ChatGPT : plus la demande est précise, meilleure est la réponse. Le générateur de prompt vous aide à la construire.

Gratuit ou payant ?

Il existe une offre gratuite (messages et recherches web limités, génération d'images de base) et des offres payantes. Le prix de l'offre Pro relevé le 23/11/2026 est de 17,99 €/mois. Pour comparer avec les autres assistants, voyez le comparatif des abonnements IA.

Peut-on se fier à ses réponses ?

Mistral écrit lui-même que Vibe peut occasionnellement donner des réponses incorrectes, que les modèles ont une compréhension limitée du monde et des événements, et recommande de vérifier. Il conseille aussi d'énoncer la demande clairement, de donner un maximum de contexte comme à quelqu'un qui découvre le sujet, de découper les demandes complexes, et de signaler une erreur avec le pouce vers le bas. Notre guide ChatGPT est-il fiable ? propose une méthode de contrôle qui s'applique à tous les assistants.

Comment retrouver votre compte

  1. Ouvrez chat.mistral.ai : vous arrivez dans Vibe, d'après Mistral.
  2. Connectez-vous avec le compte que vous utilisiez pour Le Chat.
  3. Retrouvez vos conversations dans l'historique ; choisissez le mode Chat si vous voulez retrouver l'ancienne expérience.

Le comparer aux autres assistants

Pour savoir si Vibe vous convient, comparez sur vos propres demandes. Notre guide pour choisir une IA et le comparatif des abonnements placent Mistral à côté de ChatGPT, Claude et Gemini.

Questions fréquentes

Qu'est-ce que le Chat Mistral ?

C'est l'assistant IA de Mistral AI, devenu Vibe en août 2026 d'après le centre d'aide de Mistral. Il permet de discuter, rechercher sur le web et déléguer des tâches.

Qui est le Chat Mistral ?

Ce n'est pas une personne : c'est l'assistant d'intelligence artificielle de Mistral AI, désormais appelé Vibe, avec les modes Work, Code et Chat.

Comment s'appelle le chat de Mistral ?

Il s'appelait Le Chat ; Mistral l'a renommé Vibe le 12 août 2026. L'adresse chat.mistral.ai et votre connexion sont restées les mêmes.

Que peut-on faire avec le Chat Mistral AI ?

Discuter, rechercher sur le web, générer des images de base, utiliser des connecteurs et, avec le mode Work, déléguer des tâches en plusieurs étapes. Le mode Code vise les développeurs.

Comment fonctionne le Chat Mistral ?

Vous écrivez une demande, l'assistant répond avec un modèle de langage de Mistral. Il peut se tromper : l'aide de Mistral recommande de vérifier les réponses.

C'est quoi le Chat Mistral AI ?

C'est l'ancien nom de Vibe, l'assistant de Mistral AI : un agent pour la productivité et le code, avec les modes Work, Code et Chat.
