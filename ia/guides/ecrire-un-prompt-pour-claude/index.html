Comment écrire un bon prompt pour Claude

D'après la documentation officielle d'Anthropic, Claude répond mieux à des consignes claires, expliquées et structurées. Voici comment l'appliquer, avec des prompts à copier.

Claude est l'assistant d'Anthropic. Sa documentation de prompting décrit une série de techniques : être clair et direct, donner du contexte, utiliser des exemples, structurer avec des balises XML, donner un rôle. Cette page les reprend sous un angle pratique pour une personne qui utilise Claude en conversation, sans programmer. Pour les bases communes à toutes les IA, lisez d'abord la méthode générale.

Comment faire

  1. Soyez explicite sur le résultat voulu. Anthropic note que si vous voulez que Claude aille plus loin que strictement demandé, il faut le demander clairement plutôt que de compter sur une déduction à partir d'une consigne vague.
  2. Expliquez le pourquoi. La documentation donne un exemple parlant : plutôt que « n'utilise jamais de points de suspension », écrire que le texte sera lu à voix haute par un logiciel qui ne sait pas les prononcer. Claude généralise à partir de la raison.
  3. Donnez trois à cinq exemples quand le format ou le ton comptent. C'est le nombre recommandé dans la documentation, avec des exemples variés.
  4. Séparez les types de contenu avec des balises. Les balises XML (par exemple <contexte>, <texte>) aident à ne pas mélanger instructions, documents et exemples.
  5. Placez les longs documents en premier, votre question à la fin, et demandez de citer d'abord les passages utiles.

Le test du collègue

Anthropic propose un test simple : montrez votre prompt à quelqu'un qui ne connaît pas le sujet et demandez-lui d'exécuter la tâche. S'il hésite, Claude hésitera aussi. Prenons un exemple : vous voulez un texte de présentation pour votre association.

Écris un texte de présentation pour mon association.

Version améliorée, avec le contexte et la raison des consignes :

Je suis bénévole dans une association de quartier qui organise un repas partagé chaque premier samedi du mois. Le texte sera imprimé sur un petit flyer, glissé dans les boîtes aux lettres : les lecteurs ne nous connaissent pas et le liront en trente secondes.

Écris-le en 80 mots maximum, ton chaleureux, vouvoiement, sans jargon associatif. Commence par la phrase la plus accrocheuse. Termine par l'adresse [adresse] et l'heure [heure]. Propose-moi deux versions différentes pour que je choisisse.

Le point clé est la deuxième phrase : elle explique pourquoi le texte doit être court. Claude peut alors arbitrer lui-même d'autres détails.

Utiliser des balises pour un document long

La documentation recommande de placer les longs documents au début du prompt, au-dessus de la question, et de les entourer de balises. Voici un modèle pour analyser un compte rendu de réunion (sans données sensibles) :

<document>
[collez ici le compte rendu]
</document>

D'abord, cite les trois passages du document qui comptent le plus pour les décisions à prendre, entre guillemets.
Ensuite, à partir de ces passages seulement, dresse un tableau : décision, responsable, échéance. Si une information manque dans le document, écris « non précisé » au lieu de la déduire.

Demander des citations en premier est une technique citée par Anthropic pour les longs documents : elle aide Claude à se concentrer sur l'essentiel du texte.

Donner des exemples de ce que vous attendez

Les exemples sont décrits comme l'un des moyens les plus fiables de guider le format, le ton et la structure. Supposons que vous classiez des avis de clients :

Classe chaque avis client en « positif », « négatif » ou « mitigé », puis donne le motif principal en trois mots.

Exemples :
Avis : « Livraison rapide, mais l'emballage était abîmé. » -> mitigé ; emballage abîmé
Avis : « Je recommande, très bon accueil. » -> positif ; accueil
Avis : « Jamais reçu ma commande, personne ne répond. » -> négatif ; commande non reçue

Avis à classer :
1. [avis 1]
2. [avis 2]
3. [avis 3]

Les pièges à éviter

  • Les consignes tout en majuscules ou en interdictions. Une raison courte fonctionne mieux qu'un « JAMAIS ».
  • Mélanger consigne et document sans séparation. Les balises ou les le séparateur ### évitent la confusion.
  • Un exemple unique et très particulier. Claude risque de le copier. Variez vos exemples.
  • Croire sans vérifier. Même bien guidé, Claude peut se tromper. Relisez les faits, les chiffres et les citations.
  • Données personnelles. Remplacez noms et adresses par des crochets avant de coller un document.

Sur l'application

Pour des consignes qui valent pour toutes vos conversations (ton, niveau de détail, langue), l'outil instructions personnalisées vous aide à les rédiger ; cherchez ensuite dans les réglages de l'application l'endroit où les enregistrer, car les menus évoluent. Questions fréquentes

Claude comprend-il le français aussi bien que l'anglais ?

Vous pouvez lui écrire en français sans difficulté. Si un résultat est décevant, précisez la langue de réponse souhaitée dans votre prompt et donnez un exemple dans cette langue.

Faut-il vraiment utiliser des balises XML ?

Ce n'est pas obligatoire. La documentation d'Anthropic les recommande surtout pour les prompts qui mélangent instructions, documents et exemples. Pour une demande courte, une phrase claire suffit.

Combien d'exemples donner à Claude ?

La documentation officielle recommande trois à cinq exemples pour de meilleurs résultats, en les variant. Un seul exemple risque d'être recopié trop fidèlement.

Mon prompt marche-t-il aussi sur ChatGPT ou Gemini ?

Les principes de clarté, de contexte et de format sont communs. Les balises sont une habitude propre à Claude, mais d'autres outils s'en accommodent généralement.
