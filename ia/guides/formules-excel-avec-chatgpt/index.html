Écrire des formules Excel avec ChatGPT

ChatGPT peut proposer une formule à partir de la description de votre tableau.

L'essentiel

La qualité de la réponse dépend de la précision de votre description, et vous devez toujours tester le résultat.

  1. Décrivez la structure du tableau
  2. Dites ce que vous voulez obtenir
  3. Précisez votre version d'Excel
  4. Demandez la formule, puis une explication
  5. Testez sur 2 ou 3 lignes

Beaucoup de gens perdent du temps parce qu'ils savent ce qu'ils veulent obtenir dans Excel (« additionner les ventes d'un client pour un mois donné ») mais pas comment l'écrire. Une IA est utile ici : elle traduit une phrase en formule, puis explique chaque morceau. Elle ne voit pas votre fichier, sauf si vous le lui donnez : tout repose donc sur la qualité de votre description.

Comment faire

  1. Décrivez la structure du tableau : quelles colonnes (lettre et titre), à partir de quelle ligne commencent les données, quel type de contenu (dates, montants, texte).
  2. Dites ce que vous voulez obtenir, avec un exemple chiffré tiré de vos données.
  3. Précisez votre version d'Excel et sa langue. Certaines fonctions récentes ne sont pas disponibles partout : selon la page de Microsoft, RECHERCHEX n'est pas disponible dans Excel 2016 et Excel 2019.
  4. Demandez la formule, puis une explication de chaque argument en une phrase.
  5. Testez sur 2 ou 3 lignes dont vous connaissez la bonne réponse, puis étendez à tout le tableau.

Deux formules à connaître

Voici deux fonctions dont la syntaxe française a été relevée sur le site d'aide de Microsoft. Elles servent de repère pour vérifier ce que ChatGPT vous propose.

FonctionSyntaxe officielleÀ quoi elle sert
RECHERCHEXRECHERCHEX(valeur_cherchée; tableau_recherche; tableau_renvoyé; [si_non_trouvé]; [mode_correspondance]; [mode_recherche])Retrouver dans un tableau l'élément qui correspond à une valeur (par exemple le prix d'une référence).
SOMME.SI.ENSSOMME.SI.ENS(somme_plage; plage_critères1; critères1; [plage_critère2; critères2]; …)Additionner les valeurs qui respectent plusieurs conditions à la fois.

Dans RECHERCHEX, l'argument facultatif si_non_trouvé permet d'afficher un texte de votre choix à la place de l'erreur #N/A quand rien ne correspond. Dans SOMME.SI.ENS, la plage à additionner vient en premier.

Séparateur : la page de Microsoft écrit ses exemples avec des virgules entre les arguments. Selon la langue et les réglages de votre Excel, il attendra des virgules ou des points-virgules. Si une formule est refusée, essayez l'autre séparateur.

Un prompt complet à copier

Tu es un expert Excel qui explique simplement.
Mon tableau est dans la feuille « Ventes ». Les titres sont en ligne 1, les données commencent en ligne 2.
Colonne A : date de la vente. Colonne B : nom du client. Colonne C : produit. Colonne D : montant en euros.
Dans une autre feuille « Clients », la colonne A contient le nom du client et la colonne C son adresse e-mail.
Je veux, dans la feuille « Ventes », une colonne E qui affiche l'adresse e-mail du client de chaque ligne, et le texte « client inconnu » si le nom n'est pas dans la feuille « Clients ».
J'utilise Excel pour Microsoft 365 en français.
Donne-moi la formule à écrire en E2, explique chaque argument en une phrase, puis dis-moi comment la recopier jusqu'à la dernière ligne.
Termine par deux erreurs fréquentes qui pourraient apparaître et la façon de les corriger.

Un deuxième exemple : calculer avec plusieurs conditions

Dans la feuille « Ventes » (titres en ligne 1, données de la ligne 2 à la ligne 500), la colonne B contient le client, la colonne C le produit, la colonne D le montant.
Je veux le total des montants pour le client écrit dans la cellule G1 ET pour le produit écrit dans la cellule G2.
Écris la formule pour Excel en français, explique-la, et propose une variante qui compte le nombre de ventes au lieu de les additionner.
Si ma demande est ambiguë, pose-moi d'abord tes questions.

Quand vous avez un fichier plutôt qu'une description

D'après la page d'aide d'OpenAI consultée le 23/11/2026, ChatGPT accepte les tableurs (XLSX, XLS, CSV, TSV, ODS), avec une limite d'environ 50 Mo selon la taille des lignes, et les comptes gratuits sont limités à 3 envois de fichiers par jour. Les limites peuvent changer : vérifiez la page d'aide. Avant d'envoyer un fichier, retirez les données personnelles et confidentielles (noms de clients, adresses, salaires, chiffres internes) ou remplacez-les par des exemples fictifs. Une description des colonnes avec trois lignes inventées suffit souvent pour obtenir une bonne formule.

Erreurs à éviter

  • Une description vague (« fais-moi une formule pour mes ventes ») donne une formule générique qui ne correspond pas à vos colonnes.
  • Copier sans tester : une formule qui ne renvoie pas d'erreur peut quand même donner un mauvais chiffre. Vérifiez sur des lignes dont vous connaissez le résultat.
  • Oublier la version d'Excel : une fonction récente peut ne pas exister chez votre collègue ou dans votre version.
  • Coller des données sensibles sans réfléchir. Voyez aussi notre guide sur ChatGPT et les données personnelles.

Questions fréquentes

ChatGPT peut-il lire mon fichier Excel ?

Selon la page d'aide d'OpenAI, il accepte les formats XLSX, XLS, CSV, TSV et ODS, avec des limites de taille et de nombre d'envois qui dépendent de votre offre. Ne lui envoyez pas de données confidentielles.

Pourquoi la formule proposée ne marche-t-elle pas ?

Les causes fréquentes : une colonne mal décrite, une fonction absente de votre version d'Excel ou un mauvais séparateur d'arguments (virgule ou point-virgule). Collez le message d'erreur exact dans la conversation.

RECHERCHEX est-elle disponible dans toutes les versions d'Excel ?

Non. La page d'aide de Microsoft indique qu'elle n'est pas disponible dans Excel 2016 et Excel 2019. Vérifiez dans votre version.

Dois-je faire confiance au résultat ?

Non, vérifiez-le. Testez la formule sur quelques lignes dont vous connaissez la réponse avant de l'étendre à tout le tableau.
