C'est quoi Copilot de Microsoft ?

Copilot est l'assistant d'intelligence artificielle de Microsoft.

L'essentiel

Selon l'endroit où vous le croisez, ce n'est pas tout à fait le même produit : voici comment s'y retrouver.

La réponse en bref : Copilot est l'assistant IA de Microsoft. Sa version grand public est gratuite : on lui pose des questions, on lui demande d'écrire ou de créer des images, sur le web, en application ou dans le navigateur Edge. Dans les abonnements Microsoft 365, Copilot est aussi intégré à Word, Excel et d'autres applications, avec des limites d'usage.

Une même marque, plusieurs endroits

Le nom « Copilot » recouvre plusieurs usages, d'où la confusion. D'après l'assistance de Microsoft, on peut les distinguer ainsi.

OùDe quoi s'agit-il
Copilot gratuit (site, application, Edge)Un assistant qui donne des réponses directes, aide à écrire et crée des images. Accessible sur copilot.cloud.microsoft, en application (Windows, macOS, iOS, Android) et dans Edge
Application Microsoft CopilotDécrite par Microsoft comme une application d'IA pour le travail : questions, création d'images et de fichiers Word, Excel ou PowerPoint, choix entre plusieurs modèles d'IA, tâches en plusieurs étapes avec Cowork
Copilot dans Microsoft 365Les fonctions IA dans Word, Excel, PowerPoint et Outlook pour les titulaires d'un abonnement Personal, Family ou Premium, avec des limites d'usage
Copilot Chat (travail ou école)Une version pour les organisations, incluse avec certaines licences Microsoft 365 ; les données de travail (fichiers, mails) demandent une licence payante supplémentaire

Ce que l'on peut faire avec Copilot

La page d'assistance de Microsoft sur la version gratuite cite l'aide à la rédaction, le brainstorming, le résumé, des réponses fondées sur une recherche web en temps réel et, dans Edge, des résumés de pages web. L'application Copilot ajoute l'envoi ou la création de fichiers et la délégation de tâches. Pour des idées de demandes, le générateur de prompt et l'annuaire de prompts fonctionnent avec n'importe quel assistant, Copilot compris.

Faut-il un compte ?

Microsoft précise que la connexion n'est pas obligatoire pour la version gratuite, mais qu'en vous connectant avec un compte personnel vous gagnez l'historique des discussions, la création d'images, des conversations plus longues et les échanges vocaux. Vous pouvez vous connecter avec un compte Microsoft, un identifiant Apple ou un compte Google, ou avec un compte professionnel ou scolaire.

Comment l'essayer

  1. Ouvrez copilot.cloud.microsoft dans votre navigateur, ou installez l'application Copilot depuis le Microsoft Store (Windows), l'App Store ou Google Play.
  2. Posez une demande précise, avec le contexte et le format voulus, exactement comme avec ChatGPT.
  3. Relisez, vérifiez les faits, puis demandez des corrections.

Copilot et ChatGPT : ce n'est pas la même chose

Ce sont deux assistants de deux éditeurs différents. La page de l'application Copilot indique qu'elle permet de choisir entre plusieurs modèles d'IA sans les détailler : consultez l'application pour voir lesquels sont proposés chez vous. Pour comparer les usages, lisez quelle IA choisir.

À savoir avant de l'utiliser

  • Les fonctions varient selon le type de compte, le pays, l'appareil et l'abonnement ; Microsoft les fait évoluer souvent.
  • Comme toute IA, Copilot peut se tromper : relisez les faits et ne collez pas de données confidentielles.
  • Si vous ne voulez pas de l'application sur Windows, elle se désinstalle ; quelle IA choisir présente les alternatives.

Informations tirées des pages d'assistance de Microsoft consultées le 26/11/2026.

Questions fréquentes

C'est quoi Copilot 365 ?

C'est Copilot intégré aux applications Microsoft 365 (Word, Excel, PowerPoint, Outlook). Les titulaires d'un abonnement Personal, Family ou Premium l'ont dans les applications de bureau, avec des limites d'usage.

C'est quoi Copilot sur PC ?

C'est l'application Copilot de Windows : un assistant IA que l'on ouvre depuis le PC. Selon Microsoft, elle se désinstalle depuis Paramètres, Applications.

C'est quoi Copilot Cowork ?

Microsoft présente Cowork comme une fonction de l'application Copilot qui permet de déléguer des tâches en plusieurs étapes tout en gardant la main.

Copilot comment utiliser ?

Ouvrez copilot.cloud.microsoft ou l'application, écrivez votre demande en langage courant, puis précisez. Se connecter n'est pas obligatoire, mais ajoute l'historique, les images et la voix.

Copilot comment l'installer ?

Sur Windows, l'application s'obtient via le Microsoft Store ; sur téléphone, via l'App Store ou Google Play. Sur ordinateur, vous pouvez aussi simplement utiliser le site.

Est-ce que Copilot peut générer des images ?

Oui : Microsoft indique que la version gratuite crée des images, et que se connecter avec un compte personnel donne accès à la création d'images.
