Comment installer ChatGPT sur téléphone et ordinateur

Applications officielles, version web, fausses applications à éviter : voici comment installer ChatGPT proprement et ce qu'il faut régler dès la première ouverture.

L'essentiel

ChatGPT s'utilise de plusieurs façons : directement dans le navigateur, ou avec une application.

ChatGPT s'utilise de plusieurs façons : directement dans le navigateur, ou avec une application. Beaucoup de fausses applications imitent son nom dans les boutiques. Ce guide vous montre où trouver les applications officielles, comment les repérer et quoi régler avant de commencer.

Ce que propose l'éditeur

La page de téléchargement officielle (chatgpt.com/download) présente :

  • une application iPhone, à télécharger sur l'App Store d'Apple ;
  • une application Android, à télécharger sur Google Play ;
  • une section de téléchargement pour ordinateur. L'aide officielle d'OpenAI décrit l'application de bureau pour macOS (macOS 14 minimum), disponible aussi pour Windows ;
  • une extension pour le navigateur Chrome sur le Chrome Web Store, qui n'est pas une application de bureau.

Certaines fonctions mobiles sont réservées à des offres payantes : la page de téléchargement précise par exemple que ChatGPT Work sur mobile est réservé aux offres Plus, Pro, Business et Enterprise. Les offres et leurs prix sont dans notre comparatif des abonnements (prix relevés le 23/11/2026).

Comment faire

Sur iPhone ou Android

  1. Ouvrez le navigateur de votre téléphone et saisissez vous-même l'adresse chatgpt.com/download. Ne passez pas par une publicité ou un lien reçu par message.
  2. Touchez le lien ou scannez le QR code affiché pour l'App Store (iPhone) ou Google Play (Android).
  3. Dans la fiche de la boutique, vérifiez que l'éditeur affiché est bien OpenAI avant d'installer.
  4. Installez, ouvrez l'application et connectez-vous avec votre compte ou créez-en un en suivant les écrans.

Sur ordinateur

  1. Allez sur chatgpt.com/download, saisi à la main dans votre navigateur.
  2. Dans la section « ordinateur », utilisez le bouton de téléchargement proposé pour votre système. Si le Mac est concerné, la page détecte la puce (Apple Silicon ou Intel) et propose le bon installateur, d'après l'aide officielle.
  3. Ouvrez le fichier téléchargé et suivez l'installation. N'acceptez jamais un fichier trouvé sur un site tiers.
  4. Connectez-vous avec votre compte.

Sans rien installer

Vous pouvez aussi utiliser ChatGPT dans le navigateur, à l'adresse chatgpt.com. Ajoutez ce site à vos favoris : c'est le moyen le plus simple d'éviter les imitations.

Repérer une fausse application

  • Passez toujours par chatgpt.com/download plutôt que de chercher le nom dans la boutique : les résultats de recherche mélangent vraies et fausses applications.
  • Regardez le nom de l'éditeur sur la fiche : il doit s'agir d'OpenAI.
  • Méfiez-vous d'un abonnement imposé dès l'ouverture, d'un nom légèrement modifié ou d'une application qui demande des autorisations sans rapport avec son rôle.
  • Ne donnez jamais votre mot de passe à un site ou une application qui ne se trouve pas sur l'adresse officielle.
  • Un doute ? Désinstallez et recommencez depuis la page officielle.

Les réglages à faire dès l'installation

  1. Données. Dans les paramètres, rubrique « Data controls », vérifiez le réglage d'amélioration du modèle. Le détail est dans notre guide ChatGPT et données personnelles.
  2. Instructions personnalisées. Indiquez votre façon de travailler (ton, longueur, langue) sans y mettre de données sensibles : l'outil instructions personnalisées vous aide à les rédiger.
  3. Mémoire. Regardez ce que l'assistant retient, et désactivez ou supprimez ce qui ne doit pas être gardé.
  4. Sécurité du compte. Choisissez un mot de passe long et unique, et activez la double vérification si l'option est proposée dans les paramètres de sécurité.

Premier essai : un prompt à copier

Une fois installé, testez avec un prompt complet plutôt qu'une question vague :

Tu es un assistant pour débutant. Je viens d'installer ChatGPT sur [téléphone / ordinateur]. Propose-moi 5 exercices de 2 minutes pour apprendre à m'en servir, du plus simple au plus utile pour [mon quotidien : mes mails, mes cours, mon travail]. Pour chacun, donne le prompt exact à copier et ce que je dois vérifier dans la réponse.

Pour construire vos propres prompts, le générateur de prompt est gratuit, et le guide comment utiliser ChatGPT prend la suite de celui-ci.

Quand on n'a pas besoin d'installer

  • Pour un usage ponctuel, le navigateur suffit.
  • Sur un ordinateur partagé (travail, bibliothèque), préférez le navigateur et déconnectez-vous ensuite plutôt que d'installer une application.
  • Si vous cherchez un autre assistant, voyez quelle IA choisir.

Avant de valider une installation, prenez toujours le temps de relire la fiche de la boutique : nom de l'éditeur, nombre d'avis, date de mise à jour et autorisations demandées. Ce contrôle de trente secondes évite la plupart des mauvaises surprises.

Les pages de l'éditeur évoluent : si un bouton ou un intitulé diffère de ce guide, suivez la page officielle plutôt que ce texte.

Questions fréquentes

Où télécharger l'application ChatGPT officielle ?

Depuis la page chatgpt.com/download, qui renvoie vers l'App Store pour iPhone et Google Play pour Android. Vérifiez que l'éditeur affiché est OpenAI.

Faut-il installer ChatGPT pour l'utiliser ?

Non. Il s'utilise aussi directement dans le navigateur à l'adresse chatgpt.com.

Existe-t-il une application ChatGPT pour ordinateur ?

Oui, l'éditeur propose une section de téléchargement pour ordinateur ; l'aide officielle décrit une application pour macOS (14 minimum) et Windows. Prenez-la uniquement depuis la page officielle.

Comment éviter les fausses applications ChatGPT ?

Passez par la page officielle de téléchargement, vérifiez le nom de l'éditeur sur la fiche de la boutique et méfiez-vous de tout abonnement imposé dès l'ouverture.
