Est-ce que Le Chat de Mistral est gratuit ?

Oui : Mistral propose une offre gratuite, sans engagement.

L'essentiel

Voici ce qu'elle inclut, ce que coûte l'offre Pro et comment commencer.

La réponse en bref : oui, Le Chat de Mistral AI (renommé Vibe) a une offre gratuite : accès sur le web et sur mobile, messages et recherches web limités, génération et retouche d'images de base. L'offre payante Pro, relevée à 17,99 €/mois le 23/11/2026, augmente les limites. Les prix peuvent changer : vérifiez sur la page de tarifs de Mistral.

Ce que comprend l'offre gratuite

La page de tarifs de Mistral décrit l'offre Free comme un agent personnel pour les tâches du quotidien, pour tester les capacités de Vibe. Elle liste : un accès sur le web et sur mobile, des messages et recherches web limités, des sessions de code limitées, la génération et la retouche d'images de base, et plus de cent connecteurs. Mistral n'y donne pas de nombre de messages : les limites exactes ne sont pas affichées, donc méfiez-vous des chiffres qui circulent sur les forums.

Le nom a changé : depuis le 12 août 2026, selon l'aide de Mistral, Le Chat est devenu Vibe, au même endroit (chat.mistral.ai) et avec le même compte. Voir c'est quoi Le Chat de Mistral.

Ce que change l'offre Pro

La page de tarifs présente Pro comme un accès plus large : plus de messages et de recherches web, des réponses plus rapides, un usage « toute la journée » du mode code, et une assistance par chat et par mail. Prix relevé le 23/11/2026 : 17,99 €/mois. Mistral indique aussi que son offre est soumise à des règles d'usage raisonnable et à ses conditions. Il existe en outre un tarif Éducation pour les étudiants vérifiés d'établissements d'enseignement supérieur accrédités, d'une durée maximale de 12 mois et réservé à ceux qui n'ont jamais utilisé Vibe ou Le Chat, ainsi que des offres Team et Enterprise pour les organisations.

Pour placer ces prix à côté de ceux de ChatGPT, Claude et Gemini, consultez le comparatif des abonnements IA.

Comment faire : l'essayer gratuitement

  1. Ouvrez chat.mistral.ai : Mistral indique que vous arrivez dans Vibe.
  2. Créez un compte ou connectez-vous. Le bouton de la page de tarifs pour l'offre gratuite est « Start Free ».
  3. Choisissez le mode Chat pour une conversation classique.
  4. Écrivez une demande précise : objectif, contexte, format. Le générateur de prompt fait gagner du temps.
  5. Relisez les réponses, vérifiez ce qui compte, et signalez les erreurs avec le pouce vers le bas.

Sur ordinateur ou téléphone

La page de présentation de Vibe propose des applications à télécharger pour macOS et Windows, ainsi que pour iOS et Android, et une version web. Cette page mentionne aussi d'autres plateformes « bientôt disponibles » ; l'état exact des téléchargements évolue : partez de la page officielle plutôt que d'un site tiers. N'installez jamais l'application depuis un lien reçu par message : passez par le site de Mistral ou par la boutique officielle de votre téléphone.

Gratuit ne veut pas dire sans précaution

  • Ne collez pas de données personnelles ou confidentielles ; les règles de confidentialité sont dans le centre d'aide, rubrique « Trust, Security, Compliance ».
  • Relisez toujours : Mistral écrit que Vibe peut donner des réponses incorrectes.
  • Si l'offre gratuite ne suffit plus, comparez avant de payer : ChatGPT gratuit, Gemini gratuit, ou quelle IA choisir.

Informations tirées du site et du centre d'aide de Mistral consultés le 26/11/2026 ; prix relevé le 23/11/2026.

Questions fréquentes

Est-ce que le Chat Mistral est gratuit ?

Oui : l'offre gratuite donne accès sur le web et sur mobile, avec des messages et recherches web limités et des images de base. Les limites exactes ne sont pas publiées.

Est-ce que le Chat Mistral est payant ?

Seulement si vous le souhaitez : l'offre Pro, relevée à 17,99 €/mois le 23/11/2026, augmente les limites. Des offres Team et Enterprise existent pour les organisations.

Combien coûte le Chat Mistral ?

Rien pour l'offre gratuite ; Pro est relevé à 17,99 €/mois le 23/11/2026. Vérifiez le prix à jour sur la page de tarifs de Mistral.

Comment utiliser le Chat Mistral ?

Ouvrez chat.mistral.ai, connectez-vous, choisissez le mode Chat et écrivez votre demande. Précisez objectif, contexte et format pour de meilleures réponses.

Comment installer le Chat Mistral ?

Il fonctionne dans le navigateur ; des applications pour ordinateur et téléphone sont proposées sur la page officielle de Vibe. Passez toujours par le site de Mistral ou la boutique officielle.

Comment télécharger le Chat Mistral ?

Depuis la page officielle de Vibe (anciennement Le Chat) sur mistral.ai, ou la boutique d'applications de votre téléphone. Évitez les sites tiers de téléchargement.
