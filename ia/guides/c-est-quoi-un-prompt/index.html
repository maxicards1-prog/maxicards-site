C'est quoi un prompt en IA ?

Le prompt est le message que vous tapez pour demander quelque chose à une IA.

L'essentiel

Sa qualité influence directement la réponse.

Réponse courte. Un prompt est l'instruction, la question ou le texte que vous envoyez à une intelligence artificielle pour obtenir une réponse. Cela peut être une phrase (« Explique-moi la TVA ») comme un message long avec contexte, exemples et format attendu. Le « prompt engineering » désigne l'art de rédiger ces consignes pour obtenir de meilleurs résultats.

D'où vient le mot

« Prompt » est un mot anglais qui signifie à peu près « invite » ou « amorce ». En informatique, l'invite de commande est la ligne qui attend votre saisie. Avec les IA génératives, le mot a été repris pour désigner ce que vous saisissez : c'est lui qui amorce la réponse. On le dit en français tel quel, et on emploie aussi « requête » ou « consigne ». Le verbe « prompter » (donner un prompt) est entré dans l'usage.

Ce que contient un prompt

Un prompt peut contenir plusieurs éléments, tous facultatifs mais utiles :

  • L'instruction : ce que l'IA doit faire (rédiger, résumer, comparer, corriger, expliquer).
  • Le contexte : qui vous êtes, pour qui est le texte, la situation, les données utiles.
  • Les contraintes : longueur, ton, niveau de langage, ce qu'il faut éviter.
  • Le format : tableau, liste numérotée, trois paragraphes, plan en deux niveaux.
  • Un exemple : un modèle du style attendu, quand le style compte.

Les documentations officielles d'OpenAI et d'Anthropic recommandent toutes deux d'être précis et explicite, de donner le contexte et de préciser le format de sortie. Anthropic compare son IA à un collègue brillant mais qui ne connaît pas vos habitudes : plus vous expliquez, mieux il travaille.

Un prompt faible, un prompt solide

Voici une demande telle qu'on l'écrit spontanément :

Parle-moi de la photosynthèse.

L'IA ne sait pas pour qui vous voulez la réponse ni quelle longueur viser. Voici la même demande avec les éléments manquants :

Explique la photosynthèse à un élève de 4e qui prépare un contrôle.

Contraintes : 150 mots maximum, vocabulaire simple, une analogie du quotidien.
Format : un paragraphe d'explication, puis trois questions d'entraînement avec leurs réponses.

La seconde version n'est pas « plus intelligente » : elle contient simplement l'information qui manquait. Pour apprendre cette méthode pas à pas, lisez comment écrire un bon prompt ; pour la réaliser sans effort, essayez le générateur de prompt, ou l'outil d'amélioration de prompt si vous avez déjà un brouillon.

Que veut dire « prompt engineering » ?

C'est l'ensemble des techniques pour rédiger et ajuster des prompts : structurer la demande, utiliser des délimiteurs pour séparer l'instruction du texte à traiter, fournir des exemples, demander un format précis, découper une tâche en plusieurs étapes. La documentation d'OpenAI consacre une section entière à ces pratiques, et celle d'Anthropic détaille des conseils propres à Claude. Cela ne demande pas de compétence technique : c'est surtout de la clarté d'écriture. On ne parle pas de formule magique, car un même prompt peut donner des résultats différents d'un modèle à l'autre.

Les différentes sortes de prompts

  • Le prompt de conversation : votre message dans ChatGPT, Claude ou Gemini.
  • Le prompt système ou les instructions personnalisées : des consignes permanentes qui s'appliquent à toutes vos conversations. Le site propose un outil pour les préparer : instructions personnalisées.
  • Le prompt d'image : une description pour générer une image, qui obéit à d'autres règles. Voyez le générateur de prompt image et le guide pour écrire un prompt Midjourney.

Les erreurs fréquentes

  • Demander trop de choses d'un coup : procédez par étapes dans la même conversation.
  • Oublier le public visé : on n'écrit pas de la même façon pour un enfant et pour un directeur financier.
  • Se contenter de la première réponse : un prompt se corrige (« plus court », « plus concret », « ajoute un exemple »).
  • Ne pas vérifier : même avec un excellent prompt, une IA peut se tromper. Relisez chiffres, dates et noms.
  • Coller des données personnelles ou confidentielles : remplacez-les par des crochets [nom], [adresse].

Où trouver des modèles prêts à l'emploi

Si vous débutez, partez d'exemples : le guide exemples de prompts fournit des modèles à copier, et la page prompts par métier en propose pour des professions précises. Adaptez toujours les crochets à votre situation avant d'envoyer.

Questions fréquentes

C'est quoi prompt en IA ?

C'est la consigne, la question ou le texte que vous envoyez à une IA pour obtenir une réponse. Plus il est clair et complet, plus la réponse est utile.

Qu'est-ce que prompt engineering ?

C'est l'ensemble des techniques pour bien rédiger ses consignes à une IA : contexte, contraintes, format, exemples, découpage en étapes. Les documentations d'OpenAI et d'Anthropic en donnent les bases.

Pourquoi on dit prompt ?

Parce que le mot anglais signifie « invite » ou « amorce » : c'est ce qui déclenche la réponse de l'IA. Il vient de l'invite de commande en informatique et s'est imposé tel quel en français.

Comment prompter efficacement ?

Dites ce que vous voulez en une phrase, donnez le contexte, fixez des contraintes mesurables, demandez un format et, si le style compte, joignez un exemple. Puis corrigez par petites touches.

Pourquoi structurer un prompt ?

Parce qu'une IA ne devine ni votre public ni votre objectif. Une structure claire, avec instruction, contexte, contraintes et format, réduit les réponses hors sujet.

Quel prompt utiliser pour ChatGPT ?

Il n'y a pas de prompt universel : cela dépend de la tâche. Partez d'un modèle adapté, comme ceux du guide d'exemples du site, puis remplacez les crochets par vos propres informations.
