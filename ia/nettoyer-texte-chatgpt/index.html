Nettoyer un texte copié de ChatGPT

Fini les ** et les ### dans vos documents : collez le texte, récupérez une version propre ou une mise en forme prête pour Word.

  • Rien n'est envoyé
  • Aucune clé d'API
  • Gratuit, sans limite
  • Sans inscription

Tout se passe dans votre navigateur : votre texte n'est envoyé à aucune IA ni à aucun serveur, il n'y a ni compte, ni clé d'API, ni limite.

Comment faire

  1. Dans ChatGPT, Claude ou Gemini, copiez la réponse (bouton « Copier » ou sélection).
  2. Collez-la dans le cadre : le texte propre apparaît tout de suite.
  3. Choisissez le résultat : texte propre, code HTML, ou markdown nettoyé.
  4. Copiez le résultat, ou utilisez « Copier avec la mise en forme » pour Word, Google Docs ou un e-mail.

Ce que l'outil nettoie

  • Le markdown : **gras**, *italique*, titres #, listes, citations >, tableaux, blocs de code, liens.
  • Les caractères invisibles : espaces de largeur nulle, traits d'union conditionnels, marques de direction du texte. Ils passent inaperçus mais faussent un compte de caractères ou bloquent certains formulaires.
  • Les tirets longs (—) : très fréquents dans les textes générés et rares en français courant. L'outil peut les remplacer par un tiret court (–) ou une virgule.
  • En option : espaces insécables, guillemets anglais transformés en « guillemets français », émojis.

Texte propre ou mise en forme ?

Pour un SMS, un formulaire, une description de produit ou un champ qui n'accepte que du texte brut, prenez le texte propre : les titres deviennent de simples lignes, les listes gardent des puces « • ». Pour un document, prenez « Copier avec la mise en forme » : Word et Google Docs reçoivent de vrais titres, du vrai gras et de vraies listes. Pour un site ou un CMS, le code HTML est prêt à coller dans l'éditeur HTML.

Astuce : demander directement un texte sans markdown

Vous pouvez aussi écrire dans votre demande : « Réponds en texte brut, sans markdown, sans gras ni titres ». Les IA le respectent en général, mais pas toujours sur une longue conversation : l'outil reste utile pour rattraper le texte. Pour régler cela une fois pour toutes, ajoutez la consigne dans vos instructions personnalisées.

Questions fréquentes

Mon texte est-il envoyé quelque part ?

Non. L'outil fonctionne entièrement dans votre navigateur, sur votre appareil : rien n'est envoyé à ChatGPT, Claude, Gemini ni à nos serveurs, et rien n'est enregistré. Vous pouvez le vérifier dans l'onglet « Réseau » des outils de développement de votre navigateur.

Pourquoi ChatGPT met-il des étoiles et des # ?

Ce sont des marques Markdown : **gras**, # titre, - liste. Dans l'application elles deviennent une mise en forme, mais certains copier-coller (vers un formulaire, un SMS, un CMS) les gardent telles quelles. L'outil les transforme en texte propre ou en vraie mise en forme.

Comment coller dans Word sans perdre le gras ?

Utilisez « Copier avec la mise en forme » : le texte est copié comme une page web, avec ses titres, son gras et ses listes. Collez-le dans Word, Google Docs ou un e-mail : la mise en forme est conservée, sans aucune étoile.

Les caractères invisibles sont-ils un filigrane de ChatGPT ?

Rien ne le prouve. Ces caractères (espaces de largeur nulle, marques de direction…) viennent souvent du copier-coller depuis une page web ou une application. Ils peuvent gêner un formulaire ou un compteur de caractères : l'outil les compte et les retire.
