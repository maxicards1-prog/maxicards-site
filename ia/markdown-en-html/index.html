Convertir du Markdown en HTML

Collez du Markdown : vous obtenez le code HTML correspondant, un aperçu, ou du texte brut sans aucune marque.

  • Rien n'est envoyé
  • Aucune clé d'API
  • Gratuit, sans limite
  • Sans inscription

Tout se passe dans votre navigateur : votre texte n'est envoyé à aucune IA ni à aucun serveur, il n'y a ni compte, ni clé d'API, ni limite.

Ce qui est converti

MarkdownHTML obtenu
# Titre à ###### Titre<h1> à <h6>
**gras**, *italique*, ~~barré~~<strong>, <em>, <del>
- élément, 1. élément<ul>, <ol> (avec sous-listes)
| a | b | + ligne |---|---|<table>
```code``` et `code`<pre><code>, <code>
[texte](https://…)<a href> (liens http et https seulement)
> citation, ---<blockquote>, <hr>

Un HTML sûr

Tout le texte est échappé : une balise HTML écrite dans votre Markdown apparaît comme du texte, elle n'est pas exécutée. Seuls les liens en http ou https deviennent cliquables. Le code obtenu est simple, sans classes ni styles, prêt à coller dans WordPress (bloc HTML personnalisé), un e-mail ou une page.

À quoi ça sert ?

Le Markdown est le format de sortie des assistants d'IA (ChatGPT, Claude, Gemini), des fichiers README, de Notion ou d'Obsidian. Le convertir en HTML permet de le publier sur un site ; le convertir en texte brut permet de le coller là où la mise en forme n'existe pas. Pour un nettoyage plus poussé d'une réponse d'IA (caractères invisibles, tirets longs), voyez le nettoyeur de texte ChatGPT.

Questions fréquentes

Mon texte est-il envoyé quelque part ?

Non. L'outil fonctionne entièrement dans votre navigateur, sur votre appareil : rien n'est envoyé à ChatGPT, Claude, Gemini ni à nos serveurs, et rien n'est enregistré. Vous pouvez le vérifier dans l'onglet « Réseau » des outils de développement de votre navigateur.

Le HTML garde-t-il les tableaux ?

Oui, les tableaux Markdown (lignes avec des |, et une ligne de tirets sous l'en-tête) deviennent de vrais tableaux HTML.

Puis-je mettre du HTML dans mon Markdown ?

Il sera affiché comme du texte, pas interprété : c'est voulu, pour qu'aucun code ne s'exécute. Écrivez votre mise en forme en Markdown.

Quelle variante de Markdown est prise en charge ?

Les éléments courants de CommonMark et de GitHub (titres, gras, italique, listes, tableaux, code, liens, citations, barré). Les notes de bas de page et les formules mathématiques ne sont pas converties.
