Taper les caractères spéciaux : Windows, Mac et téléphone

Un symbole manque sur votre clavier ? Voici les méthodes pour le taper sur Windows, sur Mac et sur un téléphone, et la solution la plus simple : le copier.

Mis à jour le 26/11/2026.

L'outil qui va avec : Caractères spéciaux

La méthode en 6 étapes

  1. Essayez d'abord le copier-coller : Dans notre table de caractères, un clic copie le symbole. Collez-le où vous voulez.
  2. Windows : le panneau des symboles : Appuyez sur la touche Windows et sur le point (Windows + .), puis ouvrez l'onglet des symboles.
  3. Windows : le code Alt : Maintenez Alt, tapez le code au pavé numérique, relâchez. Exemple : Alt + 0176 donne °.
  4. Word : le code puis Alt + X : Tapez le code, puis Alt + X. Exemple : 20AC puis Alt + X donne €.
  5. Mac : appui long ou visualiseur : Maintenez une lettre pour ses accents, ou ouvrez le Visualiseur de caractères avec Ctrl + Cmd + Espace.
  6. Téléphone : appui long : Sur la plupart des claviers de téléphone, maintenez le doigt sur une lettre pour voir ses variantes.

Windows : les codes Alt

Maintenez la touche Alt enfoncée, tapez le code sur le pavé numérique (pas sur la rangée de chiffres du haut), puis relâchez Alt. Si votre clavier l'exige, activez Verr Num. Microsoft donne l'exemple du degré avec le code 0176.

Windows : sans pavé numérique

Beaucoup d'ordinateurs portables n'ont pas de pavé numérique. Deux solutions : le panneau Windows + ., qui propose emojis et symboles, ou le copier-coller depuis notre table.

Dans Word : le code Unicode

Dans Word, tapez le code hexadécimal du caractère, puis appuyez sur Alt + X : le code se transforme en symbole. Exemple pour l'euro : 20AC puis Alt + X. Si Word convertit trop de caractères, faites précéder le code de « U+ ». Certains programmes Office ne gèrent pas cette méthode.

Sur le clavier AZERTY de Windows

Plusieurs symboles se tapent avec la touche AltGr (à droite de la barre d'espace). D'après la disposition française de Windows :

  • AltGr + E : €
  • AltGr + 0 : @
  • AltGr + 2 : ~
  • AltGr + 3 : #
  • AltGr + 6 : |
  • Maj + ) : °

Votre clavier peut différer, surtout si vous avez choisi une autre disposition : vérifiez avec le clavier visuel de Windows.

Sur Mac

Maintenez une lettre enfoncée : un menu d'accents s'ouvre. Pour les autres symboles, ouvrez le Visualiseur de caractères avec Ctrl + Cmd + Espace (ou Fn/globe + E sur les versions récentes), ou par le menu Édition. Le Visualiseur de clavier montre, touche par touche, ce que chaque combinaison produit sur votre Mac.

Sur téléphone

Sur la plupart des claviers de téléphone, un appui long sur une lettre ou un signe affiche ses variantes : accents, guillemets, symboles proches. Le détail change selon le clavier : testez le vôtre.

Quelle méthode choisir

  • Un symbole de temps en temps : le copier-coller depuis la table est le plus rapide, sur n'importe quel appareil.
  • Le même symbole tous les jours : apprenez son code Alt, ou son raccourci AltGr si votre clavier en propose un.
  • Un clavier sans pavé numérique : le panneau Windows + ., ou le Visualiseur de caractères sur Mac.
  • Un téléphone : l'appui long sur la lettre voisine, ou un copier-coller depuis une page déjà ouverte.

Vérifier le résultat

Après avoir tapé un symbole, regardez-le de près. Un « O » peut ressembler à un zéro, un tiret long à un trait d'union, une apostrophe droite à une apostrophe courbe. Si le symbole doit être lu par d'autres personnes, envoyez-vous d'abord un message de test : une police manquante peut le remplacer par un carré. Pour les règles d'espacement autour des guillemets et des tirets, lisez notre guide sur les règles de typographie française.

Questions fréquentes

Pourquoi mon code Alt ne marche-t-il pas ?

Vérifiez que vous tapez sur le pavé numérique, avec Verr Num activé si besoin. Sans pavé numérique, utilisez Windows + point ou le copier-coller.

Comment taper É en majuscule ?

Soit avec le code Alt de la table, soit en copiant le caractère. L'Académie française recommande d'accentuer les majuscules.

Le symbole copié s'affiche en carré, pourquoi ?

La police du site ou du document ne contient pas ce symbole. Changez de police ou choisissez un caractère plus courant.
