À propos

Des outils gratuits, des raccourcis vérifiés.

Caractères spéciaux et texte rassemble des outils gratuits pour écrire : trouver un caractère qui n'est pas sur le clavier, styliser une bio, compter les mots, changer la casse, créer un mot de passe.

Qui édite le site

Le site est édité par la société MAXICARDS (SASU), qui publie aussi d'autres sites d'outils gratuits. Coordonnées complètes dans les mentions légales.

Nos principes

  • Gratuit et sans compte.
  • Vos textes restent chez vous : tout est fait dans votre navigateur. Rien n'est envoyé, rien n'est gardé, rien n'est mis dans l'adresse de la page.
  • Des raccourcis vérifiés : les codes sont calculés à partir des tables officielles, et les sources sont citées sur chaque page.
  • Accessibles : nous signalons ce qui gêne les personnes qui utilisent un lecteur d'écran.

Comment le site est financé

Le site affiche de la publicité (Google AdSense), qui ne change jamais les résultats. La page du générateur de mot de passe n'en affiche pas. Voir la politique de confidentialité.
