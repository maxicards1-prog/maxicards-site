Trois façons de taper un caractère spécial

  • Copier-coller : cliquez sur le caractère ci-dessus, il est copié. Collez-le avec Ctrl + V (Cmd + V sur Mac).
  • Le code Alt de Windows : maintenez la touche Alt, tapez les quatre chiffres sur le pavé numérique (pas sur la rangée du haut), puis relâchez Alt. Verr Num doit être allumé. Exemple : Alt + 0201 donne É.
  • Le code Word : dans Word, tapez le code Unicode du caractère puis Alt + X. Exemple : 00C9 puis Alt + X donne É.

Pas de pavé numérique, comme sur beaucoup de portables ? Ouvrez le panneau de Windows avec la touche Windows + . (point) : il contient les emojis et un onglet de symboles. Sur Mac, maintenez une lettre enfoncée pour voir ses accents, ou ouvrez le Visualiseur de caractères (Fn/globe + E, ou Ctrl + Cmd + Espace selon la version de macOS).

Accentuer les majuscules : oui

L'Académie française le rappelle : en français, l'accent a pleine valeur orthographique, y compris sur les majuscules et sur la préposition À. Écrire « ETE » au lieu de « ÉTÉ » peut faire hésiter le lecteur. Avec un code Alt ou un clic ici, É, À ou Ç ne prennent qu'une seconde.

Les espaces insécables

Une espace insécable empêche un signe de se retrouver seul au début d'une ligne. En France, l'usage la place à l'intérieur des guillemets « » et avant les deux-points, le point-virgule, le point d'exclamation et le point d'interrogation ; au Québec, l'Office québécois de la langue française recommande moins d'espaces devant la ponctuation. Elle est invisible : dans la grille, elle est notée « insécable », et son code Alt est Alt + 0160.

Questions fréquentes

Comment faire un É majuscule sur Windows ?

Maintenez la touche Alt et tapez 0201 sur le pavé numérique (Alt + 0201), Verr Num allumé, puis relâchez Alt. Sans pavé numérique, copiez É sur cette page ou ouvrez le panneau Windows + . (point).

Pourquoi mon code Alt ne marche pas ?

Les chiffres doivent être tapés sur le pavé numérique, pas sur la rangée du haut, et Verr Num doit être allumé. Sur un portable sans pavé numérique, passez par le copier-coller ou par le panneau Windows + . (point).

Comment taper œ (e dans l'o) ?

Sur Windows : Alt + 0156. Dans Word : 0153 puis Alt + X. Sur Mac : maintenez la touche o enfoncée, puis choisissez œ. Ou copiez-le ici en un clic.

Comment faire les guillemets français « » ?

Sur Windows : Alt + 0171 pour « et Alt + 0187 pour ». Mettez une espace insécable à l'intérieur : « comme ceci ».

Les codes Alt marchent-ils sur Mac ?

Non, ils sont propres à Windows. Sur Mac, maintenez une lettre pour voir ses accents, ou ouvrez le Visualiseur de caractères (Fn/globe + E, ou Ctrl + Cmd + Espace sur les versions plus anciennes de macOS).
