Comment taper des caractères spéciaux sur Mac ?

Sur Mac, maintenez une lettre enfoncée pour ses accents, ouvrez le Visualiseur de caractères (Fn/globe + E) pour les symboles, ou le Visualiseur de clavier.

Mis à jour le 26/11/2026.

Sur Mac, il n'est pas nécessaire de mémoriser des combinaisons : Apple fournit des outils pour trouver tous les caractères.

1. L'appui long pour les accents

Apple l'explique dans son aide : lorsque vous maintenez enfoncée la touche d'une lettre, un menu d'accents s'ouvre. Choisissez la variante accentuée avec la souris ou en tapant le chiffre affiché.

2. Le Visualiseur de caractères

Pour les symboles, les flèches, les cœurs, les emojis et les lettres spéciales, ouvrez le Visualiseur de caractères : Fn/globe + E sur les versions récentes de macOS, ou Contrôle + Commande + Espace sur une version plus ancienne (10.15). Vous pouvez aussi passer par le menu Édition, Emoji et symboles. Cherchez le caractère par son nom, puis cliquez dessus.

3. Le Visualiseur de clavier

Il affiche votre clavier à l'écran. Quand vous appuyez sur Option ou Maj, les touches montrent les caractères qu'elles produisent, et un contour orange signale les touches mortes (accents à placer avant la lettre). C'est la méthode fiable pour trouver une combinaison sur votre disposition de clavier.

Pourquoi pas de tableau de raccourcis ?

Apple ne publie pas de liste complète des combinaisons Option, et elles varient selon la disposition de clavier. Plutôt que de risquer une erreur, utilisez les outils ci-dessus.

Majuscules accentuées

Si une lettre ne se comporte pas comme prévu, passez par le menu d'accents ou le Visualiseur de caractères. Voir aussi les accents sur les majuscules.

Questions fréquentes

Comment ouvrir le Visualiseur de caractères ?

Fn/globe + E sur les versions récentes, ou Contrôle + Commande + Espace sur macOS 10.15, ou via Édition, Emoji et symboles.

Comment faire un accent sur une majuscule sur Mac ?

Maintenez la lettre enfoncée pour le menu d'accents, ou cherchez le caractère dans le Visualiseur de caractères.
