Comment taper une espace insécable ?

Sous Windows, l'espace insécable se tape avec Alt + 0160 au pavé numérique ; dans Word, tapez 00A0 puis Alt + X ; en HTML, &nbsp;.

Mis à jour le 26/11/2026.

Une espace insécable est une espace qui ne laisse jamais la ligne se couper à cet endroit. Elle évite qu'un « ? » ou un « : » se retrouve seul au début d'une ligne.

Les codes

EspaceWindows (pavé numérique)WordHTML
InsécableAlt + 016000A0 puis Alt + X&nbsp;
Fine insécable–202F puis Alt + X&#8239;

Il faut taper les chiffres sur le pavé numérique (à droite du clavier, pas la rangée au-dessus des lettres), avec Verr Num activé si votre clavier l'exige. Maintenez la touche Alt enfoncée, tapez le code au pavé numérique, puis relâchez Alt. Dans Word, tapez le code Word puis Alt + X. L'espace fine insécable (U+202F) n'est pas dans les codes Alt à quatre chiffres : utilisez le code Word, ou copiez-la.

Quand l'employer ?

L'Office québécois de la langue française indique qu'on l'emploie avant ou après certains signes, comme les chevrons, le deux-points et les guillemets, et qu'une espace fine est parfois utilisée devant le point d'interrogation, le point d'exclamation et le point-virgule.

France et Québec

Attention : l'usage de France met une espace insécable (ou fine) avant : ; ! ?, alors que l'OQLF au Québec préconise plutôt aucune espace devant ces signes. Choisissez la règle du public visé et gardez-la partout.

Sur Mac

Sur Mac, maintenez la touche de la lettre enfoncée : un menu d'accents s'ouvre. Pour tout autre caractère, ouvrez le Visualiseur de caractères (Contrôle + Commande + Espace, ou Fn/globe + E) ou regardez le Visualiseur de clavier.

Attention à l'affichage

Une espace insécable ressemble à une espace normale : on ne la voit pas. Certains sites ou formulaires la remplacent ou la refusent. En cas de doute, testez.

Copiez l'espace insécable et l'espace fine depuis la table des caractères spéciaux.

Questions fréquentes

Quel est le code Alt de l'espace insécable ?

Alt + 0160 au pavé numérique.

Faut-il une espace avant le point d'exclamation ?

En France, oui (insécable ou fine) ; au Québec, l'OQLF préconise plutôt aucune espace.
