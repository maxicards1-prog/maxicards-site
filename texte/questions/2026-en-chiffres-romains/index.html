Pourquoi on les voit encore

Les chiffres romains datent traditionnellement les façades, les monuments, les pages de titre et les génériques. Beaucoup de gens cherchent l'année en romain pour un gâteau d'anniversaire, un tatouage, un faire-part ou une inscription.

Les règles à garder en tête

  • Les lettres : I = 1, V = 5, X = 10, L = 50, C = 100, D = 500, M = 1000.
  • Addition : une lettre de valeur inférieure ou égale placée à droite s'ajoute (VI = 6).
  • Soustraction : une lettre de valeur inférieure placée à gauche se retranche (IV = 4).
  • Pas plus de trois fois de suite la même lettre (300 = CCC) ; au-delà, on soustrait (400 = CD), d'après l'Office québécois de la langue française.

Pour une autre année

Découpez l'année : 1999 = 1000 + 900 + 90 + 9 = M + CM + XC + IX = MCMXCIX. Si vous écrivez un siècle plutôt qu'une année, voyez les siècles en chiffres romains.

Pour n'importe quelle autre année, utilisez le convertisseur de chiffres romains.
