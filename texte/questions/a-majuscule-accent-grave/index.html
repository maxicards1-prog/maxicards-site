Comment écrire un À majuscule (A accent grave) ?

Pour écrire un À majuscule sous Windows, tapez Alt + 0192 au pavé numérique, ou copiez-le depuis le panneau Windows + point.

Mis à jour le 26/11/2026.

Le À majuscule sert dès qu'une phrase commence par la préposition « à » : « À bientôt », « À la maison ». Beaucoup l'écrivent sans accent faute de savoir le saisir. Voici comment faire.

Sous Windows

  • Code Alt : Alt + 0192. Maintenez la touche Alt enfoncée, tapez le code au pavé numérique, puis relâchez Alt. Il faut taper les chiffres sur le pavé numérique (à droite du clavier, pas la rangée au-dessus des lettres), avec Verr Num activé si votre clavier l'exige.
  • Dans Word : tapez 00C0, puis Alt + X. Certains programmes Office ne convertissent pas le code.
  • Copier-coller : Sous Windows, Windows + point (touche Windows, puis le point) ouvre le panneau des emojis et des symboles : cliquez sur le caractère voulu.

Sur Mac

Sur Mac, maintenez la touche de la lettre enfoncée : un menu d'accents s'ouvre. Pour tout autre caractère, ouvrez le Visualiseur de caractères (Contrôle + Commande + Espace, ou Fn/globe + E) ou regardez le Visualiseur de clavier.

Sur une page web

En HTML, le caractère s'écrit &Agrave;. Dans un texte normal, collez simplement le caractère : il s'affiche tel quel.

Pourquoi garder l'accent ?

La préposition À majuscule se distingue de A (le verbe « avoir ») uniquement par son accent. L'Académie française demande d'accentuer les majuscules, y compris À. Détails sur cette page.

À retenir

Le caractère est le A majuscule avec accent grave. Aucun raccourci n'est à apprendre par cœur : si vous l'utilisez souvent, gardez-le sous la main avec la table de caractères, qui le copie en un clic. Pour d'autres caractères du même genre, voyez aussi les caractères spéciaux sur Mac et l'espace insécable.

Copiez À, É, Ç et les autres majuscules accentuées depuis la table des caractères spéciaux.
