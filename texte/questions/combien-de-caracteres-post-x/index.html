Combien de caractères dans un post sur X ?

Un post sur X peut contenir 280 caractères sur un compte gratuit ; les caractères latins comptent pour 1, les emojis pour 2.

Mis à jour le 26/11/2026.

Un post sur X peut contenir jusqu'à 280 caractères sur un compte gratuit, selon la documentation de X. Tous les caractères ne comptent pas de la même façon.

Le comptage pondéré

La documentation de X précise que les caractères latins comptent pour 1, alors que les emojis, les caractères chinois, japonais ou coréens et d'autres caractères Unicode comptent pour 2.

ContenuPoids par caractèreMaximum dans 280
Lettres latines, chiffres, espaces1280
Emojis et autres caractères Unicode concernés2140

Que devient un accent ?

Les lettres accentuées du français sont des caractères latins, donc de poids 1 en principe ; en cas de doute, testez dans l'application.

Les liens

Les adresses web sont comptées d'une manière particulière dans les posts ; pour la règle exacte, voyez la documentation de X.

Comment vérifier avant de publier ?

  1. Rédigez le texte dans le compteur.
  2. Regardez le nombre de caractères avec espaces.
  3. Si vous avez des emojis, ajoutez 1 par emoji : chacun pèse 2.

Pour une bio plus courte, voyez la bio Instagram.

Un exemple de calcul

Un post composé de 200 lettres latines et de 5 emojis pèse 200 + 5 × 2 = 210 sur 280 : il reste 70. Le compteur de l'application de X fait ce calcul pour vous ; pour préparer un post ailleurs, notre compteur de mots donne le nombre de caractères : ajoutez 1 par emoji pour retrouver le compte de X.

Comptez vos caractères avec le compteur de mots (compteur X inclus).

Questions fréquentes

Combien d'emojis dans un post X ?

Au maximum 140, car chaque emoji compte pour 2 caractères sur 280.

Un accent compte-t-il double ?

En principe non : les caractères latins comptent pour 1, selon la documentation de X.
