Chiffres romains de 1 à 100 : le tableau complet

De 1 à 100, les chiffres romains vont de I à C ; par exemple 50 s'écrit L, 90 s'écrit XC et 100 s'écrit C.

Mis à jour le 26/11/2026.

Voici la liste complète des chiffres romains de 1 à 100, avec les règles pour les retrouver.

Les règles en bref

  • Les lettres : I = 1, V = 5, X = 10, L = 50, C = 100, D = 500, M = 1000.
  • Addition : une lettre de valeur inférieure ou égale placée à droite s'ajoute (VI = 6).
  • Soustraction : une lettre de valeur inférieure placée à gauche se retranche (IV = 4).
  • Pas plus de trois fois de suite la même lettre (300 = CCC) ; au-delà, on soustrait (400 = CD), d'après l'Office québécois de la langue française.

Un truc pour ne pas se tromper

Décomposez le nombre : 74 = 50 + 20 + 4 = L + XX + IV = LXXIV. Écrivez les dizaines, puis les unités. Pour un nombre plus grand, voyez les chiffres romains de 1 à 1000.

Questions fréquentes

Comment s'écrit 99 en chiffres romains ?

XCIX (90 + 9, soit XC + IX).

Combien de fois répéter la même lettre ?

Au plus trois fois de suite (CCC = 300) ; au-delà on utilise la soustraction (CD = 400).
