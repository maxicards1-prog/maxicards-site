Comment écrire des chiffres romains dans Word ?

Dans Word, choisissez le format de numérotation en chiffres romains dans « Format des numéros de page », ou tapez simplement les lettres I V X L C D M.

Mis à jour le 26/11/2026.

Dans Word, les numéros de page peuvent s'afficher en chiffres romains (i, ii, iii) : c'est un réglage de format, pas besoin de les taper un par un. Vous pouvez aussi taper les lettres à la main.

Numéros de page en romain

Microsoft indique que la boîte de dialogue « Format des numéros de page » permet de choisir le format de numérotation, comme -1-, -2- ou i, ii, iii. Dans la version anglaise, on y accède par l'onglet Insertion, Page Number, puis Format Page Numbers. En français, le chemin ressemble à Insertion, Numéro de page, Format des numéros de page ; l'intitulé exact peut varier selon votre version.

Dans le texte : taper les lettres

Pour écrire un chiffre romain dans le texte (un siècle, un chapitre), tapez simplement les lettres I V X L C D M en majuscules. Ce sont des lettres ordinaires : aucun code spécial n'est nécessaire.

Un seul caractère pour chaque chiffre ?

Unicode contient aussi des caractères « chiffre romain » dédiés, mais ils ne sont pas nécessaires : les lettres suffisent, et elles se lisent mieux avec un lecteur d'écran.

Questions fréquentes

Comment mettre les pages en chiffres romains dans Word ?

Via la boîte « Format des numéros de page » (onglet Insertion, Numéro de page), où l'on choisit le style i, ii, iii.

Faut-il un code spécial pour taper un chiffre romain ?

Non, ce sont les lettres I, V, X, L, C, D, M en majuscules.
