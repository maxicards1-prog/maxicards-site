Comment taper le œ collé (cœur, sœur, œuf) ?

Sous Windows, le œ se tape avec Alt + 0156 et le Œ avec Alt + 0140 au pavé numérique, ou se copie depuis le panneau Windows + point.

Mis à jour le 26/11/2026.

La ligature œ (o et e collés) est une vraie lettre de l'orthographe française : cœur, sœur, œuf, nœud. Les mots écrits « coeur » ou « soeur » sont des simplifications faites faute de savoir saisir le caractère.

Sous Windows

CaractèreNomWindows (pavé numérique)WordHTML
œo e collés, minusculeAlt + 01560153 puis Alt + X&oelig;
ŒO E collés, majusculeAlt + 01400152 puis Alt + X&OElig;

Il faut taper les chiffres sur le pavé numérique (à droite du clavier, pas la rangée au-dessus des lettres), avec Verr Num activé si votre clavier l'exige. Maintenez la touche Alt enfoncée, tapez le code au pavé numérique, puis relâchez Alt. Dans Word, tapez le code Word du tableau, puis Alt + X.

Sur Mac

Sur Mac, maintenez la touche de la lettre enfoncée : un menu d'accents s'ouvre. Pour tout autre caractère, ouvrez le Visualiseur de caractères (Contrôle + Commande + Espace, ou Fn/globe + E) ou regardez le Visualiseur de clavier. Cherchez « œ » dans la recherche du Visualiseur de caractères.

Copier-coller

Sous Windows, Windows + point (touche Windows, puis le point) ouvre le panneau des emojis et des symboles : cliquez sur le caractère voulu. Vous pouvez aussi copier la lettre depuis la table de l'outil et la coller.

Pourquoi ne pas écrire « oe » ?

Dans un moteur de recherche ou un tableur, « coeur » et « cœur » sont deux chaînes différentes. Pour un document soigné, utilisez la ligature ; pour un identifiant ou une adresse web, évitez-la, car certains systèmes la refusent.

Retrouvez œ, Œ, æ et Æ dans la table des caractères spéciaux.

Questions fréquentes

Quel est le code Alt du œ ?

Alt + 0156 au pavé numérique.

Le œ est-il obligatoire dans « cœur » ?

C'est l'orthographe correcte ; « coeur » est une simplification faute de pouvoir saisir la ligature.
