Pourquoi mon PDF ne s'ouvre pas, et comment le réparer

Le plus souvent, le téléchargement est incomplet ou le fichier a été abîmé en route. Retéléchargez-le, essayez un autre lecteur, puis vérifiez l'extension et la protection éventuelle.

Comment faire

  1. Vérifiez le poids du fichier. Un fichier à 0 Ko ou anormalement petit est incomplet. Retéléchargez-le ou redemandez-le à l'expéditeur.
  2. Contrôlez l'extension. Le nom doit se terminer par .pdf. Un fichier .pdf.txt ou sans extension ne s'ouvrira pas correctement.
  3. Essayez un autre lecteur. Ouvrez-le dans votre navigateur (glissez le fichier dans une fenêtre) ou dans un autre lecteur PDF.
  4. Cherchez une protection. Un mot de passe peut être demandé : il faut l'obtenir auprès de l'auteur. Ce site ne déverrouille pas les PDF protégés.
  5. Testez-le sur ce site. Si le fichier s'ouvre dans l'outil, le problème vient de votre lecteur. Sinon, il est probablement abîmé.

Les causes les plus fréquentes

Téléchargement ou envoi interrompu

Une connexion qui coupe, un mail trop gros ou un transfert annulé produisent un PDF tronqué. Les symptômes : message d'erreur à l'ouverture, document blanc, pages manquantes. Le remède est simple : retéléchargez le fichier, ou demandez à l'expéditeur de le renvoyer, de préférence par un autre moyen (lien de partage plutôt que pièce jointe).

Lecteur obsolète ou défaillant

Un lecteur PDF ancien peut échouer sur des fichiers récents. Mettez-le à jour ou testez le fichier dans un navigateur récent. Si le PDF s'ouvre dans le navigateur mais pas dans votre lecteur habituel, c'est le lecteur le coupable.

Mauvaise extension ou mauvais type

Certains fichiers reçus par mail ou téléchargés sur un site s'appellent « document.pdf » mais sont en réalité une page web, une archive ou un autre format. Un fichier très léger est un indice. Ouvrez-le avec un éditeur de texte : un vrai PDF commence généralement par « %PDF ».

Mot de passe ou restrictions

Un PDF protégé demande un mot de passe pour s'ouvrir. Sans lui, impossible d'aller plus loin : contactez l'auteur. Ce site ne contourne pas ces protections.

Fichier abîmé

Un disque défectueux, une clé USB retirée trop tôt ou une erreur d'enregistrement peuvent corrompre un fichier. Si vous avez une copie de sauvegarde, utilisez-la. Si le PDF ne s'ouvre dans aucun lecteur, la réparation est rarement possible : cherchez plutôt la source d'origine.

Cas particuliers

  • Le PDF s'ouvre mais les pages sont de travers : pivotez-les.
  • Le PDF est énorme et le lecteur plante : divisez-le en morceaux et ouvrez-les un à un.
  • Vous avez seulement besoin d'une image de la page : convertissez le PDF en JPG, si le fichier s'ouvre dans l'outil.

Sur téléphone

Sur mobile, un PDF reçu en pièce jointe peut s'ouvrir dans un aperçu limité. Enregistrez-le dans votre appareil, puis ouvrez-le avec une application de lecture PDF ou avec le navigateur. Si le fichier est lourd, laissez-lui le temps de se charger.

Quand abandonner et redemander le fichier

Si trois lecteurs différents échouent et que le poids est cohérent, le PDF est abîmé. Redemandez-le. Pour éviter le problème à l'avenir, envoyez les gros documents par lien plutôt qu'en pièce jointe, et lisez notre guide pièces jointes trop lourdes.

Questions fréquentes

Mon PDF s'ouvre en page blanche, pourquoi ?

Le fichier est peut-être incomplet, ou le lecteur peine à l'afficher. Essayez un navigateur récent, puis retéléchargez-le.

Peut-on réparer un PDF corrompu ?

Rarement. Le plus fiable est de récupérer une autre copie auprès de la source.

Ce site peut-il ouvrir un PDF protégé par mot de passe ?

Non, il ne déverrouille pas les PDF protégés.

Pourquoi un PDF reçu par mail ne s'ouvre-t-il pas sur mon téléphone ?

L'aperçu du mail est parfois limité. Enregistrez le fichier puis ouvrez-le avec une application de lecture PDF ou le navigateur.
