Comment convertir un document Word en PDF

Dans Word, utilisez Fichier > Enregistrer sous (ou Exporter) et choisissez le format PDF.

LibreOffice et Google Docs proposent la même option, et un téléphone aussi.

Mis à jour le 23/11/2026

Comment faire

  1. Relisez le document. Vérifiez l'orthographe, les sauts de page et les images : le PDF reproduira exactement ce que vous voyez.
  2. Ouvrez le menu d'enregistrement. Dans Word : Fichier > Enregistrer sous (ou Exporter).
  3. Choisissez PDF comme format. Sélectionnez PDF dans la liste des formats de fichier.
  4. Donnez un nom différent. Microsoft conseille un autre nom que celui du document d'origine : vous gardez ainsi le Word modifiable et le PDF à partager.
  5. Vérifiez le PDF. Ouvrez le fichier produit et parcourez-le avant l'envoi.

Pourquoi passer par le PDF ?

Un PDF s'affiche de la même façon sur tous les appareils, sans déformer la mise en page ni dépendre des polices du destinataire. C'est le format attendu pour un CV, un devis, une lettre ou un contrat. Il est aussi plus difficile à modifier par erreur qu'un document Word.

Dans Word

La procédure passe par « Enregistrer sous » puis le choix du format PDF. Sur Mac, Microsoft documente exactement ce chemin et rappelle un point important : si vous conservez le même nom que le document d'origine, vous ne pourrez plus modifier le PDF sans logiciel spécialisé. Donnez donc un nom différent et gardez toujours le fichier Word.

Dans LibreOffice

LibreOffice Writer propose l'export au format PDF depuis le menu Fichier. C'est une solution gratuite, qui produit des PDF fidèles pour les documents courants.

Dans Google Docs

Dans Google Docs, le menu Fichier > Télécharger propose le format PDF. Si votre document est un fichier Word dans Drive, ouvrez-le avec Google Docs puis téléchargez-le en PDF. Contrôlez la mise en page : de petites différences avec Word sont possibles.

Sur téléphone

L'application Word sur mobile propose généralement d'enregistrer ou de partager un document au format PDF. Si vous n'y trouvez pas l'option, ouvrez le document dans une version web de votre traitement de texte, ou utilisez la fonction d'impression de votre téléphone et choisissez l'enregistrement en PDF, quand elle est disponible.

Après la conversion

  • Trop lourd ? Réduisez-le avec la compression de PDF, en sachant qu'elle transforme les pages en images : le texte n'est plus sélectionnable.
  • Plusieurs documents à réunir ? Fusionnez-les en un seul PDF.
  • Un document à signer ? Ajoutez votre signature : le guide signer un PDF gratuitement explique les options.

Les erreurs à éviter

Ne partez pas du principe que le PDF corrigera une mise en page bancale : ce qui est décalé dans Word le sera dans le PDF. Vérifiez aussi les métadonnées et les commentaires : un document Word peut contenir des commentaires ou des modifications suivies que vous ne voulez pas diffuser. Enfin, n'écrasez jamais votre Word avec le PDF.

Pour faire l'inverse (partir d'un PDF vers Word), voyez convertir un PDF en Word gratuitement. Ce site ne convertit pas de Word vers PDF lui-même : cette étape se fait dans votre logiciel.

Questions fréquentes

Ce site convertit-il un fichier Word en PDF ?

Non, il ne traite pas les fichiers Word. L'export en PDF se fait dans Word, LibreOffice ou Google Docs, puis le site peut compresser, fusionner ou signer le PDF.

Pourquoi garder le fichier Word ?

Parce qu'un PDF se modifie mal. Avec le Word, vous corrigez puis réexportez en quelques secondes.

La mise en page changera-t-elle ?

En principe non : le PDF fige la mise en page. Vérifiez néanmoins avant l'envoi.

Puis-je le faire depuis mon téléphone ?

Oui, via l'application de traitement de texte ou la fonction d'impression en PDF, selon votre téléphone.
