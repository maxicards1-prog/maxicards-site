Comment mettre un PDF en paysage

Si les pages sont simplement couchées sur le côté, faites-les pivoter de 90°. Si la mise en page elle-même doit changer, modifiez l'orientation dans le document d'origine puis réexportez le PDF.

Mis à jour le 23/11/2026

L'outil gratuit, sans envoi de fichier :
Pivoter PDFOrganiser les pagesExtraire des pages

Comment faire

  1. Identifiez votre cas. Le contenu est-il couché sur le côté (il faut pivoter) ou la page est-elle simplement trop étroite pour le contenu (il faut changer la mise en page) ?
  2. Pivotez les pages concernées. Ouvrez l'outil pour pivoter un PDF, choisissez 90° dans le bon sens, sur toutes les pages ou seulement certaines.
  3. Téléchargez le nouveau PDF. Le fichier est créé dans votre navigateur, l'original n'est pas modifié.
  4. Vérifiez le sens de lecture. Ouvrez le PDF : le texte doit se lire normalement, sans avoir à tourner la tête ni l'écran.
  5. Sinon, changez la source. Pour une vraie mise en page paysage, repassez par le document d'origine (Word, tableur) puis exportez à nouveau en PDF.

Deux situations très différentes

Quand on dit « mettre en paysage », on confond souvent deux choses. Les distinguer évite de perdre du temps.

Cas 1 : le contenu est de travers

Vous avez scanné ou photographié un document dans le mauvais sens, ou un tableau large a été placé sur une page portrait en tournant le contenu. La page est correcte, mais l'affichage est couché. Il suffit de pivoter les pages de 90°. C'est instantané et sans perte, car le PDF reste le même, seule l'orientation d'affichage change.

Cas 2 : la mise en page doit changer

Vous voulez que le contenu occupe une page plus large que haute, par exemple pour un tableau qui déborde. Pivoter ne fera que coucher la page portrait : le contenu restera aussi étroit. Il faut revenir à l'application d'origine et changer l'orientation de la page : dans Word, c'est un réglage de mise en page (Orientation), dans LibreOffice et Google Docs un réglage équivalent de format de page, puis il faut réexporter le PDF. Les intitulés précis varient selon la version : cherchez « Orientation » dans les options de mise en page.

Pivoter seulement certaines pages

Un document mélange parfois pages portrait et paysage. L'outil permet de choisir les pages à tourner. Si vous n'avez qu'une page bancale, vous pouvez aussi l'extraire, la pivoter, puis la remettre à sa place avec l'organisation des pages.

Orientation à l'impression

Si votre but est d'imprimer en paysage, la boîte de dialogue d'impression propose en général un choix d'orientation, qui ne modifie pas le fichier. Si le PDF est déjà en paysage mais s'imprime mal, vérifiez ce réglage.

Pièges fréquents

  • Pivoter de 180° au lieu de 90° : la page se retrouve à l'envers. Contrôlez avant d'enregistrer.
  • Pages de tailles différentes : un PDF fusionné peut mêler formats et orientations. Voyez fusionner des PDF pour bien préparer les fichiers avant l'assemblage.
  • Scan trop lourd après rotation : la rotation ne change pas le poids. Utilisez la compression si besoin, sachant que le texte n'est alors plus sélectionnable.

Sur téléphone

Retourner le téléphone fait pivoter l'affichage, pas le fichier. Pour changer le PDF lui-même, utilisez l'outil de rotation dans le navigateur, qui marche aussi sur mobile.

Confidentialité

La rotation se fait dans le navigateur : le document n'est pas envoyé sur un serveur.

Questions fréquentes

Pivoter un PDF change-t-il sa taille ?

Non, seule l'orientation d'affichage des pages change. Le poids du fichier reste à peu près le même.

Peut-on mettre en paysage une seule page ?

Oui : choisissez la ou les pages à pivoter plutôt que le document entier.

Pourquoi mon tableau reste-t-il étroit après rotation ?

Parce que la page est restée portrait. Il faut changer l'orientation dans le document d'origine puis réexporter le PDF.

La rotation abîme-t-elle la qualité ?

Non, ce n'est qu'un changement d'orientation de page.
