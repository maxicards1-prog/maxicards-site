JPG vs JPEG: what is the difference?

There is none: JPG and JPEG are exactly the same image format.

Only the file extension differs, and you can switch from one to the other by renaming the file.

Updated November 23, 2026

Same format, two spellings

JPEG stands for Joint Photographic Experts Group, the group of experts that defined this compression format for photos. A file named photo.jpg and a file named photo.jpeg contain the same kind of data: same quality, same weight, and software reads them the same way.

Where does "JPG" come from?

In the days of older systems such as MS-DOS and the first versions of Windows, file extensions were limited to three characters. Since ".jpeg" has four letters, it was shortened to ".jpg". When systems began to accept longer extensions, ".jpeg" became possible, but the ".jpg" habit stuck. Today both coexist: some devices, programs and sites save as .jpg, others as .jpeg.

Can you rename one to the other?

Yes. Going from photo.jpeg to photo.jpg (or the reverse) changes nothing in the content, because it is already the same format. Just edit the extension in the file name. If Windows or your Mac hides extensions, turn on their display in File Explorer or Finder options so you can edit them.

Watch out: renaming does not convert

The confusion often comes from another case. Renaming a .png to .jpg does not transform the image: the file stays a PNG under a false name, and some sites or programs will reject it. The same goes for a .heic or a .webp. To really change format, you need to convert: PNG to JPG or JPG to PNG, in your browser and without uploading the file.

A site rejects my .jpeg (or my .jpg)

Some online forms accept only one of the two spellings, because of an overly strict validation rule. Simply rename the extension. If the site rejects the file because of its size, that is a different problem: see how to reduce a photo's file size or use the image compressor directly.

What about .jpe and .jfif?

You may run into other extensions, such as .jfif, often produced by some browsers when saving an image. They generally also designate JPEG images. If a program rejects them, converting to a real JPG or PNG solves the problem. To pick the right format for each use, read JPG vs PNG vs WebP.

Frequently asked questions

Do JPG and JPEG have the same quality?

Yes, it is strictly the same format. Quality depends on the compression setting used when the image was created, not on the extension.

Which extension should I use?

Use whichever the site or program requires. With no constraint, .jpg is the most common.

Is renaming a PNG to JPG enough?

No. The file would remain a PNG with the wrong extension. You need a real conversion.
