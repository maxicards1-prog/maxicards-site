How to Convert a Word Document to PDF

In Word, use File > Save As (or Export) and choose the PDF format.

How to do it

  1. Proofread the document. Check spelling, page breaks and images: the PDF will reproduce exactly what you see.
  2. Open the save menu. In Word: File > Save As (or Export).
  3. Choose PDF as the format. Select PDF in the list of file formats.
  4. Give it a different name. Microsoft advises a name different from the original document: that way you keep the editable Word file and the PDF to share.
  5. Check the PDF. Open the file you produced and scroll through it before sending.

Why go through PDF?

A PDF looks the same on every device, without distorting the layout or depending on the recipient's fonts. It is the expected format for a resume, a quote, a letter or a contract. It is also harder to change by mistake than a Word document.

In Word

The procedure goes through "Save As" and then choosing the PDF format. On a Mac, Microsoft documents exactly this path and reminds you of an important point: if you keep the same name as the original document, you will not be able to edit the PDF without specialized software. So give it a different name and always keep the Word file.

In LibreOffice

LibreOffice Writer offers export to PDF from the File menu. It is a free solution that produces faithful PDFs for everyday documents.

In Google Docs

In Google Docs, the File > Download menu offers the PDF format. If your document is a Word file in Drive, open it with Google Docs and then download it as PDF. Check the layout: small differences from Word are possible.

On a phone

The mobile Word app generally offers to save or share a document as a PDF. If you cannot find the option, open the document in a web version of your word processor, or use your phone's print function and choose to save as PDF, when available.

After the conversion

  • Too heavy? Reduce it with PDF compression, knowing it turns pages into images: the text is no longer selectable.
  • Several documents to combine? Merge them into a single PDF.
  • A document to sign? Add your signature: the guide how to sign a PDF for free explains the options.

Mistakes to avoid

Do not assume the PDF will fix a shaky layout: what is shifted in Word will be shifted in the PDF. Also check metadata and comments: a Word document can contain comments or tracked changes you do not want to share. Finally, never overwrite your Word file with the PDF.

To go the other way (from a PDF to Word), see convert a PDF to Word for free. This site does not convert Word to PDF itself: that step is done in your software.

Frequently asked questions

Does this site convert a Word file to PDF?

No, it does not process Word files. The PDF export is done in Word, LibreOffice or Google Docs, and then the site can compress, merge or sign the PDF.

Why keep the Word file?

Because a PDF is hard to edit. With the Word file, you fix and re-export in seconds.

Will the layout change?

In principle no: the PDF freezes the layout. Still, check before sending.

Can I do it from my phone?

Yes, through the word processing app or the print-to-PDF function, depending on your phone.
