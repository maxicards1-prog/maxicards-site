Why Won't My PDF Open? How to Fix It

Most often, the download is incomplete or the file was damaged along the way.

How to do it

  1. Check the file size. A file of 0 KB or an unusually small one is incomplete. Download it again or ask the sender for it.
  2. Check the extension. The name must end in .pdf. A file named .pdf.txt or with no extension will not open properly.
  3. Try another reader. Open it in your browser (drag the file into a window) or in another PDF reader.
  4. Look for protection. A password may be requested: you need to get it from the author. This site does not unlock protected PDFs.
  5. Test it on this site. If the file opens in the tool, the problem is your reader. If not, it is probably damaged.

The most common causes

Interrupted download or transfer

A dropped connection, an oversized email or a canceled transfer produces a truncated PDF. Symptoms: an error message on opening, a blank document, missing pages. The remedy is simple: download the file again, or ask the sender to send it again, preferably another way (a share link rather than an attachment).

Outdated or faulty reader

An old PDF reader can fail on recent files. Update it or test the file in an up-to-date browser. If the PDF opens in the browser but not in your usual reader, the reader is the culprit.

Wrong extension or wrong file type

Some files received by email or downloaded from a website are named "document.pdf" but are actually a web page, an archive or another format. A very light file is a clue. Open it with a text editor: a real PDF generally starts with "%PDF".

Password or restrictions

A protected PDF asks for a password to open. Without it, you cannot go further: contact the author. This site does not get around these protections.

Damaged file

A faulty disk, a USB drive removed too early or a saving error can corrupt a file. If you have a backup copy, use it. If the PDF opens in no reader at all, repair is rarely possible: look for the original source instead.

Special cases

  • The PDF opens but the pages are sideways: rotate them.
  • The PDF is huge and the reader crashes: split it into pieces and open them one by one.
  • You only need an image of the page: convert the PDF to JPG, if the file opens in the tool.

On a phone

On mobile, a PDF received as an attachment may open in a limited preview. Save it to your device, then open it with a PDF reader app or with the browser. If the file is heavy, give it time to load.

When to give up and ask for the file again

If three different readers fail and the size looks right, the PDF is damaged. Ask for it again. To avoid the problem in the future, send large documents as a link rather than an attachment, and read our guide on email attachments that are too big.

Frequently asked questions

Why does my PDF open as a blank page?

The file may be incomplete, or the reader may struggle to display it. Try an up-to-date browser, then download it again.

Can a corrupted PDF be repaired?

Rarely. The most reliable approach is to get another copy from the source.

Can this site open a password-protected PDF?

No, it does not unlock protected PDFs.

Why won't a PDF received by email open on my phone?

The email preview is sometimes limited. Save the file, then open it with a PDF reader app or the browser.
