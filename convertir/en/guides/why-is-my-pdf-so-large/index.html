Why Is My PDF So Large?

In the vast majority of cases, the cause is images: a high-resolution scan or photos that were never reduced.

Text, on the other hand, weighs very little.

Updated November 23, 2026

A text PDF is light, an image PDF is not

A multi-page document that contains only text usually weighs very little. As soon as images come into play, the size climbs. To find out what is weighing down your file, ask yourself the following questions in order.

1. Is it a scan?

If you can select the text with your mouse, the PDF is "digital". If not, it is probably a scan: each page is a photograph of the sheet. A high-resolution color scan is the most common cause of a heavy PDF. One page scanned in color can weigh several MB, while a grayscale or black-and-white page is much lighter.

Fix: redo the scan with more modest settings (grayscale, medium resolution), or run the file through the compression tool.

2. Does it contain photos?

A brochure, an illustrated quote or a presentation exported to PDF often contains photos inserted at their original size, sometimes far larger than needed on screen. If you still have the source document, shrink the images before exporting: our image compression tool can do that for you.

3. Are there extra pages?

Blank pages, appendices, several copies of the same proof document: every added page adds to the total. Remove them with page deletion.

4. Fonts and other elements

A PDF can embed the fonts it uses so the document looks the same everywhere. When several fonts or character sets are embedded, that adds a little weight, but rarely much compared with images. The same goes for layers, annotations, attached files or very detailed vector graphics: they can weigh more than you would think, without being the number one cause.

5. Merged PDFs

When you merge PDF files, the total size is roughly the sum of the starting files. If the result is too big, one of the original files already was.

What to do next

  • Compress with the compression tool. It converts pages into lighter images: the size drops sharply, but the text is no longer selectable. Keep the original.
  • Separate the document with split PDF if you must send it in pieces.
  • For the sending itself, read how to reduce a PDF for email.

How to avoid the problem in the future

Scan in grayscale unless color really matters, avoid excessive resolutions for a simple proof document, and export your documents from a word processor rather than photographing them. For scans made with a phone, our guide to scanning on mobile gives the right settings to remember.

Frequently asked questions

How can I tell if my PDF is a scan?

Try selecting a word with your mouse. If nothing highlights, or if the whole page is selected like an image, it is a scan.

Why does a 2-page PDF weigh several MB?

Most often because of images: a high-resolution color scan or photos embedded at their original size.

Do embedded fonts make a PDF much bigger?

A little, but rarely in a decisive way. Images remain the number one cause.

Does compression damage the document?

It turns pages into lighter images: the text is no longer selectable and sharpness drops slightly. Keep the original.
