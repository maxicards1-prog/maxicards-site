How to Reduce PDF Size to Send It by Email

Compress the PDF: that is enough in most cases.

The free tool, no file upload:
Compress PDFSplit PDFDelete PDF pages

If the file is still too big, split it into several parts or share it as a link instead of an attachment.

Updated November 23, 2026

How to do it

  1. Check the file size. Right-click the PDF and choose "Properties" (Windows) or "Get Info" (Mac). Compare it with your email provider's limit.
  2. Remove what you do not need. Blank pages, appendices, duplicates: delete them with the page deletion tool before compressing anything.
  3. Compress the PDF. Drop the file on the compression tool, then download the lighter version. Everything happens in your browser.
  4. Check the result. Open the new PDF and make sure the pages are still readable, especially small print and stamps.
  5. Split it if needed. If the file is still too heavy, separate the document into two or three PDFs and send them in separate messages.

What size is accepted?

Every email provider has its own limit. Gmail and Outlook.com refuse or redirect messages whose attachments add up to more than 25 MB. Work or school email systems can be stricter, and so can your recipient's. For details, see our guide on the maximum attachment size.

A word of caution: aim well below the limit. An attachment is encoded when it is sent, so the message weighs a bit more than the original file.

What compression does, and what it costs

The PDF compression tool turns each page into a lighter image. The weight savings are often large, especially for documents full of photos or scans. The trade-off is that the text is no longer selectable: you will not be able to copy it or search it. So always keep the original, and send the compressed version only for reading or printing.

The file is not uploaded to a server: processing happens in your browser, which matters if the document contains personal data. The site's limit is 300 MB per PDF.

If compression is not enough

  • Remove pages: with page deletion, you keep only what the recipient needs to see.
  • Split the document: the split PDF tool produces several lighter files to send one at a time.
  • Use a link: put the PDF in your online storage and send the link. This is exactly what Gmail suggests when an attachment is too big.

The case of scans

A PDF made from a high-resolution color scan is the first cause of huge files. If you scan yourself, set the scanner to grayscale or a medium resolution from the start and you will avoid the problem. To understand where the weight comes from, read why a PDF is so large.

A trap to avoid

Do not just rename the file or put it in a zip archive hoping to save space: a PDF is already a compressed format, and an archive barely makes it lighter.

Frequently asked questions

Can you compress a PDF without losing quality?

Not here: the site's compression turns pages into lighter images, with a slight loss of sharpness and text that is no longer selectable. Keep the original.

Is my file uploaded to a server?

No. Processing happens in your browser and the file never leaves your device.

What is the maximum file size the site accepts?

300 MB per PDF. The size a PDF can have for email is a separate question, because it depends on your email provider.

Can the recipient reject a file that my email accepted?

Yes. The recipient's mail system applies its own limit, sometimes lower than yours. When in doubt, share a link.
