How to Extract a Page From a PDF

Use the site's page extraction tool: choose the pages you want and download a new PDF.

The free tool, no file upload:
Extract pagesSplit PDFDelete PDF pages

Windows and Mac can also do it through print to PDF.

Updated November 23, 2026

How to do it

  1. Find the page numbers. Open the PDF and note the pages to keep, for example 3 or 5 to 7.
  2. Open the extraction tool. Drop the PDF on the extract pages page.
  3. Enter the pages to keep. Select the page or pages you want.
  4. Run it and download. The new PDF is created in your browser. The original is not changed.
  5. Check the result. Open the file to make sure only the right pages are in it.

Extract, split or delete: what is the difference?

  • Extract: you keep only the pages you choose, in a new file.
  • Split: you cut the document into several files.
  • Delete: you remove the unneeded pages and keep the rest.

To get a single page, extracting is the most direct. If the document has 10 pages and you want to remove 2, deleting is quicker.

With this site

The extraction tool works in your browser: the file is not uploaded to a server. The original stays intact. The limit is 300 MB per PDF. The tool works on a computer as well as on a phone.

On Windows, with nothing to install

Open the PDF in your browser, start printing, choose the "Microsoft Print to PDF" printer and enter the pages to print. Instead of printing, Windows creates a new PDF containing those pages. The exact options depend on the browser or reader you use.

On a Mac, with Preview

In Preview, show the thumbnails through View > Thumbnails. Apple explains that changes are saved automatically, so work on a copy of the file. A proven method is to use printing, choose the page range you want, then save as PDF from the PDF menu in the print window. You can also drag a thumbnail out of the window to create a file, depending on your macOS version.

On iPhone and Android

Use your phone's browser and the site's tool: it is the simplest, with no app to install. Print to PDF is also possible on some devices, but the path varies.

Practical cases

A receipt buried in a big document

Extract the page you need rather than sending all 80 pages. It is lighter and you do not disclose what should stay private. Be careful, though: check that the extracted page does not contain information you did not want to share.

A page to turn into an image

Extract it first, then use PDF to JPG if you need an image.

An upside-down page

Fix the orientation with rotate PDF. The topic is also covered in the guide change a PDF to landscape.

Going further

Frequently asked questions

Does extraction modify the original PDF?

No, the tool produces a new file and leaves the original intact.

Can I extract several non-consecutive pages?

Yes, by selecting them individually, for example pages 2, 5 and 9.

What is the difference with splitting?

Splitting cuts the whole document into several files, while extracting creates a single file with the chosen pages.

Does extraction work on a scanned PDF?

Yes: each page is handled as a page, whether it contains text or an image.
