How to Merge PDFs Without Paid Software

Drop your PDFs on the site's merge tool, put them in the right order and download the result: it is free and nothing gets installed.

How to do it

  1. Gather your PDFs. Put them in one folder and name them in the order you want (01, 02, 03) so you can keep track.
  2. Add them to the merge tool. Open the merge page and select all the files, from a computer or from a phone.
  3. Check the order. Put the files in the right sequence before starting the merge.
  4. Merge and download. The single PDF is created in your browser. Save it under a new name.
  5. Check the pages. Scroll through the result: page direction, order, no blank page.

Why merge?

For a rental application, a job application or an official request, you are often asked for a single file. Merging several PDFs saves you from sending ten attachments and guarantees the page order is respected.

The simplest method: your browser

The merge PDF tool works on Windows, Mac, Linux, iPhone and Android, with no installation. Files stay on your device: processing happens in your browser, which is useful for personal documents. The limit is 300 MB per PDF.

On a Mac, with Preview

Preview can combine PDFs. Apple explains that you can add pages from one PDF to another or gather the full content of several files, and that changes are saved automatically. One piece of official advice worth keeping: duplicate each PDF before combining them so you keep the originals. To see the pages, go to View > Thumbnails.

On Windows

As far as we know, Windows has no built-in PDF merge tool. Avoid programs that promise to be free and then impose a watermark or a subscription: the browser tool is enough.

On iPhone and Android

Use your phone's browser: select the PDFs from your files or from a storage service. If a file is an email attachment, save it to the device first.

Changing the order or removing pages

If, once merged, the order is not right, use page organization. To remove an extra page, page deletion solves it. If some pages are the wrong way up, rotate them.

Watch the final size

The merged file weighs roughly the sum of the starting files. To send it by email, check your provider's limit (see the maximum attachment size) and, if needed, compress it, knowing the text will no longer be selectable.

Files that are not PDFs

Photos? Convert them first: see convert a photo to PDF. Word documents? Save them as PDF from the software (Word to PDF guide) and then merge.

Frequently asked questions

Do I need to install software to merge PDFs?

No: the site's tool works in the browser, on a computer or a phone.

Can I merge password-protected PDFs?

The site does not unlock protected PDFs. Remove the protection with the original software if you have the right to.

Can the page order be changed afterward?

Yes, with the page organization tool, or by naming the files in order before adding them.

Is there a maximum number of files?

Only the 300 MB per PDF limit is announced. Beyond a few dozen files, work in batches.
