Quel pays a cet indicatif ?

Le numéro tapé reste sur votre appareil : il n'est ni envoyé, ni gardé.

    Tapez un indicatif, le début d'un numéro ou le nom d'un pays : la réponse s'affiche pendant la frappe.

    Mis à jour le 26/11/2026 · tout se passe dans votre navigateur, rien n'est envoyé.

    Comment lire un numéro étranger

    Un numéro international commence par + (ou par 00 depuis la France), suivi de l'indicatif du pays : 1 à 3 chiffres. Tapez le début du numéro : l'outil trouve le pays, même si vous collez le numéro entier. Exemple : +44 20… est un numéro de Londres, 00 212 6… un portable marocain.

    Pour appeler l'étranger depuis la France, composez 00, l'indicatif du pays, puis le numéro sans le 0 du début quand il y en a un. Le détail, avec les exceptions, est dans le guide appeler à l'étranger.

    Les indicatifs partagés

    Quelques indicatifs servent à plusieurs pays ; les chiffres suivants les distinguent.

    • +1 : Antigua-et-Barbuda, Bahamas, Barbade, Canada, Dominique, États-Unis, Grenade, Jamaïque, République dominicaine, Saint-Christophe-et-Niévès, Saint-Vincent-et-les-Grenadines, Sainte-Lucie, Trinité-et-Tobago
    • +39 : Italie, Vatican
    • +7 : Kazakhstan, Russie

    Questions fréquentes

    Quel pays a l'indicatif +44 ?

    Le Royaume-Uni. Depuis la France, on compose 00 44 puis le numéro sans le 0 du début.

    Que veut dire 00 devant un numéro ?

    C'est le préfixe pour appeler l'étranger depuis la France et la plupart des pays d'Europe. Sur un portable, le signe + le remplace partout dans le monde.

    Faut-il garder le 0 du numéro ?

    Le plus souvent, non : le 0 du début sert aux appels dans le pays et disparaît après l'indicatif. Exception notable : l'Italie, où le 0 des numéros fixes se garde (+39 06… pour Rome).
